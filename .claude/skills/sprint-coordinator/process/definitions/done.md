# Definition of Done

For a sprint or feature to be considered "Done", it must meet ALL criteria below.

## 1. Functional Correctness
- [ ] Features are implemented according to `docs/specifications/*.md`.
- [ ] Acceptance criteria from `sprint-planning` are met.
- [ ] Edge cases identified in planning are handled.

## 2. Quality & Testing
- [ ] Unit tests pass (100%).
- [ ] Integration tests pass (100%).
- [ ] **Test Strategy Compliance**: All "Required Test Types" identified in Phase 4 Stage 1 have been implemented and executed.
- [ ] No regression in existing test suite.

## 3. Architecture & Code
- [ ] Zero Technical Debt (no `TODO`, `FIXME`, or hacks left behind).
- [ ] Code follows architecture patterns in `docs/design/vision.md`.
- [ ] Code follows design documented in `docs/design/*.md`.

## 4. Documentation
- [ ] `docs/specifications/*.md` updated if requirements changed.
- [ ] `docs/design/*.md` updated if implementation approach changed.
- [ ] User-facing docs (README, Help Text) match behaviors.

## 5. Process
- [ ] Sprint Review created.
- [ ] Changes committed and pushed.
