# Incoming Feedback and Issues

This directory is a temporary location for user feedback, bug reports, and feature requests until GitHub Issues integration is implemented.

## Purpose

Collects user input and feedback that needs to be processed and incorporated into sprint planning.

## Current Contents

- `open-bugs.md` - Known bugs to be addressed
- `original-user-story.md` - Original project requirements
- `update-design-docs.md` - Completed documentation reorganization (2026-01-23)
- `*.png` - Screenshots and visual evidence

## Workflow

1. **User provides feedback** → File created in this directory
2. **Sprint planning** → Coordinator reviews incoming items
3. **Incorporation** → Items moved to appropriate locations:
   - Bugs → `tests/cases/` as test cases
   - Features → `docs/roadmap/backlog.md`
   - Design changes → Sprint planning docs
4. **Completion** → Original file marked as processed or archived

## Future

This directory will be replaced with GitHub Issues integration, providing:
- Better tracking and organization
- Discussion threads
- Labels and milestones
- Integration with CI/CD
- Public visibility for community

Until then, this directory serves as a simple intake mechanism for user feedback.
