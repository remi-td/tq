# TC-036-002: Profile Command with Project Config

## Purpose

Verify that `tq profiles` command correctly displays project config file path when present and shows helpful tip when no profiles exist. Validates merged profile display with source annotations.

## Acceptance Criteria Coverage

- **AC-3**: `tq profiles` shows project config file path when present
- **AC-4**: `tq profiles` shows tip about project config when no profiles exist

## Scope

This test validates:
- Project config path displayed when `.tq.toml` exists
- Path format: "Project config: /path/to/project/.tq.toml"
- Project config line omitted when no `.tq.toml` found (no noise)
- Empty state shows helpful tip: "Tip: Create .tq.toml in your project root for team-shared profiles"
- Merged profile display shows sources (user config vs project config)
- Profile source annotations are clear

## Prerequisites

- Rust test framework available
- `tq` binary built
- tempfile crate for test directory creation
- Profiles command implementation complete

## Test Procedure

### Integration Test 1: Project Config Path Display

```rust
#[test]
fn test_profiles_shows_project_config_path() {
    let temp_dir = TempDir::new().unwrap();

    // Create .tq.toml with profiles
    let project_config = temp_dir.path().join(".tq.toml");
    fs::write(
        &project_config,
        r#"
[profiles.dev]
host = "dev-td.example.com"
database = "dev_db"
        "#,
    ).unwrap();

    // Execute tq profiles from temp directory
    let output = Command::new(TQ_BIN)
        .args(&["profiles"])
        .current_dir(temp_dir.path())
        .output()
        .expect("Failed to execute tq profiles");

    assert!(output.status.success(), "Command should succeed");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify project config path is displayed
    assert!(
        stdout.contains("Project config:"),
        "Output should include 'Project config:' header"
    );
    assert!(
        stdout.contains(".tq.toml"),
        "Output should show .tq.toml path"
    );
}
```

```rust
#[test]
fn test_profiles_shows_merged_with_sources() {
    let temp_dir = TempDir::new().unwrap();

    // Create user config
    let user_config_dir = temp_dir.path().join(".config").join("tq");
    fs::create_dir_all(&user_config_dir).unwrap();
    fs::write(
        user_config_dir.join("config.toml"),
        r#"
[profiles.dev]
host = "user-dev.example.com"
user = "alice"
        "#,
    ).unwrap();

    // Create project config (overrides user config)
    let project_config = temp_dir.path().join(".tq.toml");
    fs::write(
        &project_config,
        r#"
[profiles.dev]
database = "project_db"

[profiles.prod]
host = "prod-td.example.com"
        "#,
    ).unwrap();

    // Execute tq profiles
    let output = Command::new(TQ_BIN)
        .args(&["profiles"])
        .current_dir(temp_dir.path())
        .env("HOME", temp_dir.path())
        .output()
        .expect("Failed to execute tq profiles");

    assert!(output.status.success(), "Command should succeed");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify both profiles listed
    assert!(stdout.contains("dev"), "Should list 'dev' profile");
    assert!(stdout.contains("prod"), "Should list 'prod' profile");

    // Verify source annotations
    // Implementation may show: "dev (user + project)" or similar
    assert!(
        stdout.contains("user") || stdout.contains("USER"),
        "Should indicate user config source"
    );
    assert!(
        stdout.contains("project") || stdout.contains("PROJECT"),
        "Should indicate project config source"
    );
}
```

### Integration Test 5: Project Config Overrides User Config

```rust
#[test]
fn test_profiles_project_overrides_user() {
    let temp_dir = TempDir::new().unwrap();

    // Create user config with 'dev' profile
    let user_config_dir = temp_dir.path().join(".config").join("tq");
    fs::create_dir_all(&user_config_dir).unwrap();
    fs::write(
        user_config_dir.join("config.toml"),
        r#"
[profiles.dev]
host = "user-host.example.com"
port = 1025
        "#,
    ).unwrap();

    // Create project config with 'dev' profile (should override host)
    let project_config = temp_dir.path().join(".tq.toml");
    fs::write(
        &project_config,
        r#"
[profiles.dev]
host = "project-host.example.com"
        "#,
    ).unwrap();

    // Execute tq profiles --profile dev --verbose
    // (verbose mode should show merged values with precedence)
    let output = Command::new(TQ_BIN)
        .args(&["profiles", "--profile", "dev"])
        .current_dir(temp_dir.path())
        .env("HOME", temp_dir.path())
        .output()
        .expect("Failed to execute tq profiles");

    assert!(output.status.success(), "Command should succeed");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify project config host takes precedence
    assert!(
        stdout.contains("project-host.example.com"),
        "Should show project config host (overrides user config)"
    );

    // Port should still come from user config (not overridden)
    assert!(
        stdout.contains("1025"),
        "Should show port from user config (not overridden)"
    );
}
```

### Integration Test 6: Absolute Path Display

```rust
#[test]
fn test_profiles_shows_absolute_path() {
    let temp_dir = TempDir::new().unwrap();

    // Create .tq.toml in nested directory
    let nested = temp_dir.path().join("projects").join("myproject");
    fs::create_dir_all(&nested).unwrap();
    let project_config = nested.join(".tq.toml");
    fs::write(
        &project_config,
        r#"
[profiles.local]
host = "localhost"
        "#,
    ).unwrap();

    // Execute tq profiles from nested directory
    let output = Command::new(TQ_BIN)
        .args(&["profiles"])
        .current_dir(&nested)
        .output()
        .expect("Failed to execute tq profiles");

    assert!(output.status.success(), "Command should succeed");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify absolute path (not relative like "./.tq.toml")
    let expected_path = project_config.canonicalize().unwrap();
    let path_str = expected_path.to_string_lossy();

    assert!(
        stdout.contains(&*path_str) || stdout.contains(".tq.toml"),
        "Should show absolute path to project config"
    );
    assert!(
        !stdout.contains("./.tq.toml"),
        "Should not show relative path"
    );
}
```
