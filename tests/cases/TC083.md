# TC083: File Overwrite - Existing File

**Test ID:** TC083  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** High  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify behavior when output file already exists (overwrite without prompt in batch mode).

## Requirement Coverage

- REQ-F1-08: Overwrite protection (--force flag or prompt)

## Test Procedure

```bash
# Create existing file
echo "Old content" > /tmp/test_overwrite.txt

# Overwrite with new query output
tq query "SELECT 'New content' AS data" --output /tmp/test_overwrite.txt

# Verify content replaced
cat /tmp/test_overwrite.txt
# Expected: Table format with "New content", NOT "Old content"

# Clean up
rm -f /tmp/test_overwrite.txt
```

## Expected Results

- ✅ File overwritten successfully
- ✅ Old content completely replaced
- ✅ Warning message (optional): "Overwriting existing file..."

## Acceptance Criteria

- Batch mode overwrites without interactive prompt
- Complete replacement (not append)
- Atomic operation (no mixed old/new content)

## Notes

Interactive prompt may be P2 feature. For Sprint 23, simple overwrite is acceptable.
