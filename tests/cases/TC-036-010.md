# TC-036-010: `/show indexes` Completion and Help

## Purpose

Verify that `/show indexes` command appears in tab completion with description and is documented in `/help` output. Validates discoverability and documentation quality.

## Acceptance Criteria Coverage

- **AC-21**: Tab completion includes `/show indexes` with description
- **AC-22**: `/help` output includes `/show indexes` command

## Scope

This test validates:
- Tab completion suggests `/show indexes` when typing `/show`
- Tab completion shows description for `/show indexes`
- `/help` command lists `/show indexes`
- `/help` shows description of `/show indexes` functionality
- Short alias `\di` documented in help or completion
- Completion and help entries match command functionality
- Consistency with other `/show` subcommands

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- expectrl crate for PTY testing
- Tab completion implementation complete
- Help text implementation complete
- Database connection available (for REPL spawn)

### Interactive Test 8: Consistency with Other `/show` Commands

```rust
#[test]
#[ignore] // Requires database connection
fn test_help_show_commands_consistent() {
    let mut repl = spawn_repl().expect("Failed to spawn REPL");

    // Execute /help
    repl.send_line("/help").unwrap();

    let output = repl.read_until_prompt().unwrap();

    // If other /show subcommands exist, verify consistency
    let has_other_show_commands = output.contains("/show tables") ||
                                   output.contains("/show databases") ||
                                   output.contains("/show columns");

    if has_other_show_commands {
        // All /show commands should be grouped or formatted consistently
        let show_commands = output
            .lines()
            .filter(|line| line.contains("/show"))
            .collect::<Vec<_>>();

        // Should have multiple /show commands
        assert!(
            show_commands.len() > 1,
            "Multiple /show commands should exist"
        );

        // Verify /show indexes is among them
        let has_indexes = show_commands.iter().any(|line| line.contains("indexes"));
        assert!(has_indexes, "/show indexes should be with other /show commands");
    }
}
```

### Interactive Test 9: Help and Completion Match

```rust
#[test]
#[ignore] // Requires database connection
fn test_help_and_completion_descriptions_match() {
    let mut repl = spawn_repl().expect("Failed to spawn REPL");

    // Get completion description
    repl.send("/show indexes").unwrap();
    repl.send("\t").unwrap();
    let completion_output = repl.read_until_prompt().unwrap();

    // Get help description
    repl.send_line("/help").unwrap();
    let help_output = repl.read_until_prompt().unwrap();

    // Both should mention indexes and similar action verbs
    let completion_mentions_display = completion_output.contains("display") ||
                                      completion_output.contains("show") ||
                                      completion_output.contains("list");

    let help_mentions_display = help_output.contains("display") ||
                               help_output.contains("show") ||
                               help_output.contains("list");

    assert!(
        completion_mentions_display || help_mentions_display,
        "Completion and help should use consistent terminology"
    );
}
```
