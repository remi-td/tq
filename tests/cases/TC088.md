# TC088: Transaction Status Messages

**Test ID:** TC088  
**Feature:** Batch Mode Transaction Control (Sprint 23 - P1)  
**Priority:** High  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify clear transaction status messages displayed during --atomic execution.

## Requirement Coverage

- REQ-F2-06: Transaction status messages

## Test Procedure

```bash
# Simple multi-statement batch
cat > /tmp/test_messages.sql << 'SQL'
SELECT 1 AS step;
SELECT 2 AS step;
SQL

# Run with verbose mode to see messages
tq query --file /tmp/test_messages.sql --atomic -v 2>&1 | tee /tmp/output.txt

# Check for expected messages
grep "BEGIN TRANSACTION" /tmp/output.txt && echo "✓ BEGIN message found"
grep "COMMIT" /tmp/output.txt && echo "✓ COMMIT message found"

# Clean up
rm -f /tmp/test_messages.sql /tmp/output.txt
```

## Expected Results

- ✅ "BEGIN TRANSACTION (--atomic mode)" in verbose output
- ✅ "COMMIT (all statements succeeded)" in verbose output
- ✅ Statement progress messages
- ✅ Messages to stderr (not mixed with query results)

## Acceptance Criteria

- Transaction boundaries clearly communicated
- User understands when transaction starts/ends
- Verbose mode required for transaction messages (not shown by default)
