# TC-043-002: Profile Add - Error Cases

**Test ID:** TC-043-002
**Feature:** Profile Management - `tq profile add` error handling
**Priority:** P0 - Critical
**Test Type:** Integration (CLI process) + Unit
**Sprint:** 43
**Created:** 2026-03-21
**Requirement References:** AC-4, AC-11, AC-12

---

## Objective

Verify that `tq profile add` correctly rejects invalid inputs and produces useful error messages.
This test case focuses on the error path: duplicate profile name, missing required flag, invalid logmech, and invalid port numbers.

---

## Test Environment

Same as TC-043-001: temporary directory via `TQ_CONFIG_DIR` environment variable. No database required.

## Test Cases

### TS43-P-B01: Add to existing profile name without --force (AC-4)

**Precondition:** Config file contains profile `staging`.

**Command:**
```
tq profile add staging --host newhost.example.com
```

**Expected Results:**
- Exit code: non-zero (1 or 2)
- Error message on stderr mentions profile name `staging`
- Error message indicates the profile already exists
- Config file UNCHANGED (original `staging` profile not overwritten)

```rust
#[test]
fn test_add_existing_profile_without_force() {
    let tmp = tempfile::TempDir::new().unwrap();
    // Create initial profile
    std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "staging", "--host", "original.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    let before = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();

    // Attempt duplicate add
    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "staging", "--host", "new.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    assert!(!output.status.success(), "must fail on duplicate profile");

    let stderr = String::from_utf8_lossy(&output.stderr);
    let stdout = String::from_utf8_lossy(&output.stdout);
    let combined = format!("{stderr}{stdout}");
    assert!(
        combined.contains("staging"),
        "error must mention profile name, got: {combined}"
    );
    assert!(
        combined.to_lowercase().contains("exist") || combined.to_lowercase().contains("already"),
        "error must indicate profile exists, got: {combined}"
    );

    // Config must be unchanged
    let after = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert_eq!(before, after, "config file must not be modified on error");
}
```

### TS43-P-B03: Invalid logmech value - lowercase (AC-11)

**Precondition:** Fresh temp directory.

**Command:**
```
tq profile add p1 --host h --logmech td2
```

**Expected Results:**
- Exit code: non-zero
- Error message lists valid logmech values (TD2, LDAP, KRB5, TDNEGO)
- Validates that logmech matching is case-sensitive

```rust
#[test]
fn test_add_invalid_logmech_lowercase() {
    let tmp = tempfile::TempDir::new().unwrap();
    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "p1", "--host", "h", "--logmech", "td2"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    assert!(!output.status.success(), "lowercase 'td2' must be rejected");
    let combined = format!(
        "{}{}",
        String::from_utf8_lossy(&output.stderr),
        String::from_utf8_lossy(&output.stdout)
    );
    // Error should list valid values
    assert!(
        combined.contains("TD2") || combined.contains("LDAP") || combined.to_lowercase().contains("logmech"),
        "error must indicate valid logmech values, got: {combined}"
    );
}
```
