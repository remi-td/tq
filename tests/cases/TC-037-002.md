# TC-037-002: Edit Modified Content Execution

## Metadata

| **Category** | Integration + Interactive |

## Purpose

Verify that when the editor modifies the SQL query, the modified query is automatically executed upon save and exit, and the edited query is stored as `last_sql` (enabling `/repeat` after `/edit`).

## Acceptance Criteria Coverage

- **AC-2**: On save and exit, the edited SQL is executed automatically
- **AC-10**: Edited query stored as `last_sql` (enabling `/repeat` after `/edit`)

## Scope

This test validates:
- Modified SQL query executed automatically after editor exits
- Query execution results displayed correctly
- Edited query stored in `ReplState.last_sql`
- `/repeat` works after `/edit` (proves last_sql updated)
- Editor exit code 0 (success) triggers execution
- Workflow: SQL → `/edit` → modify → save/exit → auto-execute

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- expectrl crate for PTY testing
- Database connection available for interactive tests
- Mock editor scripts created in `tests/fixtures/mock_editors/`
- `/edit` implementation complete

## Test Procedure

### Integration Test 1: Mock Editor Modifies and Executes

```rust
#[test]
fn test_edit_modified_content_executes() {
    use std::fs;
    use std::process::Command;
    use tempfile::TempDir;

    // Create mock editor that appends to file
    let temp_dir = TempDir::new().unwrap();
    let mock_editor = temp_dir.path().join("mock_editor_modify.sh");
    fs::write(&mock_editor, r#"#!/bin/bash
echo " WHERE 1=1" >> "$1"
exit 0
"#).unwrap();

    // Make executable
    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        let mut perms = fs::metadata(&mock_editor).unwrap().permissions();
        perms.set_mode(0o755);
        fs::set_permissions(&mock_editor, perms).unwrap();
    }

    // Set EDITOR to mock script
    std::env::set_var("EDITOR", mock_editor.to_str().unwrap());

    // Create test database connection
    let logon = std::env::var("TQ_LOGON").expect("TQ_LOGON not set");

    // Run tq with commands: execute SQL, then /edit
    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("SELECT 1 AS original;")
        .arg("--command")
        .arg("/edit")
        .output()
        .expect("Failed to execute tq");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify modified query was executed
    // Original: SELECT 1 AS original;
    // Modified: SELECT 1 AS original; WHERE 1=1
    // Should execute and return result (even if syntax error, should attempt)
    assert!(
        stdout.contains("original") || stdout.contains("executed"),
        "Modified query should be executed"
    );

    // Cleanup
    std::env::remove_var("EDITOR");
}
```

### Integration Test 2: Edit Updates last_sql

```rust
#[test]
fn test_edit_updates_last_sql() {
    use std::fs;
    use std::process::Command;
    use tempfile::TempDir;

    // Create mock editor that replaces content
    let temp_dir = TempDir::new().unwrap();
    let mock_editor = temp_dir.path().join("mock_editor_replace.sh");
    fs::write(&mock_editor, r#"#!/bin/bash
echo "SELECT 99 AS modified;" > "$1"
exit 0
"#).unwrap();

    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        let mut perms = fs::metadata(&mock_editor).unwrap().permissions();
        perms.set_mode(0o755);
        fs::set_permissions(&mock_editor, perms).unwrap();
    }

    std::env::set_var("EDITOR", mock_editor.to_str().unwrap());

    let logon = std::env::var("TQ_LOGON").expect("TQ_LOGON not set");

    // Run: SQL → /edit → /repeat (should execute modified query)
    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("SELECT 1 AS original;")
        .arg("--command")
        .arg("/edit")
        .arg("--command")
        .arg("/repeat")
        .output()
        .expect("Failed to execute tq");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify /repeat executed the MODIFIED query (99), not original (1)
    assert!(
        stdout.matches("99").count() >= 2, // Once from /edit, once from /repeat
        "/repeat should execute modified query from /edit"
    );

    std::env::remove_var("EDITOR");
}
```

## Pass/Fail Criteria

**PASS if:**
- All integration tests pass
- All interactive tests pass (when database available)
- Modified content executed automatically after editor exit
- Modified query results displayed correctly
- `/repeat` after `/edit` executes modified query (proves last_sql updated)
- No user prompt required (execution is automatic)

**FAIL if:**
- Modified query not executed automatically
- Original query executed instead of modified query
- `/repeat` after `/edit` executes original query (last_sql not updated)
- User prompted for confirmation (should be automatic)
- Editor exits successfully but query not executed
- Syntax errors in modified query crash the REPL
- Database errors not handled gracefully
