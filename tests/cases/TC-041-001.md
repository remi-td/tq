## Purpose

Verify that (1) `cargo build` succeeds after the build.rs cross-compilation fix, and (2) all 855+ existing tests continue to pass after both the build.rs changes and the Sprint 40 remediation code changes (query.rs, repl/mod.rs, params.rs).

## Acceptance Criteria Coverage

- **AC-14**: Local native builds (cargo build) still work correctly
- **AC-15**: All existing tests pass with updated build.rs
- **AC-26**: All existing 855 tests pass after Sprint 40 remediation changes

## Test Procedure

### Step 1: Native Build Verification

```bash
cd <project-root>
cargo build 2>&1
echo "Exit code: $?"
```

**Expected result:**
- Exit code: 0
- No compilation errors
- Any `cargo:warning=` lines are acceptable (library copy notifications)
- The binary `target/debug/tq` is produced

### Step 2: Full Test Suite Regression

```bash
cd <project-root>
cargo test 2>&1
```

**Expected result:**
- All tests pass (no failures)
- Test count >= 855
- Zero test failures
- `#[ignore]` tests are skipped (requires live database - acceptable)

### Step 3: Count Verification

```bash
cd <project-root>
cargo test 2>&1 | tail -5
```

**Expected result:**
- Output includes a line like `test result: ok. N passed; 0 failed; M ignored; 0 measured`
- `N` (passed) >= 855
- `failed` = 0

## Pass/Fail Criteria

| Check | Pass Condition | Fail Condition |
|-------|---------------|----------------|
| cargo build exit code | 0 | Non-zero |
| cargo test pass count | >= 855 | < 855 |
| cargo test fail count | 0 | > 0 |
| Binary produced | target/debug/tq exists | File absent |

## Notes

- If `cargo build` fails, this is a BLOCKING regression - do not proceed with other tests
- Live-database tests (`#[ignore]`) are excluded from this count and are acceptable as skipped
- The baseline test count (855) comes from Sprint 40 final state
