# TC080: Atomic File Writing (Temp + Rename)

**Test ID:** TC080  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** Critical  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify atomic file writes using temp file + rename pattern prevent partial files.

## Requirement Coverage

- REQ-F1-05: Atomic file writing (temp + rename)

## Test Procedure

```bash
# Test 1: Normal success case - no temp files left
ls /tmp/tq_*.tmp 2>/dev/null | wc -l  # Should be 0
tq query "SELECT 1" --output /tmp/test_atomic.txt
ls /tmp/tq_*.tmp 2>/dev/null | wc -l  # Should be 0 (temp cleaned up)
[ -f /tmp/test_atomic.txt ] && echo "PASS: File created"

# Test 2: Simulate failure - verify no partial file
# (Need to test with query that fails mid-execution)
tq query "SELECT INVALID SQL" --output /tmp/test_fail.txt 2>/dev/null || true
[ ! -f /tmp/test_fail.txt ] && echo "PASS: No partial file on error"
```

## Expected Results

- ✅ No temp files visible after success
- ✅ No partial files on error
- ✅ Complete file or no file (atomic)

## Acceptance Criteria

- Temp file created in same directory as target
- Rename atomic (same filesystem)
- Cleanup on success and failure
