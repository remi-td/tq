# TC085: Empty Result Set to File

**Test ID:** TC085  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** Medium  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify file output handles empty result sets correctly.

## Test Procedure

```bash
# Query returning 0 rows
tq query "SELECT * FROM (SELECT 1 AS id WHERE 1=0) AS empty" --output /tmp/empty.txt

# Verify file exists (even if empty)
[ -f /tmp/empty.txt ] && echo "File exists"

# Check contents
cat /tmp/empty.txt
# Expected: Header only (for table/CSV), or empty array (for JSON)

# Clean up
rm -f /tmp/empty.txt
```

## Expected Results

- ✅ File created (not skipped)
- ✅ Contains headers but no data rows (table/CSV)
- ✅ Empty array `[]` for JSON
- ✅ Message: "Wrote 0 rows to..."

## Acceptance Criteria

- Empty results handled gracefully
- File format still valid
- Clear indication of 0 rows
