## Purpose

Verify that column widths are calculated from actual cell content rather than schema type definitions, maximizing information density in table displays.

## Acceptance Criteria Coverage

- **AC-1**: Column width calculated from actual cell content, not schema type
- **AC-3**: Minimum column width respects column header length

## Scope

This test validates:
- Column width calculation uses actual content length
- Width is not derived from schema VARCHAR(N) definition
- Multiple rows: max content length is selected
- Header length is considered in width calculation

## Prerequisites

- Rust test framework available
- Access to table formatting module in `src/format/table.rs`

## Test Procedure

### Test Implementation (in `src/format/table.rs`):

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_column_width_from_content_not_schema() {
        // Setup: VARCHAR(64) column with short content
        let columns = vec![
            ColumnMetadata {
                name: "DatabaseName".to_string(),
                type_info: "VARCHAR(64)".to_string(), // Schema says 64 chars
                nullable: false,
            },
        ];
        let rows = vec![
            vec![Value::String("SystemDB".to_string())], // 8 chars
            vec![Value::String("TempDB".to_string())],   // 6 chars
            vec![Value::String("UserDB".to_string())],   // 6 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        // Calculate column widths
        let widths = calculate_column_widths(&result);

        // Assert: Width based on content (8 chars), not schema (64 chars)
        // Actual width will be max(header_length, max_content_length)
        // Header "DatabaseName" = 12 chars, max content = 8 chars
        // Expected width = 12
        assert_eq!(widths[0], 12);
        assert!(widths[0] < 64, "Width should not be based on schema type");
    }

    #[test]
    fn test_column_width_respects_header_length() {
        // Setup: Long header, short content
        let columns = vec![
            ColumnMetadata {
                name: "VeryLongColumnHeaderName".to_string(), // 24 chars
                type_info: "VARCHAR(100)".to_string(),
                nullable: false,
            },
        ];
        let rows = vec![
            vec![Value::String("short".to_string())], // 5 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is at least header length
        assert_eq!(widths[0], 24, "Width should match header length");
    }

    #[test]
    fn test_column_width_max_across_rows() {
        // Setup: Multiple rows with varying content lengths
        let columns = vec![
            ColumnMetadata {
                name: "Name".to_string(), // 4 chars
                type_info: "VARCHAR(50)".to_string(),
                nullable: false,
            },
        ];
        let rows = vec![
            vec![Value::String("Bob".to_string())],        // 3 chars
            vec![Value::String("Alice".to_string())],      // 5 chars
            vec![Value::String("Charlie".to_string())],    // 7 chars (max)
            vec![Value::String("Eve".to_string())],        // 3 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max content length (7) across all rows
        assert_eq!(widths[0], 7, "Width should be max content length across all rows");
    }

    #[test]
    fn test_multiple_columns_independent_widths() {
        // Setup: Multiple columns with different content lengths
        let columns = vec![
            ColumnMetadata::new("ID", "INTEGER"),
            ColumnMetadata::new("Name", "VARCHAR(50)"),
            ColumnMetadata::new("Email", "VARCHAR(100)"),
        ];
        let rows = vec![
            vec![
                Value::Integer(1),
                Value::String("Alice".to_string()),    // 5 chars
                Value::String("a@example.com".to_string()), // 13 chars
            ],
            vec![
                Value::Integer(123),
                Value::String("Bob".to_string()),      // 3 chars
                Value::String("bob@test.co".to_string()), // 11 chars
            ],
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Each column has independent width based on its content
        // ID: max(2, 3) = 3 (header "ID" = 2, content "123" = 3)
        // Name: max(4, 5) = 5 (header "Name" = 4, content "Alice" = 5)
        // Email: max(5, 13) = 13 (header "Email" = 5, content "a@example.com" = 13)
        assert_eq!(widths[0], 3);
        assert_eq!(widths[1], 5);
        assert_eq!(widths[2], 13);
    }
}
```

## Expected Results

All unit tests pass:
- Column widths calculated from actual content, not schema types
- Width is max(header_length, max_content_length)
- Multiple rows: maximum content length selected
- Multiple columns: independent width calculations

## Pass/Fail Criteria

**PASS if:**
- All 4 unit tests compile and pass
- Column widths are based on content, not schema VARCHAR(N) definition
- Header length is respected as minimum width
- Max content length across all rows is used
- No panics or calculation errors

**FAIL if:**
- Any unit test fails
- Column width equals schema type definition (e.g., 64 for VARCHAR(64))
- Header is truncated (width < header length)
- Width calculation fails with panics or errors
