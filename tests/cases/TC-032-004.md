# TC-032-004: Unit Test - Numeric Column Right-Alignment Logic

| Field | Value |
|-------|-------|
| **Test ID** | TC-032-004 |
| **Title** | Unit Test - Numeric Column Right-Alignment Logic |
| **Category** | Unit Test |
| **Priority** | High |
| **Feature** | Sprint 32 - Content-Based Column Width (AC-9) |
| **Test Type** | Unit |
| **Created** | 2026-02-03 |

## Purpose

Verify that numeric columns remain right-aligned within their content-calculated width, preserving readability for numeric data.

## Acceptance Criteria Coverage

- **AC-9**: Works correctly with numeric alignment

## Scope

This test validates:
- Numeric column widths calculated from actual numeric values
- Alignment logic preserved for numeric types
- Integer, decimal, and float types handled correctly
- Mixed numeric and text columns maintain independent alignment

## Prerequisites

- Rust test framework available
- Access to table formatting module in `src/format/table.rs`

## Test Procedure

### Test Implementation (in `src/format/table.rs`):

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_integer_column_width_from_digits() {
        // Setup: Integer column with varying digit counts
        let columns = vec![
            ColumnMetadata::new("Amount", "INTEGER"),
        ];
        let rows = vec![
            vec![Value::Integer(1)],      // 1 digit
            vec![Value::Integer(42)],     // 2 digits
            vec![Value::Integer(12345)],  // 5 digits (max)
            vec![Value::Integer(999)],    // 3 digits
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max(header, max_digit_count)
        // Header "Amount" = 6 chars, max digits = 5
        assert_eq!(widths[0], 6);
    }

    #[test]
    fn test_negative_integer_includes_minus_sign() {
        // Setup: Negative integers
        let columns = vec![
            ColumnMetadata::new("Delta", "INTEGER"),
        ];
        let rows = vec![
            vec![Value::Integer(-123)],   // 4 chars (including minus)
            vec![Value::Integer(45)],     // 2 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width includes minus sign
        // Header "Delta" = 5 chars, max content = 4 chars
        assert_eq!(widths[0], 5);
    }

    #[test]
    fn test_decimal_column_width_includes_decimal_point() {
        // Setup: Decimal numbers
        let columns = vec![
            ColumnMetadata::new("Price", "DECIMAL(10,2)"),
        ];
        let rows = vec![
            vec![Value::Float(9.99)],      // "9.99" = 4 chars
            vec![Value::Float(123.45)],    // "123.45" = 6 chars (max)
            vec![Value::Float(1.00)],      // "1.00" = 4 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width includes decimal point and precision
        // Header "Price" = 5 chars, max content = 6 chars
        assert_eq!(widths[0], 6);
    }

    #[test]
    fn test_numeric_alignment_logic_preserved() {
        // Setup: Check that alignment metadata is set correctly
        let columns = vec![
            ColumnMetadata::new("ID", "INTEGER"),
            ColumnMetadata::new("Name", "VARCHAR(50)"),
        ];
        let rows = vec![
            vec![
                Value::Integer(123),
                Value::String("Alice".to_string()),
            ],
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        // Get column alignment info
        let alignment = get_column_alignment(&result);

        // Assert: Numeric columns are right-aligned, text is left-aligned
        assert_eq!(alignment[0], Alignment::Right, "Numeric column should be right-aligned");
        assert_eq!(alignment[1], Alignment::Left, "Text column should be left-aligned");
    }

    #[test]
    fn test_large_integer_width() {
        // Setup: Very large integer
        let columns = vec![
            ColumnMetadata::new("BigNum", "BIGINT"),
        ];
        let rows = vec![
            vec![Value::Integer(9876543210)], // 10 digits
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width accommodates all digits
        // Header "BigNum" = 6 chars, content = 10 chars
        assert_eq!(widths[0], 10);
    }

    #[test]
    fn test_mixed_numeric_and_text_columns() {
        // Setup: Multiple columns with different types
        let columns = vec![
            ColumnMetadata::new("ID", "INTEGER"),
            ColumnMetadata::new("Qty", "INTEGER"),
            ColumnMetadata::new("Name", "VARCHAR(50)"),
            ColumnMetadata::new("Price", "DECIMAL(10,2)"),
        ];
        let rows = vec![
            vec![
                Value::Integer(1),
                Value::Integer(100),
                Value::String("Widget".to_string()),
                Value::Float(19.99),
            ],
            vec![
                Value::Integer(42),
                Value::Integer(5),
                Value::String("Gadget".to_string()),
                Value::Float(9.50),
            ],
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Each column width calculated correctly
        // ID: max(2, 2) = 2
        // Qty: max(3, 3) = 3
        // Name: max(4, 6) = 6
        // Price: max(5, 5) = 5
        assert_eq!(widths[0], 2);
        assert_eq!(widths[1], 3);
        assert_eq!(widths[2], 6);
        assert_eq!(widths[3], 5);
    }
}
```

## Expected Results

All unit tests pass:
- Numeric column widths calculated from digit count (including minus sign, decimal point)
- Alignment logic preserved: numeric = right, text = left
- Large integers and decimals handled correctly
- Mixed numeric and text columns maintain independent alignment

## Pass/Fail Criteria

**PASS if:**
- All 6 unit tests compile and pass
- Integer widths include minus sign for negative numbers
- Decimal widths include decimal point and precision
- Alignment metadata correct: numeric = right, text = left
- Large numbers (10+ digits) calculated correctly
- No panics or numeric conversion errors

**FAIL if:**
- Any unit test fails
- Numeric widths exclude minus sign or decimal point
- Alignment metadata incorrect
- Large number widths truncated or incorrect
