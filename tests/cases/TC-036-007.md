# TC-036-007: `/show indexes` SQL Generation and Parsing

| **Category** | Unit |

| **Created** | 2026-02-13 |

## Purpose

Verify that `/show indexes` metacommand correctly generates SQL queries to DBC.IndicesV, parses qualified table names, and handles the short alias `\di`.

## Acceptance Criteria Coverage

- **AC-15**: `/show indexes <table>` displays index information from DBC.IndicesV
- **AC-16**: Qualified name support: `/show indexes database.table`
- **AC-17**: Short alias `\di` works
- **AC-23**: Unit tests for SQL generation and argument parsing

## Scope

This test validates:
- SQL generation for unqualified table name (uses current database)
- SQL generation for qualified table name (database.table)
- Argument parsing: `/show indexes mytable`
- Argument parsing: `/show indexes mydb.mytable`
- Alias parsing: `\di` treated as `/show indexes`
- Error handling: missing table name argument
- SQL query correctness (queries DBC.IndicesV)
- Column selection: IndexName, IndexType, ColumnName, ColumnPosition

## Prerequisites

- Rust test framework available
- SQL generation functions implemented
- Metacommand parser implemented
- No database required (unit tests only)

## Test Procedure

### Unit Test 1: Unqualified Table Name SQL Generation

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_show_indexes_sql_unqualified_table() {
        let current_database = "mydb";
        let table_name = "employees";

        let sql = generate_show_indexes_sql(current_database, table_name);

        // Verify SQL queries DBC.IndicesV
        assert!(
            sql.contains("DBC.IndicesV") || sql.contains("DBC.Indices"),
            "SQL should query DBC.IndicesV system catalog"
        );

        // Verify WHERE clause uses current database
        assert!(
            sql.contains("DatabaseName") && sql.contains("mydb"),
            "SQL should filter by DatabaseName = current database"
        );

        // Verify WHERE clause uses table name
        assert!(
            sql.contains("TableName") && sql.contains("employees"),
            "SQL should filter by TableName"
        );

        // Verify correct columns selected
        assert!(sql.contains("IndexName"), "Should select IndexName");
        assert!(sql.contains("IndexType"), "Should select IndexType");
        assert!(sql.contains("ColumnName"), "Should select ColumnName");
        assert!(sql.contains("ColumnPosition"), "Should select ColumnPosition");
    }

    #[test]
    fn test_show_indexes_sql_qualified_table() {
        let current_database = "default_db"; // Should be ignored
        let qualified_name = "otherdb.employees";

        let sql = generate_show_indexes_sql_from_qualified(qualified_name);

        // Verify SQL uses specified database, not current
        assert!(
            sql.contains("otherdb") && !sql.contains("default_db"),
            "SQL should use specified database from qualified name"
        );

        // Verify table name extracted correctly
        assert!(
            sql.contains("employees"),
            "SQL should use table name from qualified name"
        );
    }

    #[test]
    fn test_show_indexes_command_parsing() {
        let input = "/show indexes employees";
        let parsed = parse_metacommand(input);

        assert!(parsed.is_some(), "Should parse /show indexes command");
        let command = parsed.unwrap();
        assert_eq!(command.name, "show", "Command name should be 'show'");
        assert_eq!(command.subcommand, Some("indexes"), "Subcommand should be 'indexes'");
        assert_eq!(command.args, vec!["employees"], "Should extract table name");
    }

    #[test]
    fn test_show_indexes_qualified_name_parsing() {
        let input = "/show indexes prod_db.customer_table";
        let parsed = parse_metacommand(input);

        assert!(parsed.is_some(), "Should parse qualified table name");
        let command = parsed.unwrap();
        assert_eq!(command.args, vec!["prod_db.customer_table"]);

        // Test qualified name splitting
        let (database, table) = parse_qualified_name("prod_db.customer_table");
        assert_eq!(database, Some("prod_db"), "Should extract database name");
        assert_eq!(table, "customer_table", "Should extract table name");
    }

    #[test]
    fn test_show_indexes_alias_di_parsing() {
        let input = r"\di employees";
        let parsed = parse_metacommand(input);

        assert!(parsed.is_some(), r"Should parse \di alias");
        let command = parsed.unwrap();
        assert_eq!(
            command.name, "show",
            r"\di should be treated as /show indexes"
        );
        assert_eq!(
            command.subcommand, Some("indexes"),
            r"\di should map to 'indexes' subcommand"
        );
        assert_eq!(command.args, vec!["employees"]);
    }

    #[test]
    fn test_show_indexes_missing_argument_error() {
        let input = "/show indexes";
        let parsed = parse_metacommand(input);

        assert!(parsed.is_some(), "Should parse command");
        let command = parsed.unwrap();

        // Validation should fail (missing table name)
        let result = validate_show_indexes_args(&command);
        assert!(
            result.is_err(),
            "Should return error when table name missing"
        );

        let error = result.unwrap_err();
        assert!(
            error.contains("table name") || error.contains("argument"),
            "Error should mention missing table name"
        );
    }

    #[test]
    fn test_parse_qualified_name_variations() {
        // Test unqualified name
        let (db, table) = parse_qualified_name("employees");
        assert_eq!(db, None, "Unqualified name should have no database");
        assert_eq!(table, "employees");

        // Test qualified name
        let (db, table) = parse_qualified_name("mydb.employees");
        assert_eq!(db, Some("mydb"));
        assert_eq!(table, "employees");

        // Test quoted identifiers (if supported)
        let (db, table) = parse_qualified_name(r#""my db"."my table""#);
        assert_eq!(db, Some(r#""my db""#));
        assert_eq!(table, r#""my table""#);
    }

    #[test]
    fn test_sql_generation_escapes_identifiers() {
        let current_database = "my-db";
        let table_name = "my-table";

        let sql = generate_show_indexes_sql(current_database, table_name);

        // Verify identifiers are properly handled
        // (May need quoting if they contain special characters)
        assert!(
            sql.contains("my-db") || sql.contains(r#""my-db""#),
            "SQL should handle database name with special characters"
        );
        assert!(
            sql.contains("my-table") || sql.contains(r#""my-table""#),
            "SQL should handle table name with special characters"
        );
    }

    #[test]
    fn test_sql_generation_case_sensitivity() {
        let current_database = "MyDB";
        let table_name = "MyTable";

        let sql = generate_show_indexes_sql(current_database, table_name);

        // Verify case is preserved
        assert!(
            sql.contains("MyDB"),
            "SQL should preserve database name case"
        );
        assert!(
            sql.contains("MyTable"),
            "SQL should preserve table name case"
        );
    }

    #[test]
    fn test_sql_order_by_clause() {
        let sql = generate_show_indexes_sql("mydb", "mytable");

        // Verify results are ordered for readability
        assert!(
            sql.contains("ORDER BY"),
            "SQL should include ORDER BY for consistent output"
        );

        // Typically: ORDER BY IndexName, ColumnPosition
        assert!(
            sql.contains("IndexName") && sql.contains("ColumnPosition"),
            "SQL should order by IndexName and ColumnPosition"
        );
    }
}
```
