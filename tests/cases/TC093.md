# TC093: Transaction with Different Output Formats

**Test ID:** TC093  
**Feature:** Transaction Control with Output Formats  
**Priority:** Medium  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify --atomic works with all output formats (table, CSV, JSON).

## Test Procedure

```bash
# Test with CSV
tq query --file batch.sql --atomic --format csv --output results.csv

# Test with JSON
tq query --file batch.sql --atomic --format json --output results.json

# Test with table (default)
tq query --file batch.sql --atomic --output results.txt
```

## Expected Results

- ✅ Transaction control independent of output format
- ✅ All formats work with --atomic

## Acceptance Criteria

- No format-specific transaction bugs
- Output correct in all formats
