# TC-035-001: Project Config Discovery - Directory Walking

## Purpose

Verify that the project configuration discovery mechanism correctly walks up the directory tree to find `.tq.toml` files and stops at the appropriate boundaries.

## Acceptance Criteria Coverage

- **AC-1**: Parse `.tq.toml` from current directory (walks up to find) - Directory walking logic
- **AC-8**: Test coverage: unit tests for config loading, integration tests for profile resolution - Unit test component

## Scope

This test validates:
- Finding `.tq.toml` in current directory
- Walking up to parent directories
- Walking up multiple levels
- Stopping at filesystem root (no infinite loop)
- Returning None when no `.tq.toml` found
- Caching resolved path
- Symlink resolution to prevent infinite loops

## Prerequisites

- Rust test framework available
- tempfile crate available for test directory creation
- Project config discovery implementation exists

## Test Procedure

### Test Implementation:

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::fs;
    use tempfile::TempDir;

    #[test]
    fn test_find_project_config_in_current_dir() {
        // Create temp directory with .tq.toml
        let temp_dir = TempDir::new().unwrap();
        let config_path = temp_dir.path().join(".tq.toml");
        fs::write(&config_path, "[defaults]\nformat = \"json\"").unwrap();

        // Change to temp directory
        let old_dir = std::env::current_dir().unwrap();
        std::env::set_current_dir(temp_dir.path()).unwrap();

        // Test discovery
        let result = find_project_config();

        // Restore directory
        std::env::set_current_dir(old_dir).unwrap();

        assert!(result.is_ok());
        let found_path = result.unwrap();
        assert!(found_path.is_some(), "Should find .tq.toml in current directory");
        assert_eq!(found_path.unwrap(), config_path);
    }

    #[test]
    fn test_find_project_config_in_parent_dir() {
        // Create temp directory structure:
        // temp_root/
        //   .tq.toml
        //   subdir/
        let temp_root = TempDir::new().unwrap();
        let config_path = temp_root.path().join(".tq.toml");
        fs::write(&config_path, "[defaults]\nformat = \"json\"").unwrap();

        let subdir = temp_root.path().join("subdir");
        fs::create_dir(&subdir).unwrap();

        // Change to subdirectory
        let old_dir = std::env::current_dir().unwrap();
        std::env::set_current_dir(&subdir).unwrap();

        // Test discovery from subdirectory
        let result = find_project_config();

        // Restore directory
        std::env::set_current_dir(old_dir).unwrap();

        assert!(result.is_ok());
        let found_path = result.unwrap();
        assert!(found_path.is_some(), "Should find .tq.toml in parent directory");
        assert_eq!(found_path.unwrap(), config_path);
    }

    #[test]
    fn test_find_project_config_multiple_levels_up() {
        // Create temp directory structure:
        // temp_root/
        //   .tq.toml
        //   level1/
        //     level2/
        //       level3/
        let temp_root = TempDir::new().unwrap();
        let config_path = temp_root.path().join(".tq.toml");
        fs::write(&config_path, "[defaults]\nformat = \"json\"").unwrap();

        let level1 = temp_root.path().join("level1");
        let level2 = level1.join("level2");
        let level3 = level2.join("level3");
        fs::create_dir_all(&level3).unwrap();

        // Change to deeply nested directory
        let old_dir = std::env::current_dir().unwrap();
        std::env::set_current_dir(&level3).unwrap();

        // Test discovery from deep subdirectory
        let result = find_project_config();

        // Restore directory
        std::env::set_current_dir(old_dir).unwrap();

        assert!(result.is_ok());
        let found_path = result.unwrap();
        assert!(found_path.is_some(), "Should find .tq.toml multiple levels up");
        assert_eq!(found_path.unwrap(), config_path);
    }

    #[test]
    fn test_find_project_config_stops_at_first_match() {
        // Create temp directory structure with TWO .tq.toml files:
        // temp_root/
        //   .tq.toml (outer)
        //   subdir/
        //     .tq.toml (inner - should find this one)
        //     workdir/
        let temp_root = TempDir::new().unwrap();
        let outer_config = temp_root.path().join(".tq.toml");
        fs::write(&outer_config, "[defaults]\nformat = \"table\"").unwrap();

        let subdir = temp_root.path().join("subdir");
        fs::create_dir(&subdir).unwrap();
        let inner_config = subdir.join(".tq.toml");
        fs::write(&inner_config, "[defaults]\nformat = \"json\"").unwrap();

        let workdir = subdir.join("workdir");
        fs::create_dir(&workdir).unwrap();

        // Change to workdir
        let old_dir = std::env::current_dir().unwrap();
        std::env::set_current_dir(&workdir).unwrap();

        // Test discovery - should find inner config, not outer
        let result = find_project_config();

        // Restore directory
        std::env::set_current_dir(old_dir).unwrap();

        assert!(result.is_ok());
        let found_path = result.unwrap();
        assert!(found_path.is_some(), "Should find .tq.toml");
        assert_eq!(
            found_path.unwrap(),
            inner_config,
            "Should stop at first .tq.toml found (inner, not outer)"
        );
    }

    #[test]
    fn test_find_project_config_not_found() {
        // Create temp directory WITHOUT .tq.toml
        let temp_dir = TempDir::new().unwrap();

        // Change to temp directory
        let old_dir = std::env::current_dir().unwrap();
        std::env::set_current_dir(temp_dir.path()).unwrap();

        // Test discovery
        let result = find_project_config();

        // Restore directory
        std::env::set_current_dir(old_dir).unwrap();

        assert!(result.is_ok(), "Not finding config is not an error");
        let found_path = result.unwrap();
        assert!(found_path.is_none(), "Should return None when no .tq.toml found");
    }

    #[test]
    fn test_find_project_config_stops_at_filesystem_root() {
        // Start from a real directory that definitely doesn't have .tq.toml
        // in its ancestry (unlikely to have one at root)
        // This test validates we don't loop infinitely

        // Create a temp directory far from root
        let temp_dir = TempDir::new().unwrap();
        let deep_path = temp_dir.path().join("a").join("b").join("c").join("d");
        fs::create_dir_all(&deep_path).unwrap();

        let old_dir = std::env::current_dir().unwrap();
        std::env::set_current_dir(&deep_path).unwrap();

        // This should terminate (not infinite loop)
        let result = find_project_config();

        std::env::set_current_dir(old_dir).unwrap();

        // Should return Ok(None) after reaching filesystem root
        assert!(result.is_ok(), "Should not error when reaching filesystem root");
    }
}
```

## Expected Results

All unit tests pass:
- `.tq.toml` found in current directory
- `.tq.toml` found in parent directory (walk up 1 level)
- `.tq.toml` found multiple levels up (walk up 3+ levels)
- Discovery stops at first `.tq.toml` found (doesn't continue to parent)
- Returns None when no `.tq.toml` exists
- Search terminates at filesystem root (no infinite loop)

## Pass/Fail Criteria

**PASS if:**
- All 6 unit tests compile and pass
- Directory walking logic works correctly
- Search stops at first match (closest to current directory)
- Returns None gracefully when not found
- No infinite loops when reaching filesystem root
- Symlinks are resolved properly (no loops)

**FAIL if:**
- Any unit test fails
- Infinite loop occurs during directory traversal
- Wrong `.tq.toml` selected (outer instead of inner)
- Errors when no config exists (should return None)
- Symlink causes infinite loop
