# TC-044-008: SqlParseError Struct Variant with Line and Column

**Sprint:** 44
**Feature:** Technical Debt Cleanup (AC-20)
**Acceptance Criteria:** AC-20
**Type:** Unit Test
**Requires DB:** No
**Requires Binary:** No

---

## Objective

Verify that `TqError::SqlParseError` has been upgraded from a tuple variant `SqlParseError(String)` to a struct variant `SqlParseError { message: String, line: usize, column: usize }`, that the Display implementation includes line and column information, and that the conversion from `sql::parser::ParseError` to `TqError::SqlParseError` preserves line and column.

## Preconditions

- `TqError::SqlParseError` in `src/error.rs` is a struct variant with `message`, `line`, `column` fields
- The Display implementation includes the position information
- The conversion (via `From<ParseError>` or explicit `.map_err`) preserves line and column

## Test Scenarios

### Scenario 1: Struct variant is constructible with line and column

**Action:** Construct `TqError::SqlParseError` with explicit fields

**Assert:**
```rust
let err = TqError::SqlParseError {
    message: "Unterminated string literal".to_string(),
    line: 3,
    column: 7,
};
// Must compile - this is the primary check that the variant is a struct
assert!(matches!(err, TqError::SqlParseError { .. }));
```

### Scenario 2: Display output includes line and column

**Action:** Format the error with `format!("{}", err)` or `err.to_string()`

**Expected:** Output contains "3" and "7" (or "line 3" and "column 7")

**Assert:**
```rust
let err = TqError::SqlParseError {
    message: "Unterminated string literal".to_string(),
    line: 3,
    column: 7,
};
let display = format!("{}", err);
assert!(display.contains("3"), "Display must include line number, got: {}", display);
assert!(display.contains("7"), "Display must include column number, got: {}", display);
assert!(display.contains("Unterminated string literal"),
    "Display must include message, got: {}", display);
```

### Scenario 3: Exit code is 1 (runtime error, not usage error)

**Assert:**
```rust
let err = TqError::SqlParseError {
    message: "test".to_string(),
    line: 1,
    column: 1,
};
assert_eq!(err.exit_code(), 1,
    "SqlParseError should be exit code 1 (runtime error)");
```

### Scenario 4: ParseError from sql/parser converts to SqlParseError preserving line/column

**Setup:** Create a `sql::parser::ParseError` with known line/column

**Action:** Convert it to `TqError` (via `From` impl or explicit conversion)

**Expected:** The resulting `TqError::SqlParseError` has matching line and column

**Assert:**
```rust
use crate::sql::parser::ParseError;

let parse_err = ParseError {
    message: "Unterminated block comment".to_string(),
    line: 5,
    column: 12,
};

// Conversion should preserve line and column
let tq_err: TqError = parse_err.into();  // or TqError::from(parse_err)

match tq_err {
    TqError::SqlParseError { message, line, column } => {
        assert_eq!(line, 5, "Line must be preserved in conversion");
        assert_eq!(column, 12, "Column must be preserved in conversion");
        assert!(message.contains("block comment"));
    }
    other => panic!("Expected SqlParseError, got: {:?}", other),
}
```

### Scenario 5: user_message() includes position information

**Action:** Call `err.user_message()` on a `SqlParseError` with known line/column

**Expected:** user_message output includes position information useful to the user

**Assert:**
```rust
let err = TqError::SqlParseError {
    message: "Unterminated string".to_string(),
    line: 10,
    column: 5,
};
let msg = err.user_message();
// user_message should be at least as informative as Display
assert!(msg.contains("10") || msg.contains("line 10"),
    "user_message should include line number, got: {}", msg);
```

## Implementation Notes

The upgrade requires:

1. In `src/error.rs`, change:
   ```rust
   // Before
   #[error("SQL parse error: {0}")]
   SqlParseError(String),

   // After
   #[error("SQL parse error: {message} at line {line}, column {column}")]
   SqlParseError {
       message: String,
       line: usize,
       column: usize,
   },
   ```

2. Add conversion from `sql::parser::ParseError`:
   ```rust
   impl From<sql::parser::ParseError> for TqError {
       fn from(e: sql::parser::ParseError) -> Self {
           TqError::SqlParseError {
               message: e.message,
               line: e.line,
               column: e.column,
           }
       }
   }
   ```

3. Update all match arms in the codebase that pattern-match on `TqError::SqlParseError`.

## Pass Criteria

- `TqError::SqlParseError { message, line, column }` compiles (struct variant)
- Display includes line and column numbers
- Exit code is 1
- Conversion from `ParseError` preserves line and column
- No other existing tests broken by the variant change (regression check: run full test suite)
