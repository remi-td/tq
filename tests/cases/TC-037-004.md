## Purpose

Verify that `/edit` and `\e` appear in tab completion menu with appropriate description, and that `/help` text includes the `/edit` command with clear usage information.

## Acceptance Criteria Coverage

- **AC-5**: Tab completion includes `/edit` and `\e` in metacommand menu
- **AC-6**: `/help` text includes `/edit` command description

## Scope

This test validates:
- Tab completion suggests `/edit` when typing `/e`
- Tab completion suggests `\e` when typing `\`
- Tab completion shows description for `/edit` command
- `/help` output includes `/edit` command
- `/help` output describes what `/edit` does
- `/help` output mentions `\e` alias
- Help text and completion consistent

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- expectrl crate for PTY testing
- Tab completion implementation complete
- Help text generation complete
- No database required (help text and completion are static)

## Expected Results

### Tab Completion Results:
- Typing `/e` + TAB suggests `/edit` command
- Typing `\` + TAB includes `\e` in suggestions
- Tab completion shows description for `/edit`
- Description mentions "editor" or "edit" or "last query"
- Completion UI clear and consistent with other metacommands

### Help Text Results:
- `tq repl --help-commands` includes `/edit` command
- `/help` in REPL shows `/edit` command
- Help text describes what `/edit` does (open last query in editor)
- Help text mentions `\e` alias
- Help text shows usage pattern (no arguments)
- Help text mentions $EDITOR/$VISUAL environment variables
- Help text formatting consistent with other commands

## Pass/Fail Criteria

**PASS if:**
- All interactive tests pass (when PTY available)
- Tab completion includes `/edit` and `\e`
- Tab completion shows descriptive text for `/edit`
- Help text includes `/edit` command
- Help text describes `/edit` purpose clearly
- Help text mentions `\e` alias
- Help text mentions $EDITOR or editor concept
- Consistency between completion and help text

**FAIL if:**
- `/edit` missing from tab completion
- `\e` missing from tab completion
- No description shown for `/edit` in completion
- `/edit` missing from help text
- Help text unclear or incomplete
- `\e` alias not mentioned in help
- Inconsistency between completion and help
- Completion or help text confusing
