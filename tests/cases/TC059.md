# Test Case TC059: Result Paging - Horizontal Paging with h/l Keys

## Purpose

Verify that when query results exceed terminal width (many columns or wide columns), horizontal paging works with h (left) and l (right) keys.

## Prerequisites

- tq REPL mode active
- Pager enabled
- Query with wide results (16+ columns or very wide columns)

## Test Procedure

### Step 1: Query with many columns

```sql
tq> SELECT TOP 10 * FROM DBC.DatabasesV;
```

Note: DBC.DatabasesV has 16 columns - likely exceeds terminal width

**Expected:**
- Pager activates
- Shows first N columns that fit in terminal width
- Status line indicates horizontal scrolling available: "Cols 1-8 of 16" or similar
- Right edge indicator (e.g., "→" or ">") shows more columns exist

### Step 2: Scroll right with 'l' key

Press 'l' repeatedly (5 times)

**Expected:**
- Each 'l' press scrolls right by one column (or N characters)
- Previously visible columns scroll off left edge
- New columns appear on right edge
- Status updates: "Cols 4-11 of 16"
- Left edge indicator (e.g., "←" or "<") shows columns to the left

### Step 3: Scroll left with 'h' key

Press 'h' repeatedly (3 times)

**Expected:**
- Each 'h' press scrolls left
- Returns to viewing earlier columns
- Status updates: "Cols 1-8 of 16"
- At leftmost position, 'h' has no effect (boundary)

### Step 4: Test with vertical and horizontal scrolling

Use j/k to scroll vertically AND h/l to scroll horizontally

**Expected:**
- Both vertical and horizontal navigation work simultaneously
- Status line shows both: "Lines 5-30 of 100 | Cols 5-12 of 16"
- Can navigate entire result set in 2D

## Verification

- [ ] 'l' scrolls right (shows more columns)
- [ ] 'h' scrolls left (shows earlier columns)
- [ ] Status line indicates column position
- [ ] Edge indicators show when more columns exist
- [ ] Stops at boundaries (leftmost/rightmost)
- [ ] Works in combination with vertical scrolling

## Pass/Fail Criteria

**PASS:**
- Horizontal paging activates for wide results
- h/l keys work for horizontal navigation
- Status shows column position
- Can view all columns by scrolling
- Works with vertical paging simultaneously

**FAIL:**
- Horizontal paging doesn't work ← CURRENT BUG
- h/l keys not recognized
- Wide tables are truncated with no way to see hidden columns
- Conflicts with vertical navigation
- Terminal width not detected correctly

## Notes

Root cause: Pager module not integrated. Horizontal scrolling is likely in `pager.rs` but never used.

Terminal width detection:
```rust
let (cols, rows) = crossterm::terminal::size()?;
```

Horizontal scroll strategy:
- Option 1: Scroll by column (shift one column at a time)
- Option 2: Scroll by character width (shift N characters)
- Option 3: Snap to column boundaries

Status line should show:
- Current column range visible
- Total column count
- Indicators for more columns left/right
