# TC084: Large Result Sets - Streaming to File

**Test ID:** TC084  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** Medium  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify file output streams large result sets without buffering entire result in memory.

## Test Procedure

```bash
# Query returning many rows (adjust based on test data availability)
tq query "SELECT * FROM large_table" --output /tmp/large_output.csv --format csv

# Monitor memory usage during execution (manual observation)
# Verify file created successfully
[ -f /tmp/large_output.csv ] && wc -l /tmp/large_output.csv

# Clean up
rm -f /tmp/large_output.csv
```

## Expected Results

- ✅ File created successfully
- ✅ Memory usage remains constant (streaming, not buffering)
- ✅ Performance acceptable

## Acceptance Criteria

- Large datasets don't cause OOM
- File written incrementally (streaming)
- Reasonable performance (no slower than stdout)
