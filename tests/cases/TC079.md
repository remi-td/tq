# TC079: Output to File - JSON Format

**Test ID:** TC079  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** Critical  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify `--output` works with JSON format.

## Requirement Coverage

- REQ-F1-04: Supports JSON format output

## Test Procedure

```bash
tq query "SELECT 1 AS id, 'Alice' AS name" --format json --output /tmp/test.json
cat /tmp/test.json
# Expected: [{"id":1,"name":"Alice"}]

# Verify JSON is valid
jq . /tmp/test.json
```

## Expected Results

- ✅ Valid JSON array of objects
- ✅ Column names as keys
- ✅ Type preservation (numbers, strings)

## Acceptance Criteria

- JSON parseable by jq
- Array of objects format
