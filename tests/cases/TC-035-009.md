## Purpose

Verify that the `/peek` command's default row count in documentation matches the actual implementation, and update documentation if there's a mismatch.

## Acceptance Criteria Coverage

- **Feature 2 AC-2**: Verify `/peek` default count in code and update documentation if needed

## Scope

This test validates:
- Default count value in code implementation
- Default count value in `docs/specifications/repl.md`
- Default count value in user guides (if mentioned)
- Consistency between code and documentation
- Update documentation if mismatch found

## Prerequisites

- Code implementation: `src/commands/repl/metacommands.rs` (or similar)
- Documentation: `docs/specifications/repl.md`
- Text editor and code viewer available

## Test Procedure

### Step 1: Check Code Implementation

1. **Locate /peek implementation:**
   ```bash
   grep -r "peek" src/commands/repl/
   # or
   grep -r "DEFAULT.*PEEK" src/
   ```

2. **Find default count constant:**
   - Look for constant like `DEFAULT_PEEK_COUNT`, `PEEK_DEFAULT_ROWS`, etc.
   - Look for default parameter value in function signature
   - Look for fallback value when count not specified

3. **Record actual default value:**
   - [ ] Default count in code: _______

### Example Code Patterns:

```rust
// Pattern 1: Constant
const DEFAULT_PEEK_COUNT: usize = 20;

// Pattern 2: Function parameter
fn peek(&mut self, table: &str, count: Option<usize>) {
    let count = count.unwrap_or(20);  // <-- default here
    ...
}

// Pattern 3: Match expression
match count {
    Some(n) => n,
    None => 20,  // <-- default here
}
```

### Step 2: Check Documentation

1. **Open specification:**
   ```bash
   grep -A 10 "/peek" docs/specifications/repl.md
   ```

2. **Find /peek syntax documentation:**
   - Look for command syntax: `/peek <table> [count]`
   - Look for default count mention
   - Record documented default value

3. **Record documented default:**
   - [ ] Default count in docs: _______

### Step 3: Compare and Validate

1. **Compare values:**
   - [ ] Code default: _______
   - [ ] Docs default: _______
   - [ ] Match? YES / NO

2. **If mismatch found:**
   - [ ] Identify correct value (code is source of truth)
   - [ ] Update documentation to match code
   - [ ] Verify update is clear and accurate

3. **If match found:**
   - [ ] No action needed
   - [ ] Mark test as PASS

### Step 4: Check User Guides (Optional)

1. **Check if user guides mention /peek:**
   ```bash
   grep -r "peek" docs/user/ 2>/dev/null || echo "No user docs"
   ```

2. **If mentioned, verify consistency:**
   - [ ] User guide default matches code
   - [ ] Update user guide if needed

## Expected Results

- Default count in code is identified (likely 10 or 20)
- Default count in documentation matches code
- If mismatch: documentation updated to match code
- All mentions of /peek have consistent default count

## Pass/Fail Criteria

**PASS if:**
- ✅ Default count in code identified
- ✅ Documentation matches code (or updated to match)
- ✅ All documentation mentions are consistent
- ✅ No mismatch remains

**FAIL if:**
- ❌ Cannot identify default count in code
- ❌ Documentation mismatch not resolved
- ❌ Inconsistent values across documentation
