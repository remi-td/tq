## Purpose

Validate the structure and syntax of `.github/workflows/release.yml`. Since the workflow cannot be executed locally (it requires GitHub-hosted runners and a real tag push), this test validates what is locally verifiable: YAML syntax, trigger configuration, build matrix completeness, artifact naming, packaging steps, checksum generation, and release creation steps.

## Acceptance Criteria Coverage

- **AC-1**: triggers on `v*` tag push (locally verifiable)
- **AC-2 to AC-6**: 5 platform build targets present in matrix (locally verifiable)
- **AC-7**: artifact naming convention (locally verifiable)
- **AC-8**: packaging includes native lib + LICENSE (locally verifiable)
- **AC-9**: SHA256 checksums.txt generated (locally verifiable)
- **AC-10**: GitHub Release creation step present (locally verifiable)
- **AC-11**: Release body content (locally verifiable)

**NOT LOCALLY VERIFIABLE:**
- Actual compilation success on each platform (AC-2 to AC-6 runtime)
- Actual GitHub Release publication (AC-10 runtime)
- Actual artifact upload (AC-7, AC-8 runtime)

## Test Procedure

### Step 1: YAML Syntax Validation (actionlint - if available)

```bash
actionlint .github/workflows/release.yml 2>&1
echo "Exit code: $?"
```

**Expected result:**
- Exit code: 0
- Zero errors reported
- BLOCKED if actionlint is not installed

**Fallback (if actionlint not available):**
```bash
python3 -c "import yaml; yaml.safe_load(open('.github/workflows/release.yml'))" && echo "YAML valid" || echo "YAML invalid"
```

### Step 2: Trigger Configuration

```bash
grep -A5 "^on:" .github/workflows/release.yml
```

**Expected result:**
- Contains `push:` trigger
- Contains `tags:` with pattern matching `v*`

### Step 3: Build Matrix - All 5 Targets Present

```bash
grep -E "(x86_64-unknown-linux-gnu|aarch64-unknown-linux-gnu|x86_64-apple-darwin|aarch64-apple-darwin|x86_64-pc-windows-msvc)" .github/workflows/release.yml
```

**Expected result:**
- All 5 target strings appear in the workflow file

### Step 4: Artifact Naming Convention

```bash
grep -i "tq-" .github/workflows/release.yml | grep -i "target\|version"
```

**Expected result:**
- Artifact naming pattern references version and target variables (e.g., `tq-${{ github.ref_name }}-${{ matrix.target }}`)

### Step 5: Native Library Included in Packaging

```bash
grep -i "teradatasql\|native\|lib" .github/workflows/release.yml
```

**Expected result:**
- Reference to teradatasql library in packaging step

### Step 6: SHA256 Checksum Generation

```bash
grep -i "sha256\|checksum" .github/workflows/release.yml
```

**Expected result:**
- At least one reference to SHA256/checksum generation
- `checksums.txt` referenced in upload step

### Step 7: GitHub Release Creation Step

```bash
grep -i "create.release\|release.*create\|gh release\|softprops/action-gh-release\|actions/create-release" .github/workflows/release.yml
```

**Expected result:**
- At least one release creation action or step present

### Step 8: LICENSE Included in Package

```bash
grep -i "LICENSE" .github/workflows/release.yml
```

**Expected result:**
- LICENSE file referenced in packaging step

## Pass/Fail Criteria

| Check | Pass Condition | Fail Condition |
|-------|---------------|----------------|
| YAML syntax (actionlint or python) | Valid YAML, zero errors | Parse errors |
| Trigger on v* tags | `push.tags.v*` present | Trigger absent or wrong |
| 5 build targets | All 5 target strings present | Any target missing |
| Artifact naming | Version + target in artifact name | Naming pattern absent |
| Native library packaging | teradatasql referenced | Library not packaged |
| SHA256 checksums | sha256/checksum step present | No checksum step |
| Release creation | Release creation action present | Step absent |
| LICENSE included | LICENSE in packaging | Not packaged |

## Notes

- This test validates STRUCTURE only - runtime behavior (actual compilation, artifact creation, release publication) requires a real tag push to GitHub
- If actionlint is not installed, the YAML syntax check falls back to Python yaml.safe_load (less comprehensive but checks basic syntax)
- The verdict for this test case is PARTIAL: structural checks PASS, runtime verification DEFERRED to first release tag push
