# TC-032-005: Unit Test - Empty String and Edge Cases

## Metadata

| Field | Value |
|-------|-------|
| **Test ID** | TC-032-005 |
| **Title** | Unit Test - Empty String and Edge Cases |
| **Category** | Unit Test |
| **Priority** | Medium |
| **Feature** | Sprint 32 - Content-Based Column Width |
| **Test Type** | Unit |
| **Created** | 2026-02-03 |

## Purpose

Verify that edge cases (empty strings, single-char strings, Unicode) are handled correctly in width calculations.

## Acceptance Criteria Coverage

- **AC-1**: Column width calculated from actual cell content (edge cases)
- **AC-3**: Minimum column width respects column header length

## Scope

This test validates:
- Empty strings treated as zero-width content
- Single-character strings handled correctly
- Unicode characters (multi-byte) calculated correctly
- Column with all empty strings uses header length

## Prerequisites

- Rust test framework available
- Access to table formatting module in `src/format/table.rs`

## Test Procedure

### Test Implementation (in `src/format/table.rs`):

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_empty_string_width() {
        // Setup: Column with empty strings
        let columns = vec![
            ColumnMetadata::new("Status", "VARCHAR(50)"),
        ];
        let rows = vec![
            vec![Value::String("active".to_string())],    // 6 chars
            vec![Value::String("".to_string())],          // 0 chars (empty)
            vec![Value::String("pending".to_string())],   // 7 chars (max)
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max non-empty content
        // Header "Status" = 6 chars, max content = 7 chars
        assert_eq!(widths[0], 7);
    }

    #[test]
    fn test_all_empty_strings_uses_header() {
        // Setup: Column with all empty strings
        let columns = vec![
            ColumnMetadata::new("OptionalNote", "VARCHAR(100)"),
        ];
        let rows = vec![
            vec![Value::String("".to_string())],
            vec![Value::String("".to_string())],
            vec![Value::String("".to_string())],
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is header length
        // Header "OptionalNote" = 12 chars
        assert_eq!(widths[0], 12, "All-empty column should use header length");
    }

    #[test]
    fn test_single_char_string() {
        // Setup: Single-character strings
        let columns = vec![
            ColumnMetadata::new("Code", "VARCHAR(10)"),
        ];
        let rows = vec![
            vec![Value::String("A".to_string())],  // 1 char
            vec![Value::String("B".to_string())],  // 1 char
            vec![Value::String("C".to_string())],  // 1 char
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is header length (longer than 1-char content)
        // Header "Code" = 4 chars, max content = 1 char
        assert_eq!(widths[0], 4);
    }

    #[test]
    fn test_unicode_characters_display_width() {
        // Setup: Unicode characters (emoji, CJK)
        let columns = vec![
            ColumnMetadata::new("Message", "VARCHAR(100)"),
        ];
        let rows = vec![
            vec![Value::String("Hello 👋".to_string())],   // "Hello " = 6 + emoji (2 display width) = 8 display width
            vec![Value::String("你好".to_string())],        // 2 CJK chars (4 display width)
            vec![Value::String("Test".to_string())],       // 4 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width uses display width, not byte count
        // Note: This test validates that unicode_width crate (or equivalent) is used
        // Header "Message" = 7 chars, max display width = 8
        assert_eq!(widths[0], 8, "Unicode display width should be calculated correctly");
    }

    #[test]
    fn test_zero_rows_uses_header_only() {
        // Setup: Table with no rows (empty result)
        let columns = vec![
            ColumnMetadata::new("ColumnName", "VARCHAR(50)"),
        ];
        let rows: Vec<Vec<Value>> = vec![];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is header length only
        // Header "ColumnName" = 10 chars
        assert_eq!(widths[0], 10, "Empty table should use header width");
    }

    #[test]
    fn test_whitespace_only_strings() {
        // Setup: Strings with only whitespace
        let columns = vec![
            ColumnMetadata::new("Text", "VARCHAR(50)"),
        ];
        let rows = vec![
            vec![Value::String("   ".to_string())],        // 3 spaces
            vec![Value::String("  ".to_string())],         // 2 spaces
            vec![Value::String("Content".to_string())],    // 7 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Whitespace counts toward width
        // Header "Text" = 4 chars, max content = 7 chars
        assert_eq!(widths[0], 7);
    }

    #[test]
    fn test_mixed_edge_cases() {
        // Setup: Multiple edge cases in one column
        let columns = vec![
            ColumnMetadata::new("MixedData", "VARCHAR(100)"),
        ];
        let rows = vec![
            vec![Value::String("".to_string())],           // Empty
            vec![Value::String("A".to_string())],          // Single char
            vec![Value::Null],                             // NULL (6 chars)
            vec![Value::String("  ".to_string())],         // Whitespace (2 chars)
            vec![Value::String("Normal text".to_string())], // 11 chars (max)
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max content across all edge cases
        // Header "MixedData" = 9 chars, max content = 11 chars
        assert_eq!(widths[0], 11);
    }
}
```

## Expected Results

All unit tests pass:
- Empty strings treated as zero-width (header length used)
- Single-character strings handled correctly
- Unicode display width calculated correctly (not byte count)
- Zero-row tables use header length
- Whitespace-only strings counted correctly
- Mixed edge cases: max content length selected

## Pass/Fail Criteria

**PASS if:**
- All 7 unit tests compile and pass
- Empty strings do not dominate width calculation
- Unicode characters use display width (not byte count)
- Zero-row tables use header length
- Mixed edge cases handled correctly
- No panics or calculation errors

**FAIL if:**
- Any unit test fails
- Unicode width incorrect (byte count instead of display width)
- Empty strings incorrectly influence width
- Zero-row tables panic or fail
