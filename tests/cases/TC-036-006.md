# TC-036-006: `/repeat` Completion and Help

## Purpose

Verify that `/repeat` command appears in tab completion suggestions with appropriate description and is documented in `/help` output.

## Acceptance Criteria Coverage

- **AC-11**: Tab completion includes `/repeat` with description "Re-execute last query"
- **AC-12**: `/help` output includes `/repeat` command

## Scope

This test validates:
- Tab completion suggests `/repeat` when typing `/r`
- Tab completion shows description "Re-execute last query" (or similar)
- `/help` command lists `/repeat`
- `/help` shows description of `/repeat` command
- Short alias `\r` documented in help or completion
- Completion and help entries match command functionality

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- expectrl crate for PTY testing
- Tab completion implementation complete
- Help text implementation complete
- Database connection available (for REPL spawn)

### Interactive Test 7: Tab Completion Order

```rust
#[test]
#[ignore] // Requires database connection
fn test_tab_completion_repeat_in_alphabetical_order() {
    let mut repl = spawn_repl().expect("Failed to spawn REPL");

    // Type / and press TAB twice to list all commands
    repl.send("/").unwrap();
    repl.send("\t\t").unwrap(); // Double TAB

    let output = repl.read_until_prompt().unwrap();

    // Verify /repeat appears in alphabetical position
    // (between /quit and /show, or similar)
    assert!(
        output.contains("/repeat"),
        "Tab completion should list /repeat among metacommands"
    );

    // Optional: verify alphabetical order
    let commands: Vec<&str> = output
        .split_whitespace()
        .filter(|s| s.starts_with('/'))
        .collect();

    if commands.len() > 1 {
        // Check that /repeat is in alphabetical position
        let repeat_index = commands.iter().position(|&s| s == "/repeat");
        if let Some(idx) = repeat_index {
            // Verify it's not wildly out of order
            if idx > 0 {
                let prev = commands[idx - 1];
                assert!(
                    prev < "/repeat",
                    "/repeat should be in alphabetical order"
                );
            }
            if idx < commands.len() - 1 {
                let next = commands[idx + 1];
                assert!(
                    "/repeat" < next,
                    "/repeat should be in alphabetical order"
                );
            }
        }
    }
}
```

### Interactive Test 8: Help and Completion Match

```rust
#[test]
#[ignore] // Requires database connection
fn test_help_and_completion_descriptions_match() {
    let mut repl = spawn_repl().expect("Failed to spawn REPL");

    // Get completion description
    repl.send("/re").unwrap();
    repl.send("\t\t").unwrap();
    let completion_output = repl.read_until_prompt().unwrap();

    // Get help description
    repl.send_line("/help").unwrap();
    let help_output = repl.read_until_prompt().unwrap();

    // Descriptions should be consistent
    // Both should mention "re-execute" or "repeat" and "last query"
    let completion_has_desc = completion_output.contains("Re-execute") ||
                              completion_output.contains("last query");
    let help_has_desc = help_output.contains("Re-execute") ||
                       help_output.contains("last query");

    assert!(
        completion_has_desc && help_has_desc,
        "Completion and help should have consistent descriptions"
    );
}
```
