## Purpose

Verify that tq can read and execute SQL queries from files.

## Scope

This test validates:
- --file flag functionality
- SQL script execution
- Multiline query support
- Comment handling
- File not found errors

## Prerequisites

- tq binary is built and available
- `.env` file configured with valid Teradata connection credentials

## Test Procedure

### Step 1: Simple query file
```bash
# Using credentials from .env file
cat > /tmp/test_simple.sql << 'EOF'
SELECT 1 AS one, 2 AS two
EOF
tq query --file /tmp/test_simple.sql
rm /tmp/test_simple.sql
```

### Step 2: Multiline query file
```bash
cat > /tmp/test_multiline.sql << 'EOF'
SELECT
    'Alice' AS name,
    25 AS age,
    'Engineer' AS role
EOF
tq query --file /tmp/test_multiline.sql
rm /tmp/test_multiline.sql
```

### Step 3: Query file with comments
```bash
cat > /tmp/test_comments.sql << 'EOF'
-- This is a comment
SELECT 1 AS test
-- Another comment
EOF
tq query --file /tmp/test_comments.sql
rm /tmp/test_comments.sql
```

### Step 4: Query file with JSON output
```bash
cat > /tmp/test.sql << 'EOF'
SELECT 'test' AS col
EOF
tq query --file /tmp/test.sql --format json
rm /tmp/test.sql
```

### Step 5: Nonexistent file
```bash
tq query --file /nonexistent/file.sql 2>&1
echo "Exit code: $?"
```

### Step 6: Empty file
```bash
touch /tmp/test_empty.sql
tq query --file /tmp/test_empty.sql 2>&1
rm /tmp/test_empty.sql
```

### Step 7: File with multiple statements (semicolon separated)
```bash
cat > /tmp/test_multi.sql << 'EOF'
SELECT 1;
SELECT 2;
EOF
tq query --file /tmp/test_multi.sql 2>&1
rm /tmp/test_multi.sql
```

## Pass/Fail Criteria

**PASS if:**
- Reads and executes SQL from file
- Multiline queries supported
- Comments are properly handled (ignored)
- Format flags work with --file
- Clear error for nonexistent file
- Clear error for empty file
- Exit codes are correct

**FAIL if:**
- Cannot read from file
- Multiline queries fail
- Comments cause errors
- Poor error messages
- Incorrect exit codes

## Notes

- --file is useful for storing complex queries
- Should support standard SQL comments (-- and /* */)
- Multiple statements (semicolon-separated) is future enhancement
- File path can be relative or absolute
- Consider supporting .sql extension detection
