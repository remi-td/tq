# TC092: Combined Feature - File Output with Atomic Transaction

**Test ID:** TC092  
**Feature:** Integration of Sprint 23 Features  
**Priority:** High  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify `--output` and `--atomic` flags work together correctly.

## Requirement Coverage

- Integration test for both features
- REQ-F1-01 + REQ-F2-01

## Test Procedure

```bash
# Create test table
tq query "CREATE VOLATILE TABLE test_combined (id INT, val VARCHAR(50))"

# Multi-statement batch with file output and atomic transaction
cat > /tmp/batch_atomic.sql << 'SQL'
INSERT INTO test_combined VALUES (1, 'First');
INSERT INTO test_combined VALUES (2, 'Second');
SELECT * FROM test_combined ORDER BY id;
SQL

# Execute with both flags
tq query --file /tmp/batch_atomic.sql --atomic --output /tmp/combined_results.txt -v

# Verify transaction committed
tq query "SELECT COUNT(*) FROM test_combined"
# Expected: 2

# Verify file contains SELECT results
cat /tmp/combined_results.txt
# Expected: Table with 2 rows

# Clean up
tq query "DROP TABLE test_combined"
rm -f /tmp/batch_atomic.sql /tmp/combined_results.txt
```

## Expected Results

- ✅ Transaction BEGIN/COMMIT in verbose output
- ✅ All statements execute successfully
- ✅ File contains query results
- ✅ Both features work without conflicts

## Acceptance Criteria

- No feature interaction bugs
- Results correctly written to file
- Transaction semantics preserved
