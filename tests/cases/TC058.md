# Test Case TC058: Result Paging - Vertical Paging with PageUp/PageDown Keys

## Purpose

Verify that PageUp and PageDown keys work for faster vertical navigation (page at a time instead of line at a time).

## Prerequisites

- tq REPL mode active
- Pager enabled
- Query results > 2 pages (at least 50+ lines)

## Test Procedure

### Step 1: Activate pager

```sql
tq> SELECT TOP 200 * FROM DBC.TablesV;
```

### Step 2: Navigate with PageDown

Press PageDown (or Ctrl+F)

**Expected:**
- Scrolls down one full page (terminal height minus status line)
- Status line updates to show new position
- Example: "Lines 1-25" → "Lines 26-50"

### Step 3: Navigate with PageUp

Press PageUp (or Ctrl+B)

**Expected:**
- Scrolls up one full page
- Returns to previous page view
- Status updates: "Lines 26-50" → "Lines 1-25"

### Step 4: Test rapid paging

Press PageDown multiple times rapidly (5 times)

**Expected:**
- Each press advances one page
- Reaches end of results
- Stops at last page

Press PageUp multiple times to return to top

**Expected:**
- Each press goes back one page
- Reaches first page
- Stops at top

## Verification

- [ ] PageDown scrolls one full page
- [ ] PageUp scrolls one full page
- [ ] Page size = terminal height - status line - margin
- [ ] Status line updates correctly
- [ ] Boundaries respected (stops at top/bottom)
- [ ] Works in combination with j/k (can mix navigation methods)

## Pass/Fail Criteria

**PASS:**
- PageUp/PageDown work for page-at-a-time scrolling
- Page size is appropriate (terminal height)
- Fast navigation through large results
- Boundaries handled correctly

**FAIL:**
- PageUp/PageDown don't work
- Page size is wrong (too small/large)
- Doesn't stop at boundaries (wraps or errors)
- Conflicts with j/k navigation

## Notes

Common keybindings:
- PageDown: PageDown key, Ctrl+F, Space (in some pagers)
- PageUp: PageUp key, Ctrl+B

Implementation should detect terminal height dynamically:
```rust
let (cols, rows) = crossterm::terminal::size()?;
let page_size = rows - 2; // Subtract status line and margin
```
