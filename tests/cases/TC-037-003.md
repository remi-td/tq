# TC-037-003: Edit Without Changes Skips Execution

## Metadata

| Field | Value |
|-------|-------|
| **Test ID** | TC-037-003 |
| **Title** | Edit Without Changes Skips Execution |
| **Category** | Unit + Integration + Interactive |
| **Priority** | High |
| **Feature** | Sprint 37 - `/edit` Command (AC-3) |
| **Test Type** | Unit + Integration + Interactive |
| **Created** | 2026-02-13 |

## Purpose

Verify that when the editor exits without modifying the file (or if the file is empty), no execution occurs and a clear message is displayed to the user.

## Acceptance Criteria Coverage

- **AC-3**: On exit without changes (or empty file), no execution occurs

## Scope

This test validates:
- Content comparison detects unmodified files
- No query execution when file unchanged
- Clear user message: "No changes made" or similar
- Empty file (all content deleted) skips execution
- Editor exit code 0 but no changes → skip execution
- No database query when content identical

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- expectrl crate for PTY testing
- Database connection available for interactive tests
- Mock editor scripts created
- Content comparison logic implemented

### Integration Test 1: Mock Editor No Changes

```rust
#[test]
fn test_edit_no_changes_skips_execution() {
    use std::fs;
    use std::process::Command;
    use tempfile::TempDir;

    // Create mock editor that exits without modifying file
    let temp_dir = TempDir::new().unwrap();
    let mock_editor = temp_dir.path().join("mock_editor_no_change.sh");
    fs::write(&mock_editor, r#"#!/bin/bash
# Exit without modifying file
exit 0
"#).unwrap();

    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        let mut perms = fs::metadata(&mock_editor).unwrap().permissions();
        perms.set_mode(0o755);
        fs::set_permissions(&mock_editor, perms).unwrap();
    }

    std::env::set_var("EDITOR", mock_editor.to_str().unwrap());

    let logon = std::env::var("TQ_LOGON").expect("TQ_LOGON not set");

    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("SELECT 1 AS original;")
        .arg("--command")
        .arg("/edit")
        .output()
        .expect("Failed to execute tq");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Verify message about no changes
    assert!(
        stdout.contains("No changes") ||
        stdout.contains("not modified") ||
        stdout.contains("unchanged"),
        "Should display message when no changes made"
    );

    // Verify no additional query execution (only original query result)
    let original_count = stdout.matches("original").count();
    assert_eq!(
        original_count, 1,
        "Should only see original query result once (no re-execution)"
    );

    std::env::remove_var("EDITOR");
}
```
