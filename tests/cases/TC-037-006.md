## Purpose

Verify that `/edit` works in full REPL mode only (not quick REPL), matching the behavior of `/repeat` from Sprint 36.

## Acceptance Criteria Coverage

- **AC-11**: Works in full REPL mode only (not quick REPL), matching `/repeat` behavior

## Scope

This test validates:
- `/edit` works in full REPL mode (`tq repl`)
- `/edit` unavailable in quick REPL mode (`tq --command`)
- `/edit` unavailable in batch mode (SQL from file)
- Consistent with `/repeat` behavior (Sprint 36)
- Clear error or silent ignore in non-REPL modes
- Mode detection logic correct

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- expectrl crate for PTY testing
- Database connection available for interactive tests
- Mode detection implementation complete

## Test Procedure

### Integration Test 1: Edit Works in Full REPL

```rust
#[test]
fn test_edit_works_in_full_repl() {
    use std::fs;
    use std::process::Command;
    use tempfile::TempDir;

    // Create mock editor
    let temp_dir = TempDir::new().unwrap();
    let mock_editor = temp_dir.path().join("mock_editor.sh");
    fs::write(&mock_editor, r#"#!/bin/bash
echo "-- modified" >> "$1"
exit 0
"#).unwrap();

    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        let mut perms = fs::metadata(&mock_editor).unwrap().permissions();
        perms.set_mode(0o755);
        fs::set_permissions(&mock_editor, perms).unwrap();
    }

    std::env::set_var("EDITOR", mock_editor.to_str().unwrap());

    let logon = std::env::var("TQ_LOGON").expect("TQ_LOGON not set");

    // Run in full REPL mode
    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("SELECT 1;")
        .arg("--command")
        .arg("/edit")
        .output()
        .expect("Failed to execute tq");

    let stdout = String::from_utf8_lossy(&output.stdout);

    // Should work in full REPL mode
    assert!(
        output.status.success(),
        "/edit should work in full REPL mode"
    );

    // Should not see error about mode restriction
    assert!(
        !stdout.contains("not available") && !stdout.contains("mode"),
        "/edit should not show mode restriction error in full REPL"
    );

    std::env::remove_var("EDITOR");
}
```

### Interactive Test 1: Edit Works in Full REPL Session

```rust
#[test]
#[ignore] // Requires database connection
fn test_edit_works_in_interactive_repl() {
    use std::fs;
    use tempfile::TempDir;

    // Create mock editor
    let temp_dir = TempDir::new().unwrap();
    let mock_editor = temp_dir.path().join("mock_editor.sh");
    fs::write(&mock_editor, r#"#!/bin/bash
exit 0
"#).unwrap();

    #[cfg(unix)]
    {
        use std::os::unix::fs::PermissionsExt;
        let mut perms = fs::metadata(&mock_editor).unwrap().permissions();
        perms.set_mode(0o755);
        fs::set_permissions(&mock_editor, perms).unwrap();
    }

    std::env::set_var("EDITOR", mock_editor.to_str().unwrap());

    // Spawn full REPL
    let mut repl = spawn_repl().expect("Failed to spawn REPL");

    // Execute query
    repl.send_line("SELECT 1;").unwrap();
    repl.expect("1").unwrap();

    // Execute /edit - should work
    repl.send_line("/edit").unwrap();

    // Should not see mode restriction error
    // (May see "No changes" since mock editor doesn't modify)
    let output = repl.read_until_prompt();
    assert!(
        !output.contains("not available") && !output.contains("only available"),
        "/edit should work in full REPL without mode restrictions"
    );

    std::env::remove_var("EDITOR");
}
```
