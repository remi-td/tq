# Test Case TC051: Tab Completion - Loading Indicator for Slow Metadata Queries

## Purpose

Verify that when metadata queries take time (>200ms), a visual loading indicator is shown to inform the user that completion is in progress.

## Prerequisites

- tq REPL mode active
- Live Teradata database connection
- Database with many tables (to create realistic query time)

## Test Procedure

### Step 1: First Tab press after FROM (metadata not cached)

```sql
tq> SELECT * FROM <TAB>
```

**Expected:**
- Loading indicator appears within 200ms: "Loading tables... ⠋" or similar
- Spinner animation (⠋ ⠙ ⠹ ⠸ ⠼ ⠴ ⠦ ⠧ ⠇ ⠏)
- Indicator disappears when metadata loaded
- Completion list appears

### Step 2: Subsequent Tab (cached)

```sql
tq> SELECT * FROM <TAB>
```

**Expected:**
- NO loading indicator (instant response)
- Completion list appears immediately

## Verification

- [ ] Loading indicator visible on first Tab
- [ ] Spinner animates (updates every ~100ms)
- [ ] Message is clear: "Loading tables..." or "Loading metadata..."
- [ ] Indicator disappears when load completes
- [ ] No indicator on cached access

## Pass/Fail Criteria

**PASS:**
- Loading indicator appears within 200ms of first Tab
- Indicator includes animation (spinner) or progress message
- User knows something is happening
- Indicator disappears when done

**FAIL:**
- No loading indicator (silent waiting)
- User presses Tab and gets no feedback
- Indicator doesn't disappear (stuck)
- Loading message is cryptic or unclear

## Notes

From sprint-8-ux-design.md:
> "Show spinner or loading message while fetching metadata"
> "Loading message appears after 200ms (avoid flash for fast queries)"

If query completes in <200ms, skip loading indicator entirely.
