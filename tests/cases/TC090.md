# TC090: Single Statement - No Transaction

**Test ID:** TC090  
**Feature:** Batch Mode Transaction Control (Sprint 23 - P1)  
**Priority:** Medium  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify --atomic flag has no effect on single statement queries (optimization).

## Test Procedure

```bash
# Single statement with --atomic
tq query "SELECT 1 AS single" --atomic -v 2>&1 | tee /tmp/single_atomic.txt

# Check if BEGIN TRANSACTION was issued
grep "BEGIN TRANSACTION" /tmp/single_atomic.txt && echo "Transaction started" || echo "No transaction (expected)"

# Clean up
rm -f /tmp/single_atomic.txt
```

## Expected Results

- ✅ Query executes normally
- ✅ NO "BEGIN TRANSACTION" message (single statements don't need transaction wrapper)
- ✅ Exit code 0

## Acceptance Criteria

- Single statements bypass transaction wrapper (optimization)
- --atomic flag silently ignored for single statements
- No performance overhead
