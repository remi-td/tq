# TC077: Output to File - Table Format

**Test ID:** TC077  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** Critical  
**Test Type:** Integration (with database)  
**Created:** 2026-01-23

---

## Objective

Verify that `--output <path>` flag writes query results to file in table format with atomic file operations.

## Requirement Coverage

- REQ-F1-01: `--output <path>` flag accepted
- REQ-F1-02: Supports table format output

## Test Procedure

```bash
# Clean environment
rm -f /tmp/tq_output_test.txt

# Execute query with file output
tq query "SELECT 1 AS id, 'Alice' AS name" --output /tmp/tq_output_test.txt

# Verify file exists and contains results
cat /tmp/tq_output_test.txt

# Clean up
rm -f /tmp/tq_output_test.txt
```

## Expected Results

- ✅ Exit code 0
- ✅ File created at specified path
- ✅ File contains ASCII table format
- ✅ Success message to stderr: "Wrote N rows to <path>"

## Acceptance Criteria

- File format matches table specification
- No partial files on error
- Atomic write operation (temp + rename)
