# TC089: Nested Transaction Detection

**Test ID:** TC089  
**Feature:** Batch Mode Transaction Control (Sprint 23 - P1)  
**Priority:** High  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify error when user's SQL contains explicit BEGIN TRANSACTION conflicting with --atomic.

## Requirement Coverage

- REQ-F2-07: Error: Nested transaction detection

## Test Procedure

```bash
# SQL with explicit transaction control
cat > /tmp/test_nested.sql << 'SQL'
BEGIN TRANSACTION;
INSERT INTO some_table VALUES (1, 'Test');
COMMIT;
SQL

# Try to run with --atomic
tq query --file /tmp/test_nested.sql --atomic 2>&1

# Expected: Error message explaining conflict
# Clean up
rm -f /tmp/test_nested.sql
```

## Expected Results

- ✅ Exit code non-zero
- ✅ Error message: "Cannot use --atomic with SQL containing explicit BEGIN TRANSACTION"
- ✅ Suggestion: "Either remove --atomic or remove BEGIN/COMMIT from your SQL"
- ✅ No execution attempted

## Acceptance Criteria

- Conflict detected before execution
- Clear error message with workaround
- Prevents Teradata nested transaction error
