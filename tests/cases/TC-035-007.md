# TC-035-007: Error Handling - Invalid TOML and File Errors

## Metadata

| Field | Value |

| **Test ID** | TC-035-007 |
| **Title** | Error Handling - Invalid TOML and File Errors |

| **Created** | 2026-02-13 |

## Purpose

Verify comprehensive error handling for project configuration: invalid TOML syntax, file permission errors, malformed profiles, and other error conditions.

## Acceptance Criteria Coverage

- **AC-7**: Comprehensive error handling (invalid TOML, permission errors) - Complete error handling

## Scope

This test validates:
- Invalid TOML syntax produces clear error with line/column
- Missing required fields produce clear errors
- Type mismatches produce clear errors
- File not found is handled gracefully (not an error - project config is optional)
- Permission denied produces clear error with fix suggestion
- Malformed profile values produce clear errors
- Error messages include file path and helpful guidance

## Prerequisites

- Rust test framework available
- tempfile crate available
- Error handling implementation complete

## Test Procedure

### Unit Test Implementation:

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::fs;
    use tempfile::TempDir;

    #[test]
    fn test_invalid_toml_syntax_error() {
        let invalid_toml = r#"
            [profiles.dev]
            host: "dev.company.com"  # Wrong: should use '=' not ':'
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        assert!(result.is_err(), "Invalid TOML should produce error");
        let error_msg = result.unwrap_err().to_string();
        assert!(
            error_msg.contains("expected") || error_msg.contains("="),
            "Error should mention syntax issue: {}",
            error_msg
        );
    }

    #[test]
    fn test_invalid_toml_missing_bracket() {
        let invalid_toml = r#"
            profiles.dev]  # Missing opening bracket
            host = "dev.company.com"
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        assert!(result.is_err(), "Missing bracket should produce error");
    }

    #[test]
    fn test_invalid_type_boolean_as_string() {
        let invalid_toml = r#"
            [defaults]
            timing = "yes"  # Should be boolean true/false
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        assert!(result.is_err(), "Type mismatch should produce error");
        let error_msg = result.unwrap_err().to_string();
        assert!(
            error_msg.contains("invalid type") || error_msg.contains("boolean"),
            "Error should mention type mismatch: {}",
            error_msg
        );
    }

    #[test]
    fn test_invalid_type_port_as_string() {
        let invalid_toml = r#"
            [profiles.dev]
            host = "dev.company.com"
            port = "one thousand twenty five"  # Should be integer
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        assert!(result.is_err(), "Non-integer port should produce error");
    }

    #[test]
    fn test_invalid_profile_empty_host() {
        // Host is the only required field for a profile
        let invalid_toml = r#"
            [profiles.dev]
            # No host field - might be valid TOML but invalid profile
            database = "mydb"
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        // TOML parsing succeeds (empty host is valid TOML)
        // But profile validation should catch this later
        if result.is_ok() {
            let config = result.unwrap();
            let dev_profile = config.profiles.get("dev").unwrap();

            // Validation function should reject profiles without host
            assert!(
                validate_profile(dev_profile).is_err(),
                "Profile without host should be invalid"
            );
        }
    }

    #[test]
    fn test_file_not_found_not_an_error() {
        let temp_dir = TempDir::new().unwrap();
        let nonexistent_path = temp_dir.path().join("nonexistent.toml");

        // Attempt to load non-existent project config
        let result = load_project_config_optional(&nonexistent_path);

        // Should return Ok(None), not an error
        assert!(
            result.is_ok(),
            "Non-existent project config should not be an error"
        );
        assert!(
            result.unwrap().is_none(),
            "Should return None for non-existent file"
        );
    }

    #[test]
    fn test_file_permission_denied() {
        let temp_dir = TempDir::new().unwrap();
        let config_path = temp_dir.path().join(".tq.toml");
        fs::write(&config_path, "[defaults]\nformat = \"json\"").unwrap();

        #[cfg(unix)]
        {
            use std::os::unix::fs::PermissionsExt;

            // Remove all permissions
            let mut perms = fs::metadata(&config_path).unwrap().permissions();
            perms.set_mode(0o000);
            fs::set_permissions(&config_path, perms).unwrap();

            // Attempt to load
            let result = load_config_from_file(&config_path);

            assert!(
                result.is_err(),
                "Permission denied should produce error"
            );
            let error_msg = result.unwrap_err().to_string();
            assert!(
                error_msg.contains("permission") || error_msg.contains("denied"),
                "Error should mention permission denied: {}",
                error_msg
            );

            // Restore permissions for cleanup
            let mut perms = fs::metadata(&config_path).unwrap().permissions();
            perms.set_mode(0o644);
            fs::set_permissions(&config_path, perms).unwrap();
        }

        #[cfg(not(unix))]
        {
            println!("Skipping permission test on non-Unix platform");
        }
    }

    #[test]
    fn test_file_corrupt_utf8() {
        let temp_dir = TempDir::new().unwrap();
        let config_path = temp_dir.path().join(".tq.toml");

        // Write invalid UTF-8 bytes
        let invalid_utf8 = vec![0xFF, 0xFE, 0xFD];
        fs::write(&config_path, invalid_utf8).unwrap();

        let result = load_config_from_file(&config_path);

        assert!(result.is_err(), "Invalid UTF-8 should produce error");
        let error_msg = result.unwrap_err().to_string();
        assert!(
            error_msg.contains("UTF-8") || error_msg.contains("encoding"),
            "Error should mention encoding issue: {}",
            error_msg
        );
    }

    #[test]
    fn test_invalid_logmech_value() {
        // logmech should be one of: TD2, LDAP, KRB5, TDNEGO
        let invalid_toml = r#"
            [profiles.dev]
            host = "dev.company.com"
            logmech = "INVALID_MECHANISM"
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        // TOML parsing succeeds (any string is valid TOML)
        // But validation should catch invalid logmech
        if result.is_ok() {
            let config = result.unwrap();
            let dev_profile = config.profiles.get("dev").unwrap();

            assert!(
                validate_profile(dev_profile).is_err(),
                "Invalid logmech should be rejected"
            );
        }
    }

    #[test]
    fn test_invalid_timeout_format() {
        let invalid_toml = r#"
            [profiles.dev]
            host = "dev.company.com"
            timeout = "not-a-duration"
        "#;

        let result: Result<Config, _> = toml::from_str(invalid_toml);

        // TOML parsing succeeds
        // But timeout parsing/validation should catch invalid format
        if result.is_ok() {
            let config = result.unwrap();
            let dev_profile = config.profiles.get("dev").unwrap();

            // When attempting to parse timeout
            let timeout_result = parse_duration(dev_profile.timeout.as_ref().unwrap());
            assert!(
                timeout_result.is_err(),
                "Invalid timeout format should be rejected"
            );
        }
    }
}
```

### Integration Test Implementation:

```rust
#[cfg(test)]
mod integration_tests {
    use std::fs;
    use std::process::Command;
    use tempfile::TempDir;

    #[test]
    fn test_invalid_toml_cli_error_message() {
        let temp_dir = TempDir::new().unwrap();
        let config_path = temp_dir.path().join(".tq.toml");

        // Write invalid TOML
        let invalid_toml = r#"
            [profiles.dev]
            host: "dev.company.com"  # Wrong syntax
        "#;
        fs::write(&config_path, invalid_toml).unwrap();

        // Run tq from project directory
        let output = Command::new("cargo")
            .args(&["run", "--", "profiles"])
            .current_dir(temp_dir.path())
            .output()
            .expect("Failed to execute tq");

        // Should fail with clear error
        assert!(
            !output.status.success(),
            "Should fail with invalid TOML"
        );

        let stderr = String::from_utf8_lossy(&output.stderr);

        // Verify error message quality
        assert!(
            stderr.contains("parse") || stderr.contains("TOML"),
            "Error should mention TOML parsing: {}",
            stderr
        );
        assert!(
            stderr.contains(".tq.toml") || stderr.contains(config_path.to_str().unwrap()),
            "Error should mention file path: {}",
            stderr
        );
        // Bonus: line number
        if stderr.contains("line") {
            assert!(true, "Error includes line number");
        }
    }

    #[test]
    fn test_permission_denied_cli_error_message() {
        #[cfg(unix)]
        {
            let temp_dir = TempDir::new().unwrap();
            let config_path = temp_dir.path().join(".tq.toml");

            // Write valid config
            fs::write(&config_path, "[defaults]\nformat = \"json\"").unwrap();

            // Remove read permission
            use std::os::unix::fs::PermissionsExt;
            let mut perms = fs::metadata(&config_path).unwrap().permissions();
            perms.set_mode(0o000);
            fs::set_permissions(&config_path, perms).unwrap();

            // Run tq
            let output = Command::new("cargo")
                .args(&["run", "--", "profiles"])
                .current_dir(temp_dir.path())
                .output()
                .expect("Failed to execute tq");

            // Should fail with clear error
            assert!(!output.status.success(), "Should fail with permission denied");

            let stderr = String::from_utf8_lossy(&output.stderr);
            assert!(
                stderr.contains("permission") || stderr.contains("denied"),
                "Error should mention permission denied: {}",
                stderr
            );
            assert!(
                stderr.contains(".tq.toml"),
                "Error should mention file: {}",
                stderr
            );

            // Bonus: fix suggestion
            if stderr.contains("chmod") {
                assert!(true, "Error includes fix suggestion");
            }

            // Restore permissions for cleanup
            let mut perms = fs::metadata(&config_path).unwrap().permissions();
            perms.set_mode(0o644);
            fs::set_permissions(&config_path, perms).unwrap();
        }

        #[cfg(not(unix))]
        {
            println!("Skipping permission test on non-Unix platform");
        }
    }

    #[test]
    fn test_missing_project_config_not_an_error() {
        let temp_dir = TempDir::new().unwrap();
        // No .tq.toml file

        // Run tq profiles (should work without project config)
        let output = Command::new("cargo")
            .args(&["run", "--", "profiles"])
            .current_dir(temp_dir.path())
            .env("HOME", "/nonexistent") // No user config either
            .output()
            .expect("Failed to execute tq");

        // Should succeed (no configs is valid)
        assert!(
            output.status.success(),
            "Should succeed without project config"
        );

        let stdout = String::from_utf8_lossy(&output.stdout);
        assert!(
            stdout.contains("No profiles") || stdout.contains("no profiles"),
            "Should indicate no profiles configured"
        );
    }
}
```
