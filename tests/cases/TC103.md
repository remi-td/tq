## Overview

Sprint 67 introduced `write_value_with_highlights`, which renders a cell value with matched
substrings wrapped in ANSI reverse-video escape sequences (`\x1b[7m` ... `\x1b[27m`). This was
strategy-classified REQUIRED in Sprint 67 but not authored — the strategy noted that ANSI bytes
were "confirmed by source grep." Sprint 68 closes that gap with a proper byte-assertion unit test
that writes into a `Vec<u8>` and inspects the raw bytes.

The two ANSI sequences to assert:
- `\x1b[7m` — CSI code for `SetAttribute(Attribute::Reverse)` (highlight start)
- `\x1b[27m` — CSI code for `SetAttribute(Attribute::NoReverse)` (highlight end)

## TC103-U01: `write_value_with_highlights_emits_reverse_video`

**Requirement:** AC-OBJ2-2 — the function wraps matched substrings with `Attribute::Reverse`
escape sequences and writes the non-matching prefix/suffix unmodified.

**Location:** `src/commands/repl/pager.rs`, `#[cfg(test)]` module

**BLOCKED condition:** Never blocked. Pure in-memory unit test.

### Function Signature

```rust
fn write_value_with_highlights(
    &self,
    stdout: &mut impl Write,
    value: &str,
    matches: &[(usize, usize)],
) -> io::Result<()>
```

This is a private method on `Pager`. It is accessible from the `#[cfg(test)]` module in the same
file via `use super::*`.

### Fixture

- `value = "fooBAR baz"` (10 bytes; bytes 3..6 = `"BAR"`)
- `matches = &[(3, 6)]` — match span: bytes 3 (inclusive) to 6 (exclusive)
- `writer = Vec::<u8>::new()`

### Expected Output Structure

The rendered bytes must contain, in order:
1. `"foo"` (non-matching prefix, written as-is)
2. `\x1b[7m` (reverse-video on — 4 bytes)
3. `"BAR"` (matched substring, rendered inside highlight)
4. `\x1b[27m` (reverse-video off — 5 bytes)
5. `" baz"` (non-matching suffix, written as-is)

### Test Code

```rust
#[test]
fn write_value_with_highlights_emits_reverse_video() {
    // Construct a minimal pager. write_value_with_highlights only needs &self
    // for method dispatch; it does not access self fields.
    // Reuse the existing make_pager_with_data helper or construct directly.
    let pager = make_pager_with_data(1, 10); // 1 row, page_size 10

    let value = "fooBAR baz";
    let matches = &[(3usize, 6usize)]; // "BAR" at bytes 3..6
    let mut writer: Vec<u8> = Vec::new();

    pager
        .write_value_with_highlights(&mut writer, value, matches)
        .expect("write_value_with_highlights must not return Err");

    let bytes = &writer;

    // Assert \x1b[7m (Attribute::Reverse) is present
    let has_reverse = bytes.windows(4).any(|w| w == b"\x1b[7m");
    assert!(
        has_reverse,
        "Output must contain \\x1b[7m (Attribute::Reverse); got: {:?}",
        String::from_utf8_lossy(bytes)
    );

    // Assert \x1b[27m (Attribute::NoReverse) is present
    let has_no_reverse = bytes.windows(5).any(|w| w == b"\x1b[27m");
    assert!(
        has_no_reverse,
        "Output must contain \\x1b[27m (Attribute::NoReverse); got: {:?}",
        String::from_utf8_lossy(bytes)
    );

    // Assert "foo" appears before \x1b[7m
    let reverse_pos = bytes
        .windows(4)
        .position(|w| w == b"\x1b[7m")
        .expect("\\x1b[7m must be present");
    let foo_pos = bytes
        .windows(3)
        .position(|w| w == b"foo")
        .expect("'foo' must appear in output");
    assert!(
        foo_pos < reverse_pos,
        "'foo' (pos {}) must appear before \\x1b[7m (pos {})",
        foo_pos,
        reverse_pos
    );

    // Assert "BAR" appears between the two escape sequences
    let bar_pos = bytes
        .windows(3)
        .position(|w| w == b"BAR")
        .expect("'BAR' must appear in output");
    assert!(
        bar_pos > reverse_pos,
        "'BAR' (pos {}) must appear after \\x1b[7m (pos {})",
        bar_pos,
        reverse_pos
    );

    let no_reverse_pos = bytes
        .windows(5)
        .position(|w| w == b"\x1b[27m")
        .expect("\\x1b[27m must be present");
    assert!(
        bar_pos < no_reverse_pos,
        "'BAR' (pos {}) must appear before \\x1b[27m (pos {})",
        bar_pos,
        no_reverse_pos
    );

    // Assert " baz" appears after \x1b[27m
    let baz_pos = bytes
        .windows(4)
        .position(|w| w == b" baz")
        .expect("' baz' must appear in output");
    assert!(
        baz_pos > no_reverse_pos,
        "' baz' (pos {}) must appear after \\x1b[27m (pos {})",
        baz_pos,
        no_reverse_pos
    );
}
```

**Notes for implementation:**
- If `make_pager_with_data` does not exist in the test module, replace with:
  ```rust
  let result = QueryResult { columns: vec!["col"], rows: vec![vec![Value::String("x".into())]], ..Default::default() };
  let pager = Pager::new(&result, &PagerConfig::default());
  ```
- The function signature takes `&self`, so any valid `Pager` instance suffices. The test only
  exercises the writer path; `self` is used only for method dispatch.
- Crossterm CSI codes are deterministic on any platform when writing to a `Vec<u8>`. The byte
  values `\x1b[7m` and `\x1b[27m` are the standard ANSI codes for Reverse and NoReverse.

### Pass Criteria

1. `writer` contains `\x1b[7m` (4 bytes).
2. `writer` contains `\x1b[27m` (5 bytes).
3. `"foo"` appears before `\x1b[7m`.
4. `"BAR"` appears between `\x1b[7m` and `\x1b[27m`.
5. `" baz"` appears after `\x1b[27m`.

**Run command:**
```bash
cargo test --lib write_value_with_highlights_emits_reverse_video
```
