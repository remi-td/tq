## Purpose

Verify end-to-end that the three new CLI commands connect to Teradata, execute their queries, and render output. Uses DBC system views as stable test targets (always present, always readable with normal Teradata access).

## Acceptance Criteria Coverage

- **AC-1**: `tq describe <table>` outputs column info in table/CSV/JSON formats
- **AC-2**: `tq list databases` outputs database list
- **AC-3**: `tq list tables [pattern]` outputs table list with optional glob filter
- **AC-4**: `tq list views` outputs view list
- **AC-5**: `tq show-indexes <table>` outputs index information

## Prerequisites

- Teradata database accessible
- `TQ_LOGON` environment variable set (e.g., `user:pass@host:1025/DBC`)
- `tq` binary compiled (`cargo build`)

## Test Procedure

### Test Implementation (in `tests/cli_commands_46.rs`)

```rust
use std::process::Command;

fn tq_bin() -> std::path::PathBuf {
    let mut path = std::env::current_exe().expect("current exe path");
    path.pop();
    path.pop();
    path.push("tq");
    path
}

fn logon() -> String {
    std::env::var("TQ_LOGON").expect("TQ_LOGON must be set for integration tests")
}

// TC-046-006-A: tq describe dbc.tables — column info in table format
#[test]
#[ignore]
fn test_describe_dbc_tables() {
    let output = Command::new(tq_bin())
        .args(["-l", &logon(), "describe", "dbc.tables"])
        .output()
        .expect("Failed to execute tq describe");

    let stdout = String::from_utf8_lossy(&output.stdout);
    let stderr = String::from_utf8_lossy(&output.stderr);

    assert!(
        output.status.success(),
        "tq describe dbc.tables failed\nstdout: {}\nstderr: {}",
        stdout, stderr
    );
    // Should contain column names — DBC.Tables has TableName, DatabaseName, etc.
    assert!(
        stdout.contains("TableName") || stdout.contains("tablename") || stdout.contains("Column"),
        "Expected column names in output\nstdout: {}", stdout
    );
}

// TC-046-006-B: tq describe dbc.tables --format json
#[test]
#[ignore]
fn test_describe_dbc_tables_json() {
    let output = Command::new(tq_bin())
        .args(["-l", &logon(), "describe", "--format", "json", "dbc.tables"])
        .output()
        .expect("Failed to execute tq describe --format json");

    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(
        output.status.success(),
        "tq describe --format json failed\nstdout: {}", stdout
    );
    // JSON output should be valid JSON starting with [ or {
    let trimmed = stdout.trim();
    assert!(
        trimmed.starts_with('[') || trimmed.starts_with('{'),
        "Expected JSON output, got: {}", stdout
    );
}

// TC-046-006-C: tq list databases
#[test]
#[ignore]
```

## Pass/Fail Criteria

**PASS if:**
- All 5 tests exit 0
- Output is non-empty and matches expected format
- No "command not found" or argument parsing errors

**FAIL if:**
- Exit code non-zero — command not implemented or SQL error
- Empty output — query returned no rows or command exited before rendering
- "unknown command" in stderr — command not registered in `src/main.rs`

**BLOCKED if:**
- `TQ_LOGON` not set or database unreachable

- `tq list tables` without a database qualifier uses the default database from `TQ_LOGON`
- `tq show-indexes dbc.tables` queries `DBC.IndicesV` — must have SELECT privilege
