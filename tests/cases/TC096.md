# TC096: `/sessions --watch` Interval Parsing Unit Tests

**Sprint:** 65
**Feature:** `/sessions --watch` with configurable auto-refresh interval
**Component:** `src/commands/watch.rs` — `parse_watch_args()` function
**Test Type:** Unit tests (no DB, no PTY)
**Related Strategy:** `tests/strategy/sprint-65-strategy.md` AC-1 through AC-3, AC-9

---

## Overview

These unit tests live inside `src/commands/watch.rs` under `#[cfg(test)]`. They validate
the `parse_watch_args()` function for all boundary conditions required by the acceptance
criteria. The function signature is:

```rust
pub fn parse_watch_args(args: &[&str], default_interval: u64) -> Option<u64>
```

The spec requires: default = 6 s, minimum = 1 s, maximum = 3600 s. Values outside
`[1, 3600]` must be clamped or rejected per AC-3. The current implementation uses
`clamp(2, 300)` — these tests document the **spec-correct** expected values and will
fail until the architect corrects the bounds.

## TC096-E: `--interval 0` or negative — rejected (AC-3)

**Requirement:** AC-3 — 0 and negative values are out of spec. Because `u64` cannot
represent negative values, `0` is the meaningful boundary. The spec says minimum is 1 s,
so 0 must not succeed. Since `parse_watch_args` accepts `u64`, passing "0" as a string
that parses to `0u64` should be clamped to 1 (spec says minimum=1) or ignored, falling
back to the default.

```rust
#[test]
fn watch_parse_zero_interval_clamped_to_minimum() {
    // "0" parses as u64 = 0; spec minimum is 1, so result must be >= 1
    let result = parse_watch_args(&["--watch", "--interval", "0"], 6);
    // Either clamped to 1 (Some(1)) or ignored and falls back to default (Some(6)).
    // Must NOT be Some(0).
    match result {
        Some(v) => assert!(v >= 1, "interval 0 must produce at least 1 s, got {}", v),
        None => panic!("--watch is present; result must be Some(_)"),
    }
}
```

**Pass criteria:** `Some(v)` where `v >= 1`.

**Requirement:** AC-3 — values above 3600 must be clamped (not silently accepted)


**Pass criteria:** `Some(v)` where `v <= 3600`.
