## Purpose

Verify that column name completion handles error conditions gracefully without crashing the REPL.

## Scope

This test validates:
- Table not found in metadata
- Permission denied to DBC.ColumnsV
- Timeout during column metadata query
- No table context detected
- Ambiguous table context
- Empty column list (unusual but possible)
- REPL continues after errors

## Prerequisites

- tq binary built in release mode
- REPL mode functional
- Ability to simulate various error conditions

## Test Procedure

### Step 1: Test with nonexistent table
```sql
tq> SELECT * FROM nonexistent_table WHERE <TAB>
```

**Expected behavior:**
- Error: "Table 'nonexistent_table' not found"
- Helpful message
- REPL continues

### Step 2: Test with no table context
```sql
tq> SELECT <TAB>
```
(No FROM clause present)

**Expected behavior:**
- Message: "(Cannot determine table context. Complete table name first.)"
- No error, just informative
- REPL continues

### Step 3: Test with permission denied (if simulatable)
```sql
# Connect to database where user lacks SELECT on DBC.ColumnsV
tq> SELECT * FROM some_table WHERE <TAB>
```

**Expected behavior:**
- Warning: "Cannot load columns for 'some_table' (permission denied)"
- Suggestion to contact DBA
- REPL continues

### Step 4: Test with slow metadata query
```sql
# Use slow connection if available
tq> SELECT * FROM large_table WHERE <TAB>
```

**Expected behavior:**
- "Loading columns for 'large_table'..." message
- If exceeds 300ms timeout: "Column list query timed out"
- REPL doesn't hang

### Step 5: Test ambiguous context (complex query)
```sql
tq> SELECT * FROM (SELECT * FROM employees) WHERE <TAB>
```

**Expected behavior:**
- May show: "(Cannot determine table context)" for subquery
- This is acceptable v1 limitation
- REPL continues

### Step 6: Verify REPL still works after errors
```sql
# After any error above
tq> SELECT 1 AS test;
```

**Expected behavior:**
- Query executes successfully
- No corruption from column completion errors

### Step 7: Test table name in FROM but metadata load fails
```sql
# Table exists but columns can't load
tq> SELECT * FROM employees WHERE <TAB>
# (Simulate failure during column fetch)
```

**Expected behavior:**
- Clear error message
- Doesn't crash
- Can retry

## Pass/Fail Criteria

**PASS if:**
- All error conditions handled gracefully
- Clear, actionable error messages
- REPL never crashes
- Can continue using REPL after errors
- No table context handled appropriately
- Timeouts prevent hanging
- Helpful suggestions provided

**FAIL if:**
- REPL crashes on any error
- Hangs on slow queries
- Unclear error messages
- REPL corrupted after errors
- No recovery possible

## Notes

- Error handling critical for production use
- Many possible failure modes with database metadata
- Graceful degradation: completion unavailable but REPL works
- Some errors difficult to simulate (may need mock database)
- Subquery limitation acceptable for v1 - document clearly
