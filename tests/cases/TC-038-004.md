# TC-038-004: Sysconfig REPL Command Execution and Alias

## Metadata

| Field | Value |

| **Category** | Interactive |

| **Test Type** | Interactive (expectrl, PTY) |
| **Created** | 2026-02-24 |

## Purpose

Validate the end-to-end REPL execution of `/sysconfig`:
- The command executes successfully and displays system configuration data
- Output includes AMP count and system version
- The `/sc` alias produces identical output
- REPL returns to prompt after execution (no hang)

## Acceptance Criteria Coverage

- **AC-1**: `/sysconfig` queries DBC.DBCInfoV
- **AC-2**: Displays AMP count via HASHAMP()+1
- **AC-3**: Displays version, node count, and AMP/PE topology
- **AC-9**: `/sc` short alias available

## Prerequisites

- Live Teradata database configured in `.env`
- `expectrl` crate (existing test framework)
- `tq` binary built
- SELECT privilege on DBC system views

## Test Procedure

**Location:** `tests/interactive_tests.rs` (append)

```rust
// ============================================================================
// Sprint 38: /sysconfig - Execution Tests
// ============================================================================

#[test]
#[ignore] // Requires live database: cargo test -- --ignored --test-threads=1
fn test_sysconfig_repl_command_executes_and_shows_amp_count() {
    let mut p = spawn_tq_repl();

    p.expect("Connected to").expect("Failed to connect to database");
    std::thread::sleep(Duration::from_millis(1000));

    p.send_line("/sysconfig").expect("Failed to send /sysconfig");
    std::thread::sleep(Duration::from_millis(3000)); // Allow query execution time

    let output = p.read_until_prompt().unwrap_or_default();
    let output_str = String::from_utf8_lossy(&output);

    // Output should contain AMP count or AMP-related information
    assert!(
        output_str.to_lowercase().contains("amp") || output_str.contains("AMP"),
        "/sysconfig must display AMP count information. Got: {}",
        output_str
    );

    p.send_line("/quit").expect("Failed to quit REPL");
    std::thread::sleep(Duration::from_millis(500));
}

#[test]
#[ignore] // Requires live database: cargo test -- --ignored --test-threads=1
fn test_sysconfig_repl_command_shows_version() {
    let mut p = spawn_tq_repl();

    p.expect("Connected to").expect("Failed to connect to database");
    std::thread::sleep(Duration::from_millis(1000));

    p.send_line("/sysconfig").expect("Failed to send /sysconfig");
    std::thread::sleep(Duration::from_millis(3000));

    let output = p.read_until_prompt().unwrap_or_default();
    let output_str = String::from_utf8_lossy(&output);

    // Output should contain a version string (numbers separated by dots)
    let has_version = output_str.contains("version") ||
                      output_str.contains("Version") ||
                      output_str.contains("VERSION") ||
                      // Version numbers typically look like "17.20" or "16.00"
                      output_str.chars().filter(|c| *c == '.').count() >= 1;

    assert!(
        has_version,
        "/sysconfig must display system version information. Got: {}",
        output_str
    );

    p.send_line("/quit").expect("Failed to quit REPL");
    std::thread::sleep(Duration::from_millis(500));
}

#[test]
#[ignore] // Requires live database: cargo test -- --ignored --test-threads=1
fn test_sysconfig_alias_sc_produces_output() {
    // /sc alias must work identically to /sysconfig
    let mut p = spawn_tq_repl();

    p.expect("Connected to").expect("Failed to connect to database");
    std::thread::sleep(Duration::from_millis(1000));

    p.send_line("/sc").expect("Failed to send /sc alias");
    std::thread::sleep(Duration::from_millis(3000));

    let output = p.read_until_prompt().unwrap_or_default();
    let output_str = String::from_utf8_lossy(&output);

    // /sc should produce the same type of output as /sysconfig
    // Must not show "Unknown command" or similar error
    assert!(
        !output_str.to_lowercase().contains("unknown command") &&
        !output_str.to_lowercase().contains("not found") &&
        !output_str.is_empty(),
        "/sc alias must execute as /sysconfig, not produce error. Got: {}",
        output_str
    );

    p.send_line("/quit").expect("Failed to quit REPL");
    std::thread::sleep(Duration::from_millis(500));
}
```

## Expected Results

- `/sysconfig` executes and displays system configuration including AMP count
- `/sysconfig` output includes version string
- `/sc` alias produces output without "unknown command" error
- REPL returns to prompt after each command (no hang)

## Pass/Fail Criteria

**PASS if:**
- `/sysconfig` output contains "AMP" (from AMP count display)
- `/sysconfig` output contains version information
- `/sc` alias produces data output (not an error)
- REPL prompt returns after each command

**FAIL if:**
- `/sysconfig` produces "unknown command" error
- `/sysconfig` hangs (does not return to prompt)
- Output is completely empty (no data)
- `/sc` produces "unknown command" error
