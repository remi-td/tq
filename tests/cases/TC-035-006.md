# TC-035-006: Profile Name Conflicts and Field Precedence

## Metadata

| Field | Value |
|-------|-------|
| **Test ID** | TC-035-006 |
| **Title** | Profile Name Conflicts and Field Precedence |
| **Category** | Unit + Integration Test |
| **Priority** | High |
| **Feature** | Sprint 35 - Project Configuration (AC-6) |
| **Test Type** | Unit + Integration |
| **Created** | 2026-02-13 |

## Purpose

Verify that when a profile exists in both user and project configs with the same name, project profile fields take precedence over user profile fields, with proper field-level merging.

## Acceptance Criteria Coverage

- **AC-6**: Project profiles take precedence over user profiles with same name - Field-level precedence

## Scope

This test validates:
- Profile name conflict resolution (project wins)
- Field-level merging (project field overrides user field)
- Field inheritance (user fields preserved when not in project)
- Multiple conflicting profiles handled correctly
- No data loss during merge
- Clear indication of field sources in output

## Prerequisites

- Rust test framework available
- Config merging implementation exists
- Profile resolution implementation exists

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_profile_conflict_project_host_overrides() {
        // User: dev profile with host = "localhost"
        let mut user_profiles = HashMap::new();
        user_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("localhost".to_string()),
                database: Some("local_db".to_string()),
                user: Some("alice".to_string()),
                ..Default::default()
            },
        );

        // Project: dev profile with host = "dev.company.com"
        let mut project_profiles = HashMap::new();
        project_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("dev.company.com".to_string()),
                database: Some("shared_dev".to_string()),
                ..Default::default()
            },
        );

        let merged = merge_profile_fields(
            user_profiles.get("dev").unwrap(),
            project_profiles.get("dev"),
        );

        // Project host should win
        assert_eq!(merged.host.as_ref().unwrap(), "dev.company.com");
        assert_eq!(merged.database.as_ref().unwrap(), "shared_dev");
        // User field should be inherited
        assert_eq!(merged.user.as_ref().unwrap(), "alice");
    }

    #[test]
    fn test_profile_conflict_user_credentials_inherited() {
        // User: dev profile with credentials
        let mut user_profiles = HashMap::new();
        user_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("localhost".to_string()),
                user: Some("alice".to_string()),
                password_file: Some("~/.tq/passwords/dev".to_string()),
                ..Default::default()
            },
        );

        // Project: dev profile WITHOUT credentials (intentional for security)
        let mut project_profiles = HashMap::new();
        project_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("dev.company.com".to_string()),
                database: Some("shared_dev".to_string()),
                // No user, no password_file
                ..Default::default()
            },
        );

        let merged = merge_profile_fields(
            user_profiles.get("dev").unwrap(),
            project_profiles.get("dev"),
        );

        // Project metadata wins
        assert_eq!(merged.host.as_ref().unwrap(), "dev.company.com");
        // User credentials inherited
        assert_eq!(merged.user.as_ref().unwrap(), "alice");
        assert_eq!(
            merged.password_file.as_ref().unwrap(),
            "~/.tq/passwords/dev"
        );
    }
```

### Integration Test Implementation:

```rust
#[cfg(test)]
mod integration_tests {
    use std::fs;
    use std::process::Command;
    use tempfile::TempDir;

    #[test]
    fn test_profile_conflict_integration() {
        // Create both configs with conflicting "dev" profile
        let temp_dir = TempDir::new().unwrap();

        // User config
        let user_config_dir = temp_dir.path().join(".tq");
        fs::create_dir(&user_config_dir).unwrap();
        let user_config_path = user_config_dir.join("config.toml");
        let user_config = r#"
            [profiles.dev]
            host = "localhost"
            port = 1025
            database = "local_db"
            user = "alice"
        "#;
        fs::write(&user_config_path, user_config).unwrap();

        // Project config
        let project_config_path = temp_dir.path().join(".tq.toml");
        let project_config = r#"
            [profiles.dev]
            host = "dev.company.com"
            database = "shared_dev"
            logmech = "LDAP"
        "#;
        fs::write(&project_config_path, project_config).unwrap();

        // Run tq profiles
        let output = Command::new("cargo")
            .args(&["run", "--", "profiles"])
            .current_dir(temp_dir.path())
            .env("HOME", temp_dir.path())
            .output()
            .expect("Failed to execute tq profiles");

        let stdout = String::from_utf8_lossy(&output.stdout);

        assert!(output.status.success());

        // Verify merged profile shows correct values
        assert!(
            stdout.contains("dev.company.com"),
            "Should show project host"
        );
        assert!(
            !stdout.contains("localhost") || stdout.contains("[user]"),
            "localhost should be overridden or marked as user"
        );
        assert!(
            stdout.contains("shared_dev"),
            "Should show project database"
        );
        assert!(stdout.contains("alice"), "Should show user username");
        assert!(stdout.contains("LDAP"), "Should show project logmech");
    }
}
```
