# TC-036-003: Invalid Project Config Warning

## Purpose

Verify that when `.tq.toml` contains invalid TOML syntax, the tool produces a clear warning to stderr with file path and error details, then continues operation gracefully (non-blocking, graceful degradation).

## Acceptance Criteria Coverage

- **AC-5**: Invalid `.tq.toml` produces stderr warning with file path and error details

## Scope

This test validates:
- Invalid TOML syntax detected (parse error)
- Warning message sent to stderr (not stdout)
- Warning format includes:
  - "Warning:" prefix
  - "Invalid project config" description
  - Full file path to `.tq.toml`
  - Parse error details (line number, error description)
- Tool continues operation (non-blocking)
- Graceful degradation (user config still works)
- Other commands still function (e.g., `tq profiles` works but ignores invalid project config)

## Prerequisites

- Rust test framework available
- `tq` binary built
- tempfile crate for test directory creation
- Error handling implementation complete

### Unit Test 1: Error Message Format

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_invalid_toml_error_message_format() {
        let path = PathBuf::from("/tmp/test/.tq.toml");
        let parse_error = "expected `=`, but found `:`";

        let warning = format_project_config_warning(&path, parse_error);

        // Verify warning format
        assert!(warning.starts_with("Warning:"), "Should start with 'Warning:'");
        assert!(
            warning.contains("Invalid project config"),
            "Should describe error type"
        );
        assert!(
            warning.contains("/tmp/test/.tq.toml"),
            "Should include full file path"
        );
        assert!(
            warning.contains(parse_error),
            "Should include parse error details"
        );
    }

    #[test]
    fn test_invalid_toml_returns_none_gracefully() {
        let invalid_toml = r#"
[profiles.dev
host = "example.com"  # Missing closing bracket
        "#;

        let result = parse_project_config_content(invalid_toml);

        // Should return None (graceful failure)
        assert!(result.is_none(), "Invalid TOML should return None, not panic");
    }

    #[test]
    fn test_partially_invalid_toml_degrades_gracefully() {
        let invalid_toml = r#"
[profiles.dev]
host = "dev.example.com"

[profiles.prod
database = "prod_db"  # Invalid section header
        "#;

        let result = parse_project_config_content(invalid_toml);

        // Should return None for completely invalid TOML
        assert!(result.is_none(), "Should fail gracefully on parse error");
    }
}
```

### Integration Test 1: Invalid TOML Produces Stderr Warning

```rust
#[test]
fn test_invalid_project_config_shows_stderr_warning() {
    let temp_dir = TempDir::new().unwrap();

    // Create INVALID .tq.toml (syntax error)
    let project_config = temp_dir.path().join(".tq.toml");
    fs::write(
        &project_config,
        r#"
[profiles.dev
host = "example.com"
# Missing closing bracket above
        "#,
    ).unwrap();

    // Execute tq profiles (should warn but continue)
    let output = Command::new(TQ_BIN)
        .args(&["profiles"])
        .current_dir(temp_dir.path())
        .output()
        .expect("Failed to execute tq profiles");

    // Command should still succeed (non-blocking)
    assert!(
        output.status.success(),
        "Command should succeed despite invalid project config"
    );

    let stderr = String::from_utf8_lossy(&output.stderr);

    // Verify warning to stderr
    assert!(
        stderr.contains("Warning:"),
        "Stderr should contain 'Warning:'"
    );
    assert!(
        stderr.contains("Invalid project config") ||
        stderr.contains("invalid") && stderr.contains(".tq.toml"),
        "Stderr should describe invalid project config"
    );
    assert!(
        stderr.contains(".tq.toml"),
        "Stderr should include .tq.toml filename"
    );
}
```

### Integration Test 4: Graceful Degradation - User Config Still Works

```rust
#[test]
fn test_invalid_project_config_degrades_to_user_config() {
    let temp_dir = TempDir::new().unwrap();

    // Create valid user config
    let user_config_dir = temp_dir.path().join(".config").join("tq");
    fs::create_dir_all(&user_config_dir).unwrap();
    fs::write(
        user_config_dir.join("config.toml"),
        r#"
[profiles.dev]
host = "user-dev.example.com"
        "#,
    ).unwrap();

    // Create INVALID project config
    let project_config = temp_dir.path().join(".tq.toml");
    fs::write(
        &project_config,
        r#"
[profiles.dev
host = "project-dev.example.com"
# Invalid syntax
        "#,
    ).unwrap();

    // Execute tq profiles
    let output = Command::new(TQ_BIN)
        .args(&["profiles"])
        .current_dir(temp_dir.path())
        .env("HOME", temp_dir.path())
        .output()
        .expect("Failed to execute tq profiles");

    // Should succeed
    assert!(output.status.success(), "Command should succeed");

    let stdout = String::from_utf8_lossy(&output.stdout);
    let stderr = String::from_utf8_lossy(&output.stderr);

    // Verify warning about invalid project config
    assert!(stderr.contains("Warning"), "Stderr should contain warning");

    // Verify user config still loaded (graceful degradation)
    assert!(
        stdout.contains("dev") && stdout.contains("user-dev.example.com"),
        "Should fall back to user config when project config invalid"
    );
}
```

### Integration Test 6: Warning Not Repeated Multiple Times

```rust
#[test]
fn test_invalid_config_warning_not_repeated() {
    let temp_dir = TempDir::new().unwrap();

    // Create INVALID project config
    let project_config = temp_dir.path().join(".tq.toml");
    fs::write(&project_config, "[invalid").unwrap();

    // Execute tq profiles
    let output = Command::new(TQ_BIN)
        .args(&["profiles"])
        .current_dir(temp_dir.path())
        .output()
        .expect("Failed to execute tq profiles");

    let stderr = String::from_utf8_lossy(&output.stderr);

    // Count warning occurrences
    let warning_count = stderr.matches("Warning:").count();

    // Should only warn once (not spam stderr)
    assert!(
        warning_count <= 1,
        "Warning should appear at most once, found {} occurrences",
        warning_count
    );
}
```
