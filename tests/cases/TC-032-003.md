# TC-032-003: Unit Test - NULL Value Width Handling

| **Test Type** | Unit |
| **Created** | 2026-02-03 |

## Purpose

Verify that NULL values are represented as `[NULL]` (6 characters) and correctly included in width calculations.

## Acceptance Criteria Coverage

- **AC-8**: Works correctly with NULL values

## Scope

This test validates:
- NULL values represented as `[NULL]` (6 characters)
- Width calculation includes NULL representation length
- Column with all NULL values uses header or `[NULL]` length
- Mixed NULL and non-NULL content: max length selected

## Prerequisites

- Rust test framework available
- Access to table formatting module in `src/format/table.rs`

## Test Procedure

### Test Implementation (in `src/format/table.rs`):

```rust
#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_null_value_width_calculation() {
        // Setup: Column with NULL values
        let columns = vec![
            ColumnMetadata::new("Email", "VARCHAR(100)"),
        ];
        let rows = vec![
            vec![Value::String("alice@example.com".to_string())], // 17 chars
            vec![Value::Null],                                     // [NULL] = 6 chars
            vec![Value::String("bob@test.co".to_string())],       // 11 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max(header, max_content)
        // Header "Email" = 5 chars, max content = 17 chars
        assert_eq!(widths[0], 17);
    }

    #[test]
    fn test_all_null_column_width() {
        // Setup: Column with all NULL values
        let columns = vec![
            ColumnMetadata::new("OptionalField", "VARCHAR(50)"),
        ];
        let rows = vec![
            vec![Value::Null],
            vec![Value::Null],
            vec![Value::Null],
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max(header, [NULL] length)
        // Header "OptionalField" = 13 chars, [NULL] = 6 chars
        // Expected: 13
        assert_eq!(widths[0], 13);
    }

    #[test]
    fn test_null_longer_than_header() {
        // Setup: Short header, NULL value
        let columns = vec![
            ColumnMetadata::new("Val", "INTEGER"), // 3 chars
        ];
        let rows = vec![
            vec![Value::Null], // [NULL] = 6 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is [NULL] length (6), not header length (3)
        assert_eq!(widths[0], 6, "NULL display length should be used");
    }

    #[test]
    fn test_null_shorter_than_content() {
        // Setup: NULL mixed with longer content
        let columns = vec![
            ColumnMetadata::new("Description", "VARCHAR(200)"),
        ];
        let rows = vec![
            vec![Value::Null],                                              // [NULL] = 6 chars
            vec![Value::String("This is a long description".to_string())], // 27 chars
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Width is max content length (27), not NULL length (6)
        assert_eq!(widths[0], 27);
    }

    #[test]
    fn test_multiple_columns_with_nulls() {
        // Setup: Multiple columns, some with NULLs
        let columns = vec![
            ColumnMetadata::new("ID", "INTEGER"),
            ColumnMetadata::new("Name", "VARCHAR(50)"),
            ColumnMetadata::new("Email", "VARCHAR(100)"),
        ];
        let rows = vec![
            vec![
                Value::Integer(1),
                Value::String("Alice".to_string()),
                Value::String("alice@example.com".to_string()),
            ],
            vec![
                Value::Integer(2),
                Value::Null,  // NULL in Name column
                Value::String("bob@test.co".to_string()),
            ],
            vec![
                Value::Integer(3),
                Value::String("Charlie".to_string()),
                Value::Null,  // NULL in Email column
            ],
        ];
        let result = QueryResult::new(columns, rows, Duration::from_millis(10));

        let widths = calculate_column_widths(&result);

        // Assert: Each column width calculated correctly with NULLs
        // ID: max(2, 1) = 2
        // Name: max(4, 7, 6) = 7 ("Charlie" wins)
        // Email: max(5, 17, 11, 6) = 17 ("alice@example.com" wins)
        assert_eq!(widths[0], 2);
        assert_eq!(widths[1], 7);
        assert_eq!(widths[2], 17);
    }
}
```

## Expected Results

All unit tests pass:
- NULL values represented as `[NULL]` (6 characters) in width calculations
- All-NULL columns use max(header_length, 6)
- Mixed NULL and non-NULL: max content length selected
- Multiple columns with NULLs calculated independently

## Pass/Fail Criteria

**PASS if:**
- All 5 unit tests compile and pass
- NULL values contribute 6 characters to width calculation
- All-NULL columns respect header length minimum
- Mixed NULL/non-NULL columns use max content length
- No panics or NULL handling errors

**FAIL if:**
- Any unit test fails
- NULL values not included in width calculation
- NULL representation length incorrect (not 6)
- Panics or errors when processing NULL values
