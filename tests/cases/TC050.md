# Test Case TC050: Tab Completion - FROM database.TAB Shows Tables in That Database

## Purpose

Verify that pressing Tab after `FROM database.` displays tables in the specified database, supporting Teradata's fully-qualified naming pattern.

## Scope

**Testing:**
- Tab completion after "FROM database." pattern
- Loading tables for specified database on-demand
- Filtering to show only tables in specified database
- Lazy loading and caching per database

**Not Testing:**
- Initial database list (covered in TC049)
- Error handling (covered in TC052)
- Cache invalidation (covered in TC053-TC054)

## Prerequisites

- tq REPL mode active
- Live Teradata database connection
- Multiple databases with tables available (e.g., DBC, val)

## Test Procedure

### Setup

```bash
./target/release/tq
```

### Execution Steps

**Step 1: Complete table name after DBC.**

```sql
tq> SELECT * FROM DBC.<TAB>
```

**Expected outcome:**
- Shows tables in DBC database
- Should include: DatabasesV, TablesV, ColumnsV, etc.
- Label indicates "Tables in 'DBC':"
- May show loading indicator on first access to DBC tables

**Step 2: Test with user database**

```sql
tq> SELECT * FROM val.<TAB>
```

**Expected outcome:**
- Shows tables in 'val' database
- Different list than DBC tables
- Loading indicator may appear if not cached
- Subsequent Tab is instant (cached)

**Step 3: Test filtering with partial table name**

```sql
tq> SELECT * FROM DBC.T<TAB>
```

**Expected outcome:**
- Filters to tables starting with 'T' in DBC
- Should include: TablesV, TVM, etc.
- Case-insensitive filtering

**Step 4: Verify caching behavior**

```sql
tq> SELECT * FROM DBC.<TAB>
[Wait for completion to appear]
<ESC or complete the query>

tq> SELECT * FROM DBC.<TAB>
```

**Expected outcome on second Tab:**
- Instant response (<50ms)
- No loading indicator
- Same tables as first time (cached)

### Verification

**Critical Checks:**

1. **Database-Specific Tables:**
   - [ ] Shows tables from specified database only
   - [ ] DBC.<TAB> shows DBC tables (DatabasesV, TablesV, etc.)
   - [ ] val.<TAB> shows val tables (not DBC tables)

2. **Loading Behavior:**
   - [ ] First Tab for a database may show loading indicator
   - [ ] Subsequent Tabs are instant (cached)
   - [ ] No errors or silent failures

3. **Visual Feedback:**
   - [ ] Clear label: "Tables in 'DBC':" or similar
   - [ ] Table list is readable
   - [ ] User can select and complete

## Expected Results

```sql
tq> SELECT * FROM DBC.<TAB>

Tables in 'DBC':
    ColumnsV    DatabasesV    FunctionsV    IndicesV    TablesV    TVM
```

**Key Characteristics:**
- Only tables from DBC shown (not from other databases)
- System views (ending in V) are visible
- Clear database context label

## Pass/Fail Criteria

**PASS:**
- Tab after "database." shows tables in that database
- Different databases show different table lists
- Loading indicator appears on first access (acceptable)
- Caching works (instant on subsequent access)
- Tables are filterable by typing

**FAIL:**
- Tab does nothing
- Shows tables from wrong database
- Shows same tables for all databases
- No loading indicator and no results (silent failure)
- Crashes or hangs when accessing database tables

## Notes

**Lazy Loading Strategy (from sprint-8-ux-design.md):**

> "only load the distinct databases names and the table names in the current database. If the user triggers tab completion, for table and column name within a new database, we fetch and cache table names in that database."

This test validates lazy loading:
1. Database names loaded at startup or first Tab
2. Current DB tables loaded at startup or first Tab
3. Other database tables loaded on-demand when user types `database.<TAB>`
4. Each database's tables cached independently

**Performance Expectation:**

- First access to new database: <500ms (fetch from DBC.TablesV)
- Cached access: <50ms (memory lookup)
- Cache per database (not global)

**Teradata Metadata Query:**

```sql
SELECT TRIM(TableName) AS table_name, TableKind
FROM DBC.TablesV
WHERE DatabaseName = 'DBC'  -- Specified database
ORDER BY TableName;
```
