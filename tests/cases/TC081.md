# TC081: File Output Error - Permission Denied

**Test ID:** TC081  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** High  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify clear error message when output directory is not writable.

## Requirement Coverage

- REQ-F1-06: Error: Permission denied

## Test Procedure

```bash
# Create read-only directory
mkdir -p /tmp/readonly_test
chmod 444 /tmp/readonly_test

# Attempt to write
tq query "SELECT 1" --output /tmp/readonly_test/output.txt

# Expected: Error with actionable message
# Clean up
chmod 755 /tmp/readonly_test
rmdir /tmp/readonly_test
```

## Expected Results

- ✅ Exit code non-zero
- ✅ Error message mentions permission denied
- ✅ Suggests checking directory permissions
- ✅ No partial file created

## Acceptance Criteria

- Clear, actionable error message
- Error caught before write attempt
- User understands how to fix
