## Purpose

Verify that `tq query` can execute a basic SQL query and display results in table format.

## Scope

This test validates:
- Query execution
- Table format output
- Column headers
- Row data display
- Row count summary
- Timing information

## Prerequisites

- tq binary is built and available
- `.env` file configured with valid Teradata connection credentials
- Access to system tables (e.g., DBC.DBCInfo)

## Test Procedure

### Step 1: Execute simple query
```bash
# Using credentials from .env file
tq query "SELECT 1 AS test_column"
```

### Step 2: Execute query with multiple columns
```bash
tq query "SELECT 'Alice' AS name, 25 AS age, true AS active"
```

### Step 3: Execute query with timing
```bash
tq query --timing "SELECT InfoKey, InfoData FROM DBC.DBCInfo WHERE InfoKey = 'VERSION'"
```

### Step 4: Execute query with explicit format
```bash
tq query --format table "SELECT 1"
```

## Pass/Fail Criteria

**PASS if:**
- Query executes successfully
- Exit code is 0
- Table format is properly formatted with borders
- Column headers are displayed
- Data is aligned properly (numbers right-aligned, text left-aligned)
- Row count summary is shown
- Timing information appears when --timing is used

**FAIL if:**
- Query fails to execute
- Exit code is non-zero
- Table format is malformed
- Headers or data are missing
- Alignment is incorrect
- Row count is incorrect

## Notes

- Table format is default for interactive terminals
- Column widths should auto-adjust to content
- NULL values should be visually distinct
- Large tables may need truncation or wrapping
