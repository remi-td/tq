# TC-043-003: Profile Edit - Happy Path and Errors

**Test ID:** TC-043-003
**Feature:** Profile Management - `tq profile edit`
**Priority:** P0 - Critical
**Test Type:** Integration (CLI process) + Unit
**Sprint:** 43
**Created:** 2026-03-21
**Requirement References:** AC-2, AC-5, AC-7, AC-8, AC-11, AC-12

---

## Objective

Verify that `tq profile edit <name> [--field value ...]` correctly updates only the specified fields of an existing profile, preserves all unspecified fields and all other profiles, and correctly rejects attempts to edit non-existent profiles or to call edit with no flags.

---

## Test Environment

Temporary directory via `TQ_CONFIG_DIR` environment variable. No database required.

---

## Test Cases

### TS43-P-E01: Edit single field - host (AC-2, AC-7, AC-8)

**Precondition:** Config file contains profile `dev` with host, port, database, and user fields set.

**Command:**
```
tq profile edit dev --host newhost.example.com
```

**Expected Results:**
- Exit code: 0
- Confirmation message on stdout (e.g., `Profile 'dev' updated successfully`)
- `host` field updated to `newhost.example.com`
- All other fields (`port`, `database`, `user`) UNCHANGED

```rust
#[test]
fn test_profile_edit_single_field() {
    let tmp = tempfile::TempDir::new().unwrap();
    // Set up profile with all fields
    std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args([
            "profile", "add", "dev",
            "--host", "original.example.com",
            "--port", "1025",
            "--database", "mydb",
            "--user", "admin",
        ])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    // Edit only the host
    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "edit", "dev", "--host", "newhost.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    assert!(output.status.success(), "edit must succeed, stderr: {}", String::from_utf8_lossy(&output.stderr));
    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(
        stdout.contains("dev") && (stdout.to_lowercase().contains("updated") || stdout.to_lowercase().contains("success")),
        "must confirm update, got: {stdout}"
    );

    let contents = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert!(contents.contains("newhost.example.com"), "host must be updated");
    assert!(!contents.contains("original.example.com"), "old host must be gone");
    // Other fields preserved
    assert!(contents.contains("1025"),  "port must be preserved");
    assert!(contents.contains("mydb"),  "database must be preserved");
    assert!(contents.contains("admin"), "user must be preserved");
}
```

### TS43-P-E02: Edit multiple fields simultaneously (AC-2, AC-7)

**Precondition:** Config file contains profile `dev` with all fields set.

**Command:**
```
tq profile edit dev --host updatedhost.example.com --user newuser --logmech LDAP
```

**Expected Results:**
- Exit code: 0
- Three fields updated: `host`, `user`, `logmech`
- Unspecified fields (`port`, `database`) UNCHANGED

```rust
#[test]
fn test_profile_edit_multiple_fields() {
    let tmp = tempfile::TempDir::new().unwrap();
    std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args([
            "profile", "add", "dev",
            "--host", "original.example.com",
            "--port", "1025",
            "--database", "mydb",
            "--user", "olduser",
            "--logmech", "TD2",
        ])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args([
            "profile", "edit", "dev",
            "--host", "updatedhost.example.com",
            "--user", "newuser",
            "--logmech", "LDAP",
        ])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    assert!(output.status.success(), "multi-field edit must succeed");

    let contents = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert!(contents.contains("updatedhost.example.com"), "host updated");
    assert!(contents.contains("newuser"), "user updated");
    assert!(contents.contains("LDAP"), "logmech updated");
    // Untouched fields
    assert!(contents.contains("1025"), "port preserved");
    assert!(contents.contains("mydb"), "database preserved");
    // Old values gone
    assert!(!contents.contains("original.example.com"), "old host removed");
    assert!(!contents.contains("olduser"), "old user removed");
    assert!(!contents.contains("TD2"), "old logmech removed");
}
```

### TS43-P-E03: Edit non-existent profile returns error (AC-5)

**Precondition:** Config file does NOT contain a profile named `ghost`.

**Command:**
```
tq profile edit ghost --host anyhost.example.com
```

**Expected Results:**
- Exit code: non-zero
- Error message mentions `ghost` and indicates it does not exist

```rust
#[test]
fn test_profile_edit_nonexistent_profile_fails() {
    let tmp = tempfile::TempDir::new().unwrap();
    // Create a different profile so config file exists
    std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "real", "--host", "real.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    let before = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();

    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "edit", "ghost", "--host", "anyhost.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    assert!(!output.status.success(), "editing non-existent profile must fail");
    let combined = format!(
        "{}{}",
        String::from_utf8_lossy(&output.stderr),
        String::from_utf8_lossy(&output.stdout)
    );
    assert!(
        combined.contains("ghost"),
        "error must mention the profile name, got: {combined}"
    );
    assert!(
        combined.to_lowercase().contains("not found") || combined.to_lowercase().contains("does not exist") || combined.to_lowercase().contains("unknown"),
        "error must indicate profile not found, got: {combined}"
    );

    // Config must not change
    let after = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert_eq!(before, after, "config must be unmodified on error");
}
```

### TS43-P-E04: Edit with no field flags returns error

**Precondition:** Config file contains profile `dev`.

**Command:**
```
tq profile edit dev
```

**Rationale:** Calling `edit` with no flags is a no-op at best and a user mistake at worst. The tool must reject it with a helpful message rather than silently succeeding.

**Expected Results:**
- Exit code: non-zero
- Error message indicates at least one flag is required

```rust
#[test]
fn test_profile_edit_no_flags_fails() {
    let tmp = tempfile::TempDir::new().unwrap();
    std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "dev", "--host", "h.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "edit", "dev"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    assert!(
        !output.status.success(),
        "edit with no flags must fail; exit code was 0"
    );
    let combined = format!(
        "{}{}",
        String::from_utf8_lossy(&output.stderr),
        String::from_utf8_lossy(&output.stdout)
    );
    assert!(
        combined.to_lowercase().contains("flag") || combined.to_lowercase().contains("required") || combined.to_lowercase().contains("option"),
        "error must indicate a flag is required, got: {combined}"
    );
}
```

### TS43-P-E07: Unit test - field merge logic (AC-2)

**Location:** `src/commands/profile.rs` `#[cfg(test)]` module

This test validates the internal merge function directly without spawning a process.

```rust
#[test]
fn test_profile_edit_field_merge_logic() {
    // Given: an existing profile struct with all fields
    let existing = ProfileConfig {
        host: "original.example.com".to_string(),
        port: Some(1025),
        database: Some("mydb".to_string()),
        user: Some("admin".to_string()),
        logmech: Some("TD2".to_string()),
        password_file: None,
    };

    // When: edit args specify only host and user
    let edits = ProfileEditArgs {
        host: Some("newhost.example.com".to_string()),
        port: None,  // not specified - must not change
        database: None,
        user: Some("newuser".to_string()),
        logmech: None,
        password_file: None,
    };

    let merged = merge_profile_edit(existing, edits);

    // Then: only host and user changed; everything else untouched
    assert_eq!(merged.host, "newhost.example.com", "host updated");
    assert_eq!(merged.port, Some(1025), "port preserved");
    assert_eq!(merged.database, Some("mydb".to_string()), "database preserved");
    assert_eq!(merged.user, Some("newuser".to_string()), "user updated");
    assert_eq!(merged.logmech, Some("TD2".to_string()), "logmech preserved");
    assert_eq!(merged.password_file, None, "password_file preserved (None)");
}
```
