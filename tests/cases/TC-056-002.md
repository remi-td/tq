## Purpose

Verify end-to-end that `--page-size` and `--page` CLI flags are wired through to the pagination slicer and produce correct results against a real Teradata database. Unit tests (TC-056-001) validate the logic; these tests validate the CLI argument pipeline.

## Acceptance Criteria Coverage

- PAG-REQ-1: `tq query --page-size N "SELECT ..."` returns correct slice
- PAG-REQ-2: `tq query --page-size N --page 2 "SELECT ..."` returns rows for page 2
- PAG-REQ-3: JSON output includes pagination object
- PAG-REQ-7: Works with `--agent-safe` mode

## Prerequisites

- Live Teradata database connection (set via `TQ_LOGON` env or `.env` file)
- `tq` binary built (`cargo build`)

## Test Procedure

These tests are marked `#[ignore]` and require the `--ignored` flag:

## Expected Results

All 4 integration tests pass against a live database. End-to-end flag wiring is confirmed.

## Pass/Fail Criteria

**PASS if:**
- All 4 integration tests run and pass
- Pagination metadata matches expected values
- Backward compatibility confirmed with real DB

**FAIL if:**
- Any test panics or assertion fails
- `--page-size` flag not recognized by CLI parser
- Pagination fields appear in non-paginated output

**BLOCKED if:**
- `TQ_LOGON` not set or DB unreachable
