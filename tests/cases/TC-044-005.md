# TC-044-005: License File Stored in Repository (Not Network-Fetched)

**Sprint:** 44
**Feature:** Teradata License Acceptance in Installer (Issue #31)
**Acceptance Criteria:** AC-11
**Type:** File Existence + Code Inspection
**Requires DB:** No
**Requires Binary:** No

---

## Objective

Verify that the Teradata driver license text is stored in the repository as a local file, and that `install.sh` does not fetch the license text from the network at install time.

AC-11 states: "License text stored in repository (not fetched remotely)."

## Preconditions

- The implementation has been completed (license file added to repo)
- `install.sh` has been updated to reference the local license

## Test Scenarios

### Scenario 1: License file exists in repository

**Expected file location:** One of:
- `docs/teradata-driver-license.txt`
- `LICENSE-TERADATA-DRIVER`
- `assets/teradata-license.txt`

The exact path must be agreed upon during implementation. This test verifies whichever path the architect chose.

**Assert:**
```rust
let license_path = format!("{}/docs/teradata-driver-license.txt",
    env!("CARGO_MANIFEST_DIR"));
assert!(
    std::path::Path::new(&license_path).exists(),
    "License file must exist at docs/teradata-driver-license.txt"
);
```

### Scenario 2: install.sh does not curl or wget the license

**Setup:** Read `install.sh` as a string

**Action:** Search for patterns that would fetch license text from a URL

**Expected:** No `curl` or `wget` command in `install.sh` that references a license URL pattern

**Assert:**
```bash
# Check install.sh does not fetch license from network
if grep -E "curl.*licens|wget.*licens" install.sh; then
    echo "FAIL: install.sh fetches license from network (violates AC-11)"
    exit 1
fi
echo "PASS: license is not network-fetched"
```

### Scenario 3: License file is non-empty

**Setup:** Read the license file

**Expected:** File is not empty (contains actual license text)

**Assert:**
```rust
let content = std::fs::read_to_string(&license_path).unwrap();
assert!(!content.trim().is_empty(), "License file must contain actual text");
assert!(content.len() > 100, "License file seems too short to be real license text");
```

### Scenario 4: install.sh references the license file

**Setup:** Read `install.sh` as a string

**Action:** Check that the license content is embedded in the script or referenced from a local path (the script must be usable without network access to see the license)

**Expected:** install.sh contains the license text inline OR reads it from a local file path relative to the script

## Implementation

```rust
// tests/install_license_file_test.rs or in tests/shell_tests.rs

#[test]
fn test_teradata_license_file_exists_in_repo() {
    let manifest = env!("CARGO_MANIFEST_DIR");

    // Try common candidate paths
    let candidates = [
        "docs/teradata-driver-license.txt",
        "LICENSE-TERADATA-DRIVER",
        "assets/teradata-license.txt",
        "TERADATA-LICENSE",
    ];

    let found = candidates.iter().any(|rel| {
        std::path::Path::new(&format!("{}/{}", manifest, rel)).exists()
    });

    assert!(
        found,
        "No Teradata driver license file found in repository. \
         Expected one of: {:?}",
        candidates
    );
}

#[test]
fn test_install_sh_does_not_network_fetch_license() {
    let manifest = env!("CARGO_MANIFEST_DIR");
    let install_sh = std::fs::read_to_string(format!("{}/install.sh", manifest))
        .expect("install.sh must be readable");

    // Check for network fetch of license text
    let has_network_license_fetch = install_sh.lines().any(|line| {
        let lower = line.to_lowercase();
        (lower.contains("curl") || lower.contains("wget"))
            && lower.contains("licens")
    });

    assert!(
        !has_network_license_fetch,
        "install.sh must not fetch license text from the network (AC-11 violation). \
         License must be stored in the repository."
    );
}
```

## Pass Criteria

- License file exists at a known repo path
- License file contains non-trivial text (>100 bytes)
- `install.sh` contains no `curl` or `wget` command that fetches license text
