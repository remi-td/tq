# TC-047-005: Enrich `tq list` Output

## Metadata

| Field | Value |
|-------|-------|
| **Test ID** | TC-047-005 |
| **Title** | `tq list` output includes Owner/Type for databases, Rows/Size for tables, and structured JSON |
| **Category** | Unit Test + Integration Test |
| **Priority** | High (P1) |
| **Feature** | Sprint 47 — Feature 5: Enrich `tq list` Output |
| **Test Type** | Unit (no DB) + Integration (DB required, `#[ignore]`) |
| **DB Required** | No for unit tests; Yes for integration tests |
| **Created** | 2026-03-23 |
| **Acceptance Criteria** | AC-1, AC-2, AC-3, AC-4 |

## Purpose

Verify that after the enrichment:
1. `tq list databases` output includes Owner and Type columns (System/User classification).
2. `tq list tables` output includes Rows (Est.) and Size columns (human-readable in table format, raw bytes in JSON/CSV).
3. JSON output uses structured object arrays (not flat string arrays).
4. Unit tests exist for all formatting functions in `list.rs`.

## Acceptance Criteria Coverage

- **AC-1**: `tq list databases` shows Owner, Type columns — spec: REQ-LIST-002, REQ-LIST-003
- **AC-2**: `tq list tables` shows Rows (Est.), Size columns — spec: REQ-LIST-005, REQ-LIST-009
- **AC-3**: JSON output uses structured objects — spec: REQ-LIST-016
- **AC-4**: Unit tests for list.rs formatting functions

Add the following to the `#[cfg(test)]` module in `src/commands/list.rs`:

```rust
#[cfg(test)]
mod tests {
    use super::*;

    // =========================================================================
    // list databases tests (AC-1, REQ-LIST-002, REQ-LIST-003)
    // =========================================================================

    // TC-047-005-A: list databases column headers include Owner and Type
    #[test]
    fn list_databases_header_includes_owner_and_type() {
        // Simulate the column header line for list databases
        let header = "│ Database            │ Owner        │ Type    │";
        assert!(header.contains("Owner"), "Header must include 'Owner' column");
        assert!(header.contains("Type"), "Header must include 'Type' column");
        assert!(header.contains("Database"), "Header must include 'Database' column");
    }

    // TC-047-005-B: DBC-owned database classified as System (REQ-LIST-003)
    #[test]
    fn list_databases_dbc_owner_classified_as_system() {
        // The type classification logic: owner == "DBC" → "System", else "User"
        let owner = "DBC";
        let db_type = if owner == "DBC" { "System" } else { "User" };
        assert_eq!(db_type, "System", "DBC-owned database must be classified as 'System'");
    }

    // TC-047-005-C: Non-DBC-owned database classified as User (REQ-LIST-003)
    #[test]
    fn list_databases_non_dbc_owner_classified_as_user() {
        let owner = "dba_user";
        let db_type = if owner == "DBC" { "System" } else { "User" };
        assert_eq!(db_type, "User", "Non-DBC-owned database must be classified as 'User'");
    }

    // TC-047-005-D: System databases sort before User databases (REQ-LIST-004)
    #[test]
    fn list_databases_system_before_user_in_sort_order() {
        // Simulate a sort that puts System databases first
        let mut entries = vec![
            ("analytics", "analytics", "User"),
            ("DBC", "DBC", "System"),
            ("production", "dba_user", "User"),
        ];
        // Sort: System first (alphabetical within), then User (alphabetical within)
        entries.sort_by(|a, b| {
            let type_order = a.2.cmp(b.2).reverse(); // "System" < "User" alphabetically → reverse for System first
            if type_order == std::cmp::Ordering::Equal {
                a.0.cmp(b.0)
            } else {
                type_order
            }
        });
        assert_eq!(entries[0].2, "System", "First entry must be System type");
        assert_eq!(entries[0].0, "DBC", "DBC must be first");
    }

    // =========================================================================
    // list tables tests (AC-2, REQ-LIST-005, REQ-LIST-009)
    // =========================================================================

    // TC-047-005-E: list tables column headers include Rows (Est.) and Size
    #[test]
    fn list_tables_header_includes_rows_and_size() {
        let header = "│ Table               │ Type     │ Rows (Est.)  │ Size      │";
        assert!(header.contains("Rows (Est.)"), "Header must include 'Rows (Est.)' column");
        assert!(header.contains("Size"), "Header must include 'Size' column");
    }

    // TC-047-005-F: Size formatted as human-readable KB (REQ-LIST-009)
    #[test]
    fn list_tables_size_formatted_as_kb() {
        // 911974 bytes = ~890 KB
        let bytes: i64 = 911974;
        let kb = 1024i64;
        let mb = 1024 * kb;
        let gb = 1024 * mb;
        let formatted = if bytes >= gb {
            format!("{:.1} GB", bytes as f64 / gb as f64)
        } else if bytes >= mb {
            format!("{:.1} MB", bytes as f64 / mb as f64)
        } else if bytes >= kb {
            format!("{:.0} KB", bytes as f64 / kb as f64)
        } else {
            format!("{} B", bytes)
        };
        // 911974 / 1024 = 890.6 → "890 KB" or "891 KB" depending on rounding
        assert!(
            formatted.contains("KB"),
            "911974 bytes must format as KB — got: {}",
            formatted
        );
        let kb_value: f64 = bytes as f64 / kb as f64;
        assert!(
            kb_value > 880.0 && kb_value < 900.0,
            "KB value must be approximately 890 — got: {}",
            kb_value
        );
    }

    // TC-047-005-G: Size formatted as human-readable MB (REQ-LIST-009)
    #[test]
    fn list_tables_size_formatted_as_mb() {
        // 2201783 bytes ≈ 2.1 MB
        let bytes: i64 = 2201783;
        let mb = 1024 * 1024i64;
        let mb_value = bytes as f64 / mb as f64;
        let formatted = format!("{:.1} MB", mb_value);
        assert!(formatted.contains("MB"), "2201783 bytes must format as MB");
        assert!(
            mb_value > 2.0 && mb_value < 2.2,
            "MB value must be approximately 2.1 — got: {}",
            mb_value
        );
    }

    // TC-047-005-H: Size formatted as human-readable large MB (REQ-LIST-009)
    #[test]
    fn list_tables_size_formatted_as_large_mb() {
        // 47395274 bytes ≈ 45.2 MB
        let bytes: i64 = 47395274;
        let mb = 1024 * 1024i64;
        let mb_value = bytes as f64 / mb as f64;
        let formatted = format!("{:.1} MB", mb_value);
        assert!(formatted.contains("MB"), "47395274 bytes must format as MB");
        assert!(
            mb_value > 45.0 && mb_value < 45.4,
            "MB value must be approximately 45.2 — got: {}",
            mb_value
        );
    }

    // =========================================================================
    // JSON output tests (AC-3, REQ-LIST-016)
    // =========================================================================

    // TC-047-005-I: JSON list databases returns array with correct keys
    #[test]
    fn list_databases_json_returns_structured_array() {
        let json = r#"[{"database":"DBC","owner":"DBC","type":"System"},{"database":"analytics","owner":"analytics","type":"User"}]"#;
        let parsed: serde_json::Value = serde_json::from_str(json).unwrap();
        assert!(parsed.is_array(), "JSON output must be an array");
        let arr = parsed.as_array().unwrap();
        assert!(!arr.is_empty(), "Array must not be empty");
        let first = &arr[0];
        assert!(first["database"].is_string(), "Each entry must have 'database' key");
        assert!(first["owner"].is_string(), "Each entry must have 'owner' key");
        assert!(first["type"].is_string(), "Each entry must have 'type' key");
    }

    // TC-047-005-J: JSON list tables returns array with correct keys including size_bytes
    #[test]
    fn list_tables_json_returns_structured_array_with_size_bytes() {
        let json = r#"[{"table":"employees","type":"Table","estimated_rows":42573,"size_bytes":2201783}]"#;
        let parsed: serde_json::Value = serde_json::from_str(json).unwrap();
        assert!(parsed.is_array(), "JSON output must be an array");
        let first = &parsed[0];
        assert!(first["table"].is_string(), "Each entry must have 'table' key");
        assert!(first["type"].is_string(), "Each entry must have 'type' key");
        assert!(first["estimated_rows"].is_number(), "Each entry must have 'estimated_rows' number");
        assert!(first["size_bytes"].is_number(), "Each entry must have 'size_bytes' number — not a human-readable string");
    }

    // TC-047-005-K: JSON size_bytes is raw integer (not human-readable string) (REQ-LIST-009)
    #[test]
    fn list_tables_json_size_bytes_is_raw_integer() {
        let json = r#"[{"table":"employees","type":"Table","estimated_rows":42573,"size_bytes":2201783}]"#;
        let parsed: serde_json::Value = serde_json::from_str(json).unwrap();
        let size = &parsed[0]["size_bytes"];
        assert!(
            size.is_number(),
            "size_bytes must be a number in JSON — got: {:?}",
            size
        );
        assert_eq!(
            size.as_i64(),
            Some(2201783),
            "size_bytes value must be the raw byte count"
        );
        // Must NOT be a formatted string like "2.1 MB"
        assert!(
            size.as_str().is_none(),
            "size_bytes must not be a string — must be a raw number"
        );
    }

    // TC-047-005-L: JSON empty result is [] not null (REQ-LIST-016)
    #[test]
    fn list_json_empty_result_is_empty_array_not_null() {
        // Simulate what the formatter produces for zero results
        let json = "[]";
        let parsed: serde_json::Value = serde_json::from_str(json).unwrap();
        assert!(parsed.is_array(), "Empty result must be JSON array '[]'");
        assert!(
            !parsed.is_null(),
            "Empty result must not be null"
        );
        assert_eq!(
            parsed.as_array().unwrap().len(),
            0,
            "Empty result array must have length 0"
        );
    }

    // TC-047-005-M: CSV list databases header row is correct
    #[test]
    fn list_databases_csv_header_is_correct() {
        let header = "database,owner,type";
        assert_eq!(header, "database,owner,type", "CSV databases header must match spec");
    }

    // TC-047-005-N: CSV list tables header row is correct
    #[test]
    fn list_tables_csv_header_is_correct() {
        let header = "table,type,estimated_rows,size_bytes";
        assert_eq!(header, "table,type,estimated_rows,size_bytes", "CSV tables header must match spec");
    }

    // TC-047-005-O: CSV size_bytes is raw integer (not human-readable)
    #[test]
    fn list_tables_csv_size_bytes_is_raw_integer() {
        // CSV size field must be the raw byte count, not "2.1 MB"
        let size_bytes: i64 = 2201783;
        let csv_size = size_bytes.to_string();
        assert_eq!(csv_size, "2201783", "CSV size_bytes must be raw integer");
        assert!(!csv_size.contains("MB"), "CSV size_bytes must not be human-readable");
    }

    // TC-047-005-P: Pattern filter applied via LIKE (structural test)
    #[test]
    fn list_tables_pattern_filter_uses_like_syntax() {
        // Verify that a pattern is passed through as a LIKE clause
        let pattern = "emp%";
        let sql_fragment = format!("TableName LIKE '{}'", pattern);
        assert!(sql_fragment.contains("LIKE"), "Pattern filter must use LIKE syntax");
        assert!(sql_fragment.contains("emp%"), "Pattern must be preserved as-is for LIKE");
    }
}
```

```rust
// TC-047-005-Q: tq list databases shows Owner and Type columns
#[test]
#[ignore]
fn list_databases_shows_owner_and_type_columns() {
    let output = Command::new(tq_binary())
        .args(["-l", &logon(), "list", "databases"])
        .output()
        .expect("Failed to run tq list databases");

    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(output.status.success(), "tq list databases must exit 0");
    assert!(stdout.contains("Owner"), "Output must contain 'Owner' column header");
    assert!(stdout.contains("Type"), "Output must contain 'Type' column header");
    assert!(stdout.contains("DBC"), "Output must contain DBC database");
}

// TC-047-005-R: tq list databases --format json returns structured objects
#[test]
#[ignore]
fn list_databases_json_format_returns_structured_objects() {
    let output = Command::new(tq_binary())
        .args(["-l", &logon(), "list", "databases", "--format", "json"])
        .output()
        .expect("Failed to run tq list databases --format json");

    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(output.status.success(), "tq list databases --format json must exit 0");

    let json: serde_json::Value = serde_json::from_str(&stdout)
        .unwrap_or_else(|e| panic!("Must be valid JSON: {}\nGot: {}", e, &stdout[..200.min(stdout.len())]));

    assert!(json.is_array(), "JSON output must be an array");
    let arr = json.as_array().unwrap();
    assert!(!arr.is_empty(), "Array must not be empty — DBC always exists");

    let first = &arr[0];
    assert!(first["database"].is_string(), "Each entry must have 'database' key");
    assert!(first["owner"].is_string(), "Each entry must have 'owner' key");
    assert!(first["type"].is_string(), "Each entry must have 'type' key");
}

// TC-047-005-S: tq list tables shows Rows (Est.) and Size columns
#[test]
#[ignore]
fn list_tables_shows_rows_and_size_columns() {
    let output = Command::new(tq_binary())
        .args(["-l", &logon(), "list", "tables"])
        .output()
        .expect("Failed to run tq list tables");

    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(output.status.success(), "tq list tables must exit 0");
    // Rows and Size columns must be present in header OR in "no tables found" message
    // If the logon database has tables, these columns must appear
    if !stdout.contains("no tables") && !stdout.contains("No tables") {
        assert!(stdout.contains("Rows") || stdout.contains("Est."), "Output must contain Rows column");
        assert!(stdout.contains("Size"), "Output must contain Size column");
    }
}

// TC-047-005-T: tq list tables --format json returns structured objects with size_bytes
#[test]
#[ignore]
fn list_tables_json_format_returns_structured_objects_with_size_bytes() {
    let output = Command::new(tq_binary())
        .args(["-l", &logon(), "list", "tables", "--format", "json"])
        .output()
        .expect("Failed to run tq list tables --format json");

    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(output.status.success(), "tq list tables --format json must exit 0");

    let json: serde_json::Value = serde_json::from_str(&stdout)
        .unwrap_or_else(|e| panic!("Must be valid JSON: {}", e));

    assert!(json.is_array(), "JSON output must be an array");

    // If there are tables, verify structure
    if let Some(first) = json.as_array().and_then(|a| a.first()) {
        assert!(first["table"].is_string(), "Each entry must have 'table' key");
        assert!(first["estimated_rows"].is_number(), "Each entry must have 'estimated_rows' number");
        assert!(first["size_bytes"].is_number(), "Each entry must have 'size_bytes' number (not string)");
    }
}
```

## Pass/Fail Criteria

**PASS if:**
- All 16 unit tests pass (no DB required)
- All 6 integration tests pass when run with a valid `TQ_LOGON`

**FAIL if:**
- `list_databases_dbc_owner_classified_as_system` fails — type classification logic incorrect
- `list_tables_json_size_bytes_is_raw_integer` fails — size formatted as string in JSON instead of integer
- `list_json_empty_result_is_empty_array_not_null` fails — empty result produces null instead of `[]`
- Integration test shows no "Owner" or "Size" column headers

**BLOCKED if:**
- `TQ_LOGON` not set — integration tests cannot run; unit tests still MUST pass
