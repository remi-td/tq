# TC078: Output to File - CSV Format

**Test ID:** TC078  
**Feature:** Batch Mode Output to File (Sprint 23 - P0)  
**Priority:** Critical  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify `--output` works with CSV format including special character escaping.

## Requirement Coverage

- REQ-F1-03: Supports CSV format output
- RFC 4180 compliance

## Test Procedure

```bash
# Test basic CSV
tq query "SELECT 1 AS id, 'Alice' AS name" --format csv --output /tmp/test.csv
cat /tmp/test.csv
# Expected: id,name\n1,Alice

# Test with special characters
tq query "SELECT 'Value, with comma' AS col" --format csv --output /tmp/test_escape.csv
cat /tmp/test_escape.csv
# Expected: col\n"Value, with comma"
```

## Expected Results

- ✅ CSV header row included
- ✅ Values with commas quoted
- ✅ RFC 4180 compliant escaping

## Acceptance Criteria

- CSV parseable by standard tools
- Proper escaping of commas, quotes, newlines
