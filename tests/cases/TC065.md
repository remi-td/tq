# Test Case TC065: LIMIT Hint - Help Text Uses Teradata Syntax

## Purpose

Verify that all help text, documentation, and metacommand output uses correct Teradata SQL syntax (TOP/SAMPLE) instead of LIMIT, ensuring consistency with the fixed hint message.

## Scope

**Testing:**
- `/help` command output
- Documentation references in help
- Error messages mentioning row limiting
- Any user-facing text about result limits

**Not Testing:**
- Source code comments (internal documentation)
- Developer docs (CLAUDE.md, architecture docs)
- Query execution (functionality already works)

## Prerequisites

- tq REPL mode active
- Access to help system

## Test Procedure

### Step 1: Check /help command output

```sql
tq> /help
```

**Expected:**
- Search output for mentions of "LIMIT", "TOP", "SAMPLE"
- If result limiting is mentioned, it should use TOP/SAMPLE
- NO mentions of "LIMIT clause" or similar MySQL/PostgreSQL syntax

**What to look for:**
```
CORRECT:
  "Large result sets are limited to 100 rows. Use TOP N or SAMPLE N to control."

INCORRECT:
  "Large result sets are limited to 100 rows. Use LIMIT clause to control."
```

### Step 2: Check --help flag (if implemented)

```bash
./target/release/tq --help
```

**Expected:**
- Help text should mention Teradata syntax if it discusses queries
- No references to LIMIT

### Step 3: Check tq query --help

```bash
./target/release/tq query --help
```

**Expected:**
- If examples are given, they use Teradata syntax
- Example: "SELECT TOP 10 * FROM table" not "SELECT * FROM table LIMIT 10"

### Step 4: Scan for any other help metacommands

```sql
tq> /commands
tq> /?
```

(If these exist)

**Expected:**
- Consistent Teradata syntax throughout
- No LIMIT references

### Step 5: Check error messages (if relevant)

Trigger any errors related to query limits or large results.

**Expected:**
- Error messages use Teradata syntax
- Suggestions use TOP/SAMPLE


**Teradata SQL Reference:**

Valid Teradata row limiting:
```sql
SELECT TOP 10 * FROM table;           -- First 10 rows
SELECT * FROM table SAMPLE 50;        -- 50 random rows
SELECT TOP 100 * FROM table ORDER BY col;  -- First 100 after ordering
```

Invalid in Teradata:
```sql
SELECT * FROM table LIMIT 10;         -- Syntax error
SELECT * FROM table LIMIT 10 OFFSET 5; -- Not supported
```

**Why This Matters:**

Users learn SQL syntax from:
1. Documentation/help text
2. Example queries
3. Error messages and hints

If help says "LIMIT" but Teradata doesn't support it, users will:
- Try LIMIT and get syntax errors
- Be confused about correct syntax
- Lose trust in tool's guidance

Consistency between hints, help, and examples is critical for good UX.

