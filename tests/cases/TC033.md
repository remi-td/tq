## Purpose

Verify that column name completion works correctly in ORDER BY, GROUP BY, and HAVING clauses.

## Scope

This test validates:
- Column completion after ORDER BY
- Column completion after GROUP BY
- Column completion in HAVING clause
- Multi-line query context detection
- Completion in various clause positions

## Prerequisites

- tq binary built in release mode
- Valid Teradata connection credentials configured in .env
- Test database with suitable tables
- REPL mode functional
- TC031 passed (basic column completion working)

## Test Procedure

### Step 1: Start REPL
```bash
tq repl
```

### Step 2: Test completion in ORDER BY
```sql
tq> SELECT * FROM employees ORDER BY <TAB>
```

### Step 3: Test prefix matching in ORDER BY
```sql
tq> SELECT * FROM employees ORDER BY hire<TAB>
```

### Step 4: Test multiple columns in ORDER BY
```sql
tq> SELECT * FROM employees ORDER BY department_id, <TAB>
```

### Step 5: Test completion in GROUP BY
```sql
tq> SELECT department_id, COUNT(*) FROM employees GROUP BY <TAB>
```

### Step 6: Test completion in HAVING clause
```sql
tq> SELECT department_id, COUNT(*) AS cnt
    FROM employees
    GROUP BY department_id
    HAVING <TAB>
```

### Step 7: Test multi-line query with ORDER BY
```sql
tq> SELECT employee_id,
           first_name,
           last_name
    FROM employees
    ORDER BY <TAB>
```

## Pass/Fail Criteria

**PASS if:**
- Completion works in ORDER BY clause
- Completion works in GROUP BY clause
- Completion works in HAVING clause
- Multi-line queries handled correctly
- Prefix matching works in all clauses

## Notes

- ORDER BY and GROUP BY common use cases
- Multi-line detection important for real queries
- HAVING clause may be complex (aggregate context)
- Should work with same table context detection as WHERE
