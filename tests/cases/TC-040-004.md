# TC-040-004: Sprint 39 Remediation - Redundant Test Removal

**Sprint:** 40

**Type:** Regression + Clippy
**Location:** consumer modules + `cargo clippy`
**Framework:** `cargo test --lib`, `cargo clippy`

## Overview

Sprint 39 extracted `extract_integer`, `extract_decimal`, `extract_trimmed_string`, and `escape_csv` from four consumer modules into the shared `src/commands/monitoring_utils.rs`. The shared module now has authoritative tests for all four utility functions.

This test case validates that:
1. The 31 redundant tests have been removed from consumer modules
2. All remaining tests still pass (no regression from removal)
3. No dead imports remain after removal

## Validation Procedure

### Step 1: Record pre-removal baseline

```bash
cargo test --lib 2>&1 | grep "test result:"
```

Record the total test count (should be ~790 minus the 31 redundant tests that haven't been removed yet; actual baseline confirmed at test execution time).

### Step 2: Remove redundant tests

The architect removes the 31 tests listed above from the four consumer modules.

### Step 3: Clippy check

```bash
cargo clippy -- -D warnings
```

**Expected:** Exit 0 (no warnings). If any `use` imports in the test modules were only used by the removed tests, clippy will flag them as unused. Those imports must also be removed.

### Step 4: Regression verification

```bash
cargo test --lib
```

**Expected:**
- All remaining tests pass
- Test count is (pre-removal baseline - 31)
- Exit code 0

### Step 5: Specific module verification

```bash
cargo test --lib commands::sessions::tests
cargo test --lib commands::sysconfig::tests
cargo test --lib commands::locks::tests
cargo test --lib commands::sample::tests
cargo test --lib commands::monitoring_utils::tests
```

**Expected:** All pass; monitoring_utils tests still present (the authoritative coverage).
