# Test Case TC060: Result Paging - Horizontal Paging with Arrow Keys

## Purpose

Verify that arrow keys (←→) can be used for horizontal navigation in addition to h/l keys, providing a more intuitive interface for users unfamiliar with vim-style navigation.

## Prerequisites

- tq REPL mode active
- Pager enabled
- Wide query results

## Test Procedure

### Step 1: Activate pager with wide results

```sql
tq> SELECT TOP 10 * FROM DBC.DatabasesV;
```

### Step 2: Navigate with arrow keys

Press Right Arrow key (→)

**Expected:**
- Scrolls right (same as 'l' key)
- Shows more columns on right

Press Left Arrow key (←)

**Expected:**
- Scrolls left (same as 'h' key)
- Shows more columns on left

Press Up Arrow key (↑)

**Expected:**
- Scrolls up (same as 'k' key)
- Shows previous line

Press Down Arrow key (↓)

**Expected:**
- Scrolls down (same as 'j' key)
- Shows next line

### Step 3: Test arrow key boundaries

Press Left Arrow at leftmost position:
- Should stop (no wrap or error)

Press Right Arrow at rightmost position:
- Should stop at last column

Press Up Arrow at top:
- Should stop at line 1

Press Down Arrow at bottom:
- Should stop at last line

## Verification

- [ ] Arrow keys work for 2D navigation
- [ ] ← = h (left)
- [ ] → = l (right)
- [ ] ↑ = k (up)
- [ ] ↓ = j (down)
- [ ] Works simultaneously with h/j/k/l keys
- [ ] Boundaries respected

## Pass/Fail Criteria

**PASS:**
- All arrow keys work for navigation
- Arrow keys are synonyms for hjkl
- Intuitive for non-vim users
- Works correctly at boundaries

**FAIL:**
- Arrow keys don't work
- Arrow keys conflict with hjkl
- Different behavior than hjkl
- Causes terminal issues

## Notes

Keybinding summary:
- Vertical: j/k or ↑/↓
- Horizontal: h/l or ←/→
- Page vertical: PageUp/PageDown
- Exit: q or Esc

Both vim-style (hjkl) and arrow keys should work for accessibility.
