# TC-048-004: Edge Case Messages — No indexes, NoPI, No secondary indexes

## Metadata

| Field | Value |
|-------|-------|
| **Test ID** | TC-048-004 |
| **Title** | Edge case messages: "No indexes defined.", "No Primary Index (NoPI)", "No secondary indexes." |
| **Category** | Unit Test (no DB) + Integration Test (DB required, `#[ignore]`) |
| **Priority** | High (P1) |
| **Feature** | Sprint 48 — Feature 4: Enrich list views & Edge Cases |
| **Test Type** | Unit (no DB) + Integration (DB required, `#[ignore]`) |
| **DB Required** | No for unit tests; Yes for integration tests |
| **Created** | 2026-03-23 |
| **Acceptance Criteria** | AC-2, AC-3, AC-4 (unit); AC-1, AC-5 (integration only) |

## Purpose

Verify that the correct edge case messages appear in command output:
1. `tq describe <table>` shows "No indexes defined." when a table has no indexes.
2. `tq show-indexes <table>` shows "No Primary Index (NoPI)" for NoPI tables.
3. `tq show-indexes <table>` shows "No secondary indexes." when no secondary indexes exist.

## Acceptance Criteria Coverage

- **AC-1**: `tq list views` shows Owner column (integration only — DB required)
- **AC-2**: "No indexes defined." in describe for tables without indexes
- **AC-3**: "No Primary Index (NoPI)" for NoPI tables in show-indexes
- **AC-4**: "No secondary indexes." when none exist in show-indexes
- **AC-5**: Rows (Est.) in describe object header (integration only — DB required)

## Part A — Unit Tests: "No indexes defined." in describe

### Prerequisites

- `src/commands/describe.rs` updated: when index query returns empty result for a table, output "No indexes defined."
- `cargo test --lib` compiles

### Test Implementation

Add to `#[cfg(test)] mod tests` in `src/commands/describe.rs`:

```rust
// TC-048-004-A1: describe renders "No indexes defined." when index list is empty
#[test]
fn describe_table_no_indexes_message() {
    use std::io::Write;
    let mut buf: Vec<u8> = Vec::new();

    // Simulate the indexes section of describe_table with empty index list
    let indexes: Vec<IndexGroup> = vec![];

    if indexes.is_empty() {
        writeln!(buf, "── Indexes ──").unwrap();
        writeln!(buf, "  No indexes defined.").unwrap();
    } else {
        writeln!(buf, "── Indexes ──").unwrap();
        for idx in &indexes {
            writeln!(buf, "  {} ({})", idx.name, idx.short_label).unwrap();
        }
    }

    let output = String::from_utf8(buf).unwrap();
    assert!(
        output.contains("No indexes defined."),
        "describe must show 'No indexes defined.' when table has no indexes: {}",
        output
    );
    assert!(
        output.contains("── Indexes ──"),
        "Indexes section header must still appear: {}",
        output
    );
}

// TC-048-004-A2: describe does NOT show "No indexes defined." when indexes exist
#[test]
fn describe_table_with_indexes_no_empty_message() {
    use std::io::Write;
    let mut buf: Vec<u8> = Vec::new();

    let indexes = vec![IndexGroup {
        name: "(unnamed)".to_string(),
        index_type_label: "Primary Index".to_string(),
        short_label: "UPI".to_string(),
        is_primary: true,
        columns: vec!["emp_id".to_string()],
    }];

    if indexes.is_empty() {
        writeln!(buf, "── Indexes ──").unwrap();
        writeln!(buf, "  No indexes defined.").unwrap();
    } else {
        writeln!(buf, "── Indexes ──").unwrap();
        for idx in &indexes {
            writeln!(buf, "  {} ({})", idx.name, idx.short_label).unwrap();
        }
    }

    let output = String::from_utf8(buf).unwrap();
    assert!(
        !output.contains("No indexes defined."),
        "Must not show 'No indexes defined.' when indexes exist: {}",
        output
    );
    assert!(
        output.contains("UPI"),
        "Index short label must appear: {}",
        output
    );
}
```

## Part B — Unit Tests: "No Primary Index (NoPI)" in show-indexes

### Prerequisites

### Test Implementation

Add to `#[cfg(test)] mod tests` in `src/commands/show_indexes.rs`:

```rust
// TC-048-004-B1: show-indexes renders "No Primary Index (NoPI)" for NoPI tables
#[test]
fn show_indexes_nopi_primary_message() {
    use std::io::Write;
    let mut buf: Vec<u8> = Vec::new();

    // Simulate show_indexes_table with NoPI table (no primary indexes)
    let primary_indexes: Vec<&IndexGroup> = vec![];
    let is_nopi = true;  // table_kind == "O"

    writeln!(buf, "── Primary Index ──").unwrap();
    if primary_indexes.is_empty() && is_nopi {
        writeln!(buf, "  No Primary Index (NoPI)").unwrap();
    } else if primary_indexes.is_empty() {
        writeln!(buf, "  No Primary Index").unwrap();
    } else {
        for idx in &primary_indexes {
            writeln!(buf, "  {} ({}): {}", idx.name, idx.short_label,
                idx.columns.join(", ")).unwrap();
        }
    }

    let output = String::from_utf8(buf).unwrap();
    assert!(
        output.contains("No Primary Index (NoPI)"),
        "NoPI table must show 'No Primary Index (NoPI)': {}",
        output
    );
}

// TC-048-004-B2: show-indexes does NOT show NoPI message for regular table without primary index
#[test]
fn show_indexes_regular_table_no_nopi_message() {
    use std::io::Write;
    let mut buf: Vec<u8> = Vec::new();

    // Regular table (is_nopi=false) but has a primary index
    let idx = IndexGroup {
        name: "(unnamed)".to_string(),
        index_type_label: "Primary Index".to_string(),
        short_label: "NUPI".to_string(),
        is_primary: true,
        columns: vec!["emp_id".to_string(), "dept_id".to_string()],
    };
    let primary_indexes: Vec<&IndexGroup> = vec![&idx];
    let is_nopi = false;

    writeln!(buf, "── Primary Index ──").unwrap();
    if primary_indexes.is_empty() && is_nopi {
        writeln!(buf, "  No Primary Index (NoPI)").unwrap();
    } else if primary_indexes.is_empty() {
        writeln!(buf, "  No Primary Index").unwrap();
    } else {
        for idx in &primary_indexes {
            writeln!(buf, "  {} ({}): {}", idx.name, idx.short_label,
                idx.columns.join(", ")).unwrap();
        }
    }

    let output = String::from_utf8(buf).unwrap();
    assert!(
        !output.contains("No Primary Index (NoPI)"),
        "Regular table with primary index must not show NoPI message: {}",
        output
    );
    assert!(
        output.contains("NUPI"),
        "Primary index short label must appear: {}",
        output
    );
```
