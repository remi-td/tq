# Test Case TC082: Regression Test - REPL Core Features Still Work

## Purpose

Verify that core REPL features (from Sprints 4-9) still work after Sprint 11 fixes. Ensure tab completion and table display fixes didn't break other REPL functionality.

## Scope

**Testing:**
- /help metacommand
- /quit metacommand
- /ping metacommand
- /session metacommand
- Multi-line query entry
- History navigation (up/down arrows)
- Query execution
- Error handling

**Not Testing:**
- Tab completion (separate TCs)
- Table display (separate TCs)

## Prerequisites

- tq binary with Sprint 11 fixes
- Teradata connection available
- Previous sprint features were working

## Test Procedure

### Setup

```bash
./target/release/tq repl
```

### Execution Steps

**Step 1: Test /help command**

```sql
tq> /help
```

**Expected outcome:**
- Shows help text
- Lists available commands
- No errors

**Step 2: Test /ping command**

```sql
tq> /ping
```

**Expected outcome:**
- Shows "Connection OK"
- Shows latency
- Connection verified

**Step 3: Test /session command**

```sql
tq> /session
```

**Expected outcome:**
- Shows session info
- Host, database, user shown
- Session details displayed

**Step 4: Test multi-line query entry**

```sql
tq> SELECT
    1 AS col1,
    2 AS col2;
```

**Expected outcome:**
- Multi-line entry works
- Query executes correctly
- Result displayed

**Step 5: Test history navigation**

Press UP arrow:

**Expected outcome:**
- Previous query recalled
- Can navigate history
- No corruption

**Step 6: Test query execution**

```sql
tq> SELECT DatabaseName FROM DBC.DatabasesV LIMIT 3;
```

**Expected outcome:**
- Query executes
- Results displayed
- Exit code logic intact (not exit REPL)

**Step 7: Test error handling**

```sql
tq> SELECT * FROM nonexistent_table;
```

**Expected outcome:**
- Error message shown
- REPL doesn't crash
- Can continue working

**Step 8: Test /quit command**

```sql
tq> /quit
```

**Expected outcome:**
- REPL exits cleanly
- No errors
- Returns to shell

### Verification

**Core Features Checklist:**

- [ ] /help works
- [ ] /ping works
- [ ] /session works
- [ ] /quit exits cleanly
- [ ] Multi-line entry works
- [ ] History navigation works
- [ ] Query execution works
- [ ] Error handling works
- [ ] REPL stable and usable

### Cleanup

(None - test exits REPL)

## Pass/Fail Criteria

**PASS:**
- All core features functional
- Metacommands work
- Query execution works
- Multi-line entry works
- History works
- Error handling preserved
- REPL stable

**FAIL:**
- Any core feature broken
- Metacommands don't work
- Query execution fails
- Multi-line broken
- History corrupted
- REPL crashes
- Regression in stability

## Notes

**Core Features Context:**

These features added in earlier sprints:
- Sprint 4: /help, /quit, basic REPL
- Sprint 5: /ping, /session
- Sprint 6-9: Various enhancements

Sprint 11 must not break any of these.

**Why This Matters:**

Tab completion and table display fixes involve:
- Parser changes
- Output formatting changes
- State management changes

Could inadvertently affect:
- Query execution
- Metacommand handling
- Error paths
- REPL state
