## Purpose

Verify that the editor resolution logic correctly prioritizes $VISUAL, falls back to $EDITOR, then to `vi`, and creates temp files with `.sql` extension. Also verify that alias `\e` is correctly parsed as `/edit`.

## Acceptance Criteria Coverage

- **AC-1**: `/edit` opens temp `.sql` file using $EDITOR/$VISUAL/vi fallback
- **AC-4**: Alias `\e` works identically to `/edit`
- **AC-9**: Temp file uses `.sql` extension for editor syntax highlighting

## Scope

This test validates:
- Editor resolution precedence: $VISUAL → $EDITOR → `vi`
- Temp file creation with `.sql` extension
- Temp file contains last SQL query content
- `/edit` command parsing
- `\e` alias parsing (treated identically to `/edit`)
- Error message when no editor available

## Prerequisites

- Rust test framework available
- Unit test support for environment variable manipulation
- Tempfile crate available
- Editor resolution implementation complete

## Test Procedure

### Unit Test 1: Editor Resolution - $VISUAL Priority

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::env;

    #[test]
    fn test_editor_resolution_visual_priority() {
        // Set both $VISUAL and $EDITOR
        env::set_var("VISUAL", "emacs");
        env::set_var("EDITOR", "nano");

        let editor = resolve_editor();

        assert_eq!(
            editor.unwrap(),
            "emacs",
            "$VISUAL should take priority over $EDITOR"
        );

        // Cleanup
        env::remove_var("VISUAL");
        env::remove_var("EDITOR");
    }

    #[test]
    fn test_editor_resolution_editor_fallback() {
        // Only set $EDITOR (no $VISUAL)
        env::remove_var("VISUAL");
        env::set_var("EDITOR", "nano");

        let editor = resolve_editor();

        assert_eq!(
            editor.unwrap(),
            "nano",
            "$EDITOR should be used when $VISUAL not set"
        );

        // Cleanup
        env::remove_var("EDITOR");
    }

    #[test]
    fn test_editor_resolution_vi_default() {
        // Remove both $VISUAL and $EDITOR
        env::remove_var("VISUAL");
        env::remove_var("EDITOR");

        let editor = resolve_editor();

        // Should default to vi (if available)
        assert!(
            editor.is_some(),
            "Should default to 'vi' when no env vars set"
        );
        assert_eq!(
            editor.unwrap(),
            "vi",
            "Default editor should be 'vi'"
        );
    }

    #[test]
    fn test_temp_file_has_sql_extension() {
        let sql = "SELECT 1 AS test;";

        let temp_file = create_temp_sql_file(sql).expect("Failed to create temp file");

        // Verify file has .sql extension
        let path = temp_file.path();
        assert!(
            path.extension().map(|e| e == "sql").unwrap_or(false),
            "Temp file should have .sql extension, got: {:?}",
            path.extension()
        );
    }

    #[test]
    fn test_temp_file_contains_sql() {
        let sql = "SELECT 42 AS answer;\nSELECT 'hello' AS greeting;";

        let temp_file = create_temp_sql_file(sql).expect("Failed to create temp file");

        // Read file contents
        let contents = std::fs::read_to_string(temp_file.path())
            .expect("Failed to read temp file");

        assert_eq!(
            contents.trim(),
            sql.trim(),
            "Temp file should contain original SQL"
        );
    }

    #[test]
    fn test_edit_command_parsing() {
        let input = "/edit";
        let parsed = parse_metacommand(input);

        assert!(parsed.is_some(), "Should parse /edit command");
        let command = parsed.unwrap();
        assert_eq!(command.name, "edit", "Command name should be 'edit'");
        assert!(command.args.is_empty(), "/edit takes no arguments");
    }

    #[test]
    fn test_edit_alias_e_parsing() {
        let input = r"\e";
        let parsed = parse_metacommand(input);

        assert!(parsed.is_some(), r"Should parse \e alias");
        let command = parsed.unwrap();
        assert_eq!(
            command.name,
            "edit",
            r"\e should be treated as /edit"
        );
        assert!(command.args.is_empty(), r"\e takes no arguments");
    }

    #[test]
    fn test_editor_resolution_error_when_none_available() {
        // Remove all editor env vars
        env::remove_var("VISUAL");
        env::remove_var("EDITOR");

        // Mock scenario where 'vi' is not in PATH
        // (In real implementation, this checks if vi exists)
        let editor = resolve_editor_strict(); // Returns Err if vi not found

        if which::which("vi").is_err() {
            assert!(
                editor.is_err(),
                "Should return error when no editor available"
            );
            let error = editor.unwrap_err();
            assert!(
                error.contains("No editor") || error.contains("EDITOR"),
                "Error should mention missing editor"
            );
        }
    }
}
```

## Expected Results

### Unit Test Results:
- When $VISUAL set: Returns $VISUAL value (priority over $EDITOR)
- When only $EDITOR set: Returns $EDITOR value
- When neither set: Returns "vi" (default fallback)
- Temp file created with `.sql` extension
- Temp file contains original SQL content
- `/edit` command parsed correctly
- `\e` alias treated as `/edit`
- Error returned when no editor available (and vi not in PATH)

## Pass/Fail Criteria

**PASS if:**
- All 8 unit tests pass

- $VISUAL takes priority over $EDITOR
