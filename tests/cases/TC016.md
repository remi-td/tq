## Purpose

Verify that tq correctly preserves data types when outputting JSON, not converting everything to strings.

## Scope

This test validates:
- Integer type preservation
- Float/decimal type preservation
- Boolean type preservation
- String type preservation
- Date/timestamp formatting
- Type validation with jq

## Prerequisites

- tq binary is built and available
- `.env` file configured with valid Teradata connection credentials
- jq installed for type checking

## Test Procedure

### Step 1: Integer types
```bash
# Using credentials from .env file
tq query --format json "SELECT 42 AS int_val, -100 AS neg_int, 0 AS zero"
```

### Step 2: Floating point types
```bash
tq query --format json "SELECT 3.14159 AS pi, 2.5 AS decimal, 1.0 AS whole"
```

### Step 3: Boolean types
```bash
tq query --format json "SELECT true AS t, false AS f"
```

### Step 4: String types
```bash
tq query --format json "SELECT 'text' AS str, '123' AS num_str, 'true' AS bool_str"
```

### Step 5: Mixed types
```bash
tq query --format json "SELECT 1 AS num, 'one' AS str, true AS bool, 1.5 AS dec"
```

### Step 6: Validate types with jq
```bash
tq query --format json "SELECT 42 AS n, 'text' AS s, true AS b" | \
  jq '.[0] | {num_type: (.n | type), str_type: (.s | type), bool_type: (.b | type)}'
```

### Step 7: Numeric operations in jq
```bash
tq query --format json "SELECT 10 AS a, 20 AS b" | jq '.[0].a + .[0].b'
```

## Pass/Fail Criteria

**PASS if:**
- Integers output as JSON numbers
- Floats/decimals output as JSON numbers
- Booleans output as JSON booleans
- Strings output as JSON strings
- jq confirms correct types
- Numeric operations work in jq
- No loss of type information

**FAIL if:**
- All values are strings (quoted)
- Type information lost
- Cannot perform numeric operations in jq
- jq reports wrong types
- Invalid JSON syntax

## Notes

- Type preservation is critical for downstream processing
- Many tools output everything as strings (bad practice)
- jq type checking: number, string, boolean, null, array, object
- Consider edge cases: very large numbers, scientific notation
- Dates/timestamps typically become ISO 8601 strings
- This is a key differentiator for a quality CLI tool
