## Purpose

Add database-dependent test for `/show indexes` command that validates output format and column headers with a real Teradata connection. This completes Sprint 36's `/show indexes` test coverage.

## Acceptance Criteria Coverage

- **AC-14**: `#[ignore]` test validates `/show indexes` with real Teradata connection
- **AC-15**: Test validates output format and column headers

## Scope

This test validates:
- `/show indexes` queries real Teradata database successfully
- Output includes expected column headers: IndexName, IndexType, ColumnName, ColumnPosition
- Output format is table format (aligned columns, separators)
- Query executes against DBC.IndicesV system catalog
- Test uses system catalog table guaranteed to have indexes
- Test marked with `#[ignore]` (runs only with `--ignored` flag)
- Test skipped gracefully if TQ_LOGON not set

## Prerequisites

- Rust test framework available
- `tq` binary built with REPL support
- Live Teradata database connection
- TQ_LOGON environment variable set
- Database user has SELECT access to DBC.IndicesV
- Known system table with indexes (e.g., DBC.Tables)

## Test Procedure

### Integration Test: Live Database Output Format

```rust
#[test]
#[ignore] // Requires live database: cargo test -- --ignored
fn test_show_indexes_live_database_output_format() {
    use std::process::Command;

    // Load TQ_LOGON from environment
    let logon = match std::env::var("TQ_LOGON") {
        Ok(val) => val,
        Err(_) => {
            eprintln!("Skipping test: TQ_LOGON not set");
            return;
        }
    };

    // Use system catalog table that always has indexes
    // DBC.Tables is a good choice: primary index on DatabaseName, TableName
    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("/show indexes DBC.Tables")
        .output()
        .expect("Failed to execute tq");

    // Convert output to string
    let stdout = String::from_utf8_lossy(&output.stdout);
    let stderr = String::from_utf8_lossy(&output.stderr);

    // Verify command succeeded
    assert!(
        output.status.success(),
        "Command should succeed. Stderr: {}",
        stderr
    );

    // Verify column headers present
    assert!(
        stdout.contains("IndexName"),
        "Output should include IndexName column header"
    );
    assert!(
        stdout.contains("IndexType"),
        "Output should include IndexType column header"
    );
    assert!(
        stdout.contains("ColumnName"),
        "Output should include ColumnName column header"
    );
    assert!(
        stdout.contains("ColumnPosition"),
        "Output should include ColumnPosition column header"
    );

    // Verify table formatting (separators)
    assert!(
        stdout.contains("---") || stdout.contains("═══"),
        "Output should include table separator lines"
    );

    // Verify at least one index row present
    // (DBC.Tables always has primary index)
    let line_count = stdout.lines().count();
    assert!(
        line_count > 3,
        "Output should have multiple lines (headers + separators + data)"
    );

    // Verify index types present (P = Primary, S = Secondary, etc.)
    assert!(
        stdout.contains("P") || stdout.contains("Primary"),
        "Output should include index type (at least Primary index exists)"
    );
}
```

### Integration Test: Column Header Format

```rust
#[test]
#[ignore] // Requires live database
fn test_show_indexes_column_headers_format() {
    use std::process::Command;

    let logon = match std::env::var("TQ_LOGON") {
        Ok(val) => val,
        Err(_) => {
            eprintln!("Skipping test: TQ_LOGON not set");
            return;
        }
    };

    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("/show indexes DBC.Tables")
        .output()
        .expect("Failed to execute tq");

    let stdout = String::from_utf8_lossy(&output.stdout);

    assert!(output.status.success(), "Command should succeed");

    // Verify all 4 required columns present
    let required_columns = vec!["IndexName", "IndexType", "ColumnName", "ColumnPosition"];
    for column in required_columns {
        assert!(
            stdout.contains(column),
            "Output should include {} column",
            column
        );
    }

    // Verify columns appear in reasonable order
    let indexname_pos = stdout.find("IndexName").unwrap();
    let indextype_pos = stdout.find("IndexType").unwrap();
    let columnname_pos = stdout.find("ColumnName").unwrap();
    let columnpos_pos = stdout.find("ColumnPosition").unwrap();

    // All positions should be found and reasonable
    assert!(
        indexname_pos < stdout.len() &&
        indextype_pos < stdout.len() &&
        columnname_pos < stdout.len() &&
        columnpos_pos < stdout.len(),
        "All column headers should be present in output"
    );
}
```

### Integration Test: Verify Query Against DBC.IndicesV

```rust
#[test]
#[ignore] // Requires live database
fn test_show_indexes_queries_dbc_indicesv() {
    use std::process::Command;

    let logon = match std::env::var("TQ_LOGON") {
        Ok(val) => val,
        Err(_) => {
            eprintln!("Skipping test: TQ_LOGON not set");
            return;
        }
    };

    // Execute /show indexes
    let output = Command::new(TQ_BIN)
        .arg("repl")
        .arg("--logon")
        .arg(&logon)
        .arg("--command")
        .arg("/show indexes DBC.Tables")
        .output()
        .expect("Failed to execute tq");

    let stdout = String::from_utf8_lossy(&output.stdout);

    assert!(output.status.success(), "Command should succeed");

    // Verify output structure matches DBC.IndicesV query result
    // (This test validates that the implementation uses correct catalog view)

    // Should have structured output (not error message)
    assert!(
        !stdout.contains("Error") && !stdout.contains("error"),
        "Output should not contain errors (DBC.IndicesV should be accessible)"
    );

    // Should have actual index data (not empty result)
    let data_lines = stdout.lines()
        .filter(|line| !line.contains("---") && !line.contains("Index"))
        .count();

    assert!(
        data_lines > 0,
        "Output should contain index data rows from DBC.IndicesV"
    );
}
```
