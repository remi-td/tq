# TC091: Large Transaction - Many Statements

**Test ID:** TC091  
**Feature:** Batch Mode Transaction Control (Sprint 23 - P1)  
**Priority:** Medium  
**Test Type:** Integration  
**Created:** 2026-01-23

## Objective

Verify --atomic works with large batches (50+ statements).

## Test Procedure

```bash
# Generate batch with 50 INSERT statements
cat > /tmp/large_batch.sql << 'SQL'
CREATE VOLATILE TABLE test_large (id INT, val INT);
SQL

for i in {1..50}; do
    echo "INSERT INTO test_large VALUES ($i, $((i * 2)));" >> /tmp/large_batch.sql
done

# Execute with --atomic
tq query --file /tmp/large_batch.sql --atomic -v

# Verify all 50 rows committed
tq query "SELECT COUNT(*) FROM test_large"
# Expected: 50

# Clean up
tq query "DROP TABLE test_large"
rm -f /tmp/large_batch.sql
```

## Expected Results

- ✅ All 50 statements execute within single transaction
- ✅ All rows committed
- ✅ Performance acceptable
- ✅ No timeout issues

## Acceptance Criteria

- Handles large statement counts
- Transaction completes successfully
- No memory issues
