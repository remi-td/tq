# TC-044-004: Install Script License Gate - shellcheck + Behavioral Tests

**Sprint:** 44
**Feature:** Teradata License Acceptance in Installer (Issue #31)
**Acceptance Criteria:** AC-7, AC-8, AC-9, AC-10
**Type:** Shell Script Test
**Requires DB:** No
**Requires Binary:** No

---

## Objective

Verify the install.sh license gate works correctly across four behavioral scenarios:
1. License summary is displayed before any download (AC-7)
2. Interactive `n` response aborts installation (AC-8)
3. `--accept-license` flag bypasses the prompt (AC-9)
4. Non-TTY stdin without `--accept-license` aborts with an actionable error (AC-10)

Also verify shellcheck finds no syntax errors (structural correctness prerequisite).

## Preconditions

- `install.sh` exists in project root
- `shellcheck` is installed (`shellcheck --version` exits 0)
- `bash` or POSIX `sh` is available
- Tests use function mocking to prevent actual network downloads

## Test Runner Approach

These tests are implemented as a Bash test script at `tests/shell/test_install_license.sh`. They can be invoked from Rust via `std::process::Command` or run directly.

## Test Scenarios

### Scenario 1: shellcheck passes with no errors

**Command:** `shellcheck -S error install.sh`

**Expected:** Exit code 0

**Assert:** No shellcheck error-level diagnostics

### Scenario 2: `--accept-license` flag bypasses prompt (AC-9)

**Setup:** Run `install.sh --accept-license` with the download function mocked to exit cleanly

**Approach:**
```bash
# Mock the download and install steps
_mock_exit_before_download() {
    # Override functions that would trigger download
    download_and_install() { echo "MOCK: download skipped"; exit 0; }
    export -f download_and_install
}

# Run install.sh sourced with mocked function, non-TTY stdin
echo "" | TQ_INSTALL_DIR=/tmp/tq-test-install sh install.sh --accept-license
```

**Expected:** Exit code 0 (license gate passed), no prompt appears

**Assert:** Exit code 0 AND output does NOT contain "Do you accept" or `[y/N]` prompt text

### Scenario 3: Non-TTY stdin, no flag, aborts (AC-10)

**Command:**
```bash
# Redirect stdin from /dev/null to simulate non-TTY piped install
sh install.sh </dev/null
```

**Expected:** Exit code non-zero (1 or 2)

**Assert:**
- Exit code != 0
- stderr or stdout contains `--accept-license` in the error message (actionable guidance)

### Scenario 4: Interactive `n` response aborts (AC-8)

**Command:**
```bash
# Feed 'n' as stdin response to the license prompt
echo "n" | sh install.sh
```

**Expected:** Exit code non-zero

**Assert:**
- Exit code != 0
- Output contains "aborted" or "declined" or similar

### Scenario 5: License summary displayed before download (AC-7)

**Setup:** Run with `--accept-license` and capture output before any download attempt

**Command:**
```bash
# Capture stdout; mock download to capture order of output
output=$(sh install.sh --accept-license 2>&1 || true)
```

**Expected:** License text or summary appears in output BEFORE any "Downloading" message

**Assert:**
```bash
license_pos=$(echo "$output" | grep -n "license\|License\|LICENSE" | head -1 | cut -d: -f1)
download_pos=$(echo "$output" | grep -n "Download\|download\|Installing" | head -1 | cut -d: -f1)
[ "$license_pos" -lt "$download_pos" ]  # license appears before download
```

## Implementation: Rust wrapper test

A Rust integration test can invoke shellcheck and the shell test script:

```rust
// In tests/shell_tests.rs

#[test]
fn test_install_sh_shellcheck() {
    let output = std::process::Command::new("shellcheck")
        .args(["-S", "error", "install.sh"])
        .current_dir(env!("CARGO_MANIFEST_DIR"))
        .output();

    match output {
        Ok(out) => {
            assert!(
                out.status.success(),
                "shellcheck found errors in install.sh:\n{}",
                String::from_utf8_lossy(&out.stdout)
            );
        }
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => {
            eprintln!("SKIP: shellcheck not installed. Install with: brew install shellcheck");
            // Not a hard failure if shellcheck is not present in this environment
        }
        Err(e) => panic!("Failed to run shellcheck: {}", e),
    }
}

#[test]
fn test_install_sh_accept_license_flag() {
    // Run the shell test script
    let test_script = format!("{}/tests/shell/test_install_license.sh",
        env!("CARGO_MANIFEST_DIR"));

    let output = std::process::Command::new("sh")
        .arg(&test_script)
        .current_dir(env!("CARGO_MANIFEST_DIR"))
        .output()
        .expect("Failed to run shell test script");

    assert!(
        output.status.success(),
        "Shell license tests failed:\n{}\n{}",
        String::from_utf8_lossy(&output.stdout),
        String::from_utf8_lossy(&output.stderr)
    );
}
```

## Pass Criteria

- shellcheck exits 0 on `install.sh`
- `--accept-license` flag causes script to proceed past license gate (exit 0 from license section)
- Non-TTY stdin without flag causes non-zero exit with `--accept-license` mentioned in output
- Interactive `n` response causes non-zero exit
- License text appears in output before any download messages
