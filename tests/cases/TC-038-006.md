## Purpose

Validate the core logic of the `/locks` command without requiring a database:
- SQL constant references correct Teradata lock view
- `LockInfo::from_row()` correctly parses all lock fields
- Lock type mapping converts raw values to display strings correctly
- Empty lock list produces appropriate "no locks" message
- Table, CSV, and JSON formatters produce correct structure
- Alias `/lk` is recognized

This is the most complex feature in Sprint 38 due to lock type mapping and potential blocking chain logic.

## Acceptance Criteria Coverage

- **AC-1**: SQL queries DBC.LockInfoV (or equivalent)
- **AC-2**: Display includes locked object, lock type, locking session, waiting sessions
- **AC-3**: Blocking chain identification logic
- **AC-8**: Unit tests for SQL generation, formatting, lock type mapping, and parsing
- **AC-9**: `/lk` short alias routing

## Prerequisites

- Rust test framework (`#[test]`)
- `DatabaseClient::mock()` (no database needed)
- `Value::*` enum for mock row construction

## Test Procedure

```rust
#[cfg(test)]
mod tests {
    use super::*;

    // --- SQL Constant Tests ---

    #[test]
    fn test_locks_sql_contains_lockinfov() {
        assert!(
            LOCKS_SQL.contains("LockInfoV") || LOCKS_SQL.contains("DBC.LockInfoV"),
            "Locks SQL must query DBC.LockInfoV or equivalent view"
        );
    }

    // --- LockInfo Struct Parsing Tests ---

    fn make_read_lock_row() -> Vec<Value> {
        // Typical columns from DBC.LockInfoV:
        // VProc, DatabaseName, TableName/ObjectName, LockType, LockStatus, SessionNo, ...
        vec![
            Value::Integer(0),                          // VProc or AMP
            Value::String("MyDatabase".to_string()),    // DatabaseName
            Value::String("MyTable".to_string()),       // TableName/ObjectName
            Value::String("RD".to_string()),            // LockType - READ
            Value::String("L".to_string()),             // LockStatus - Locking
            Value::Integer(1234),                       // SessionNo (holder)
            Value::Integer(0),                          // Waiting session count
        ]
    }

    fn make_write_lock_row() -> Vec<Value> {
        vec![
            Value::Integer(0),
            Value::String("MyDatabase".to_string()),
            Value::String("MyTable".to_string()),
            Value::String("WR".to_string()),            // WRITE lock
            Value::String("L".to_string()),
            Value::Integer(1235),
            Value::Integer(2),                          // 2 sessions waiting
        ]
    }

    fn make_exclusive_lock_row() -> Vec<Value> {
        vec![
            Value::Integer(0),
            Value::String("MyDatabase".to_string()),
            Value::String("MyTable".to_string()),
            Value::String("EX".to_string()),            // EXCLUSIVE lock
            Value::String("L".to_string()),
            Value::Integer(1236),
            Value::Integer(5),
        ]
    }

    fn make_share_lock_row() -> Vec<Value> {
        vec![
            Value::Integer(0),
            Value::String("MyDatabase".to_string()),
            Value::String("MyTable".to_string()),
            Value::String("SR".to_string()),            // SHARE lock
            Value::String("L".to_string()),
            Value::Integer(1237),
            Value::Integer(1),
        ]
    }

    #[test]
    fn test_lockinfo_from_row_valid_read_lock() {
        let row = make_read_lock_row();
        let lock = LockInfo::from_row(&row);
        assert!(lock.is_some(), "Valid READ lock row should parse successfully");

        let lock = lock.unwrap();
        assert_eq!(lock.database_name, "MyDatabase");
        assert_eq!(lock.object_name, "MyTable");
    }

    #[test]
    fn test_lockinfo_from_row_valid_write_lock() {
        let row = make_write_lock_row();
        let lock = LockInfo::from_row(&row);
        assert!(lock.is_some(), "Valid WRITE lock row should parse successfully");
    }

    #[test]
    fn test_lockinfo_from_row_valid_exclusive_lock() {
        let row = make_exclusive_lock_row();
        let lock = LockInfo::from_row(&row);
        assert!(lock.is_some(), "Valid EXCLUSIVE lock row should parse successfully");
    }

    #[test]
    fn test_lockinfo_from_row_valid_share_lock() {
        let row = make_share_lock_row();
        let lock = LockInfo::from_row(&row);
        assert!(lock.is_some(), "Valid SHARE lock row should parse successfully");
    }

    #[test]
    fn test_lockinfo_from_row_insufficient_columns() {
        let short_row = vec![
            Value::Integer(0),
            Value::String("MyDatabase".to_string()),
        ];
        let lock = LockInfo::from_row(&short_row);
        assert!(lock.is_none(), "Short row should return None, not panic");
    }

    #[test]
    fn test_lockinfo_from_row_null_fields() {
        let row = vec![
            Value::Integer(0),
            Value::Null,                                // NULL database name
            Value::String("MyTable".to_string()),
            Value::Null,                                // NULL lock type
            Value::String("L".to_string()),
            Value::Integer(1234),
            Value::Null,                                // NULL waiting count
        ];
        // Must not panic - NULL handling must be graceful
        let _ = LockInfo::from_row(&row);
    }

    // --- Lock Type Mapping Tests ---

    #[test]
    fn test_lock_type_mapping_read() {
        let display = map_lock_type("RD");
        assert!(
            display == "READ" || display == "Read" || display.to_uppercase() == "READ",
            "RD should map to READ, got: {}",
            display
        );
    }

    #[test]
    fn test_lock_type_mapping_write() {
        let display = map_lock_type("WR");
        assert!(
            display == "WRITE" || display == "Write" || display.to_uppercase() == "WRITE",
            "WR should map to WRITE, got: {}",
            display
        );
    }

    #[test]
    fn test_lock_type_mapping_exclusive() {
        let display = map_lock_type("EX");
        assert!(
            display == "EXCLUSIVE" || display == "Exclusive" ||
            display.to_uppercase() == "EXCLUSIVE",
            "EX should map to EXCLUSIVE, got: {}",
            display
        );
    }

    #[test]
    fn test_lock_type_mapping_share() {
        let display = map_lock_type("SR");
        assert!(
            display == "SHARE" || display == "Share" || display.to_uppercase() == "SHARE",
            "SR should map to SHARE, got: {}",
            display
        );
    }

    #[test]
    fn test_lock_type_mapping_unknown_preserved() {
        // Unknown lock type codes should be preserved as-is, not panicked
        let display = map_lock_type("UNKNOWN_CODE");
        assert!(!display.is_empty(), "Unknown lock type should return non-empty string");
    }

    // --- Empty State Test ---

    #[test]
    fn test_format_table_empty_locks_shows_no_locks_message() {
        let mut output = Vec::new();
        let locks: Vec<LockInfo> = vec![];
        display_locks_table(&locks, &mut output).unwrap();
        let s = String::from_utf8(output).unwrap();

        assert!(
            s.contains("no active locks") || s.contains("No locks") ||
            s.contains("No active locks") || s.contains("(no"),
            "Empty lock list must display 'no active locks' or similar message. Got: {}",
            s
        );
    }

    // --- Formatter Tests ---

    #[test]
    fn test_format_table_nonempty_locks_has_headers() {
        let locks = vec![
            LockInfo {
                database_name: "MyDB".to_string(),
                object_name: "MyTable".to_string(),
                lock_type: "READ".to_string(),
                session_no: 1234,
                waiting_count: 0,
            }
        ];
        let mut output = Vec::new();
        display_locks_table(&locks, &mut output).unwrap();
        let s = String::from_utf8(output).unwrap();

        // Table must have at least some header content
        assert!(
            s.contains("Lock") || s.contains("Session") || s.contains("Object"),
            "Lock table must have column headers. Got: {}",
            s
        );
    }

    #[test]
    fn test_format_csv_locks_has_comma_separated_header() {
        let mut output = Vec::new();
        let result = create_mock_locks_query_result_with_data();
        display_csv(&result, &mut output).unwrap();
        let s = String::from_utf8(output).unwrap();

        let lines: Vec<&str> = s.lines().collect();
        assert!(!lines.is_empty(), "CSV must have at least a header line");
        assert!(
            lines[0].contains(','),
            "CSV header must be comma-separated. Got: {}",
            lines[0]
        );
    }

    #[test]
    fn test_format_json_locks_produces_valid_json() {
        let mut output = Vec::new();
        let result = create_mock_locks_query_result_with_data();
        display_json(&result, &mut output).unwrap();
        let s = String::from_utf8(output).unwrap();

        let parsed: Result<serde_json::Value, _> = serde_json::from_str(&s);
        assert!(parsed.is_ok(), "Locks JSON must be valid. Got: {}", s);
        assert!(parsed.unwrap().is_array(), "Locks JSON must be an array");
    }

    // --- Alias Routing Test ---

    #[test]
    fn test_lk_alias_recognized() {
        let aliases = locks_command_aliases();
        assert!(
            aliases.contains(&"/lk") || aliases.contains(&"lk"),
            "/lk must be a recognized alias for /locks"
        );
    }
}
```

## Expected Results

- All 15 unit tests compile and pass without database
- READ, WRITE, EXCLUSIVE, SHARE lock types parse correctly from mock rows
- Short rows and NULL fields handled without panic
- All four lock type codes (RD, WR, EX, SR) map to human-readable strings
- Empty lock list displays "no active locks" message
- Formatters produce correct table/CSV/JSON structure
- `/lk` alias recognized

## Pass/Fail Criteria

**PASS if:**
- All 15 unit tests pass
- `LockInfo::from_row()` parses all four lock type rows
- Lock type mapping covers RD, WR, EX, SR → READ, WRITE, EXCLUSIVE, SHARE
- Empty lock list message is user-friendly (not raw empty table)
- JSON output is valid JSON array
- `/lk` alias is in the recognized alias list

**FAIL if:**
- Any unit test fails
- Panic on NULL or short row input
- Lock type "RD" not recognized (shown as raw code to user)
- Empty result shows bare empty table instead of "no locks" message
- JSON output is invalid
- `/lk` alias not recognized
