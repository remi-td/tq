# TC100: `handle_tick_result` Extraction + Unit Test (Feature 2, Sprint 67)

**Sprint:** 67
**Feature:** Feature 2 — Sprint 65 P2 follow-up: extract `handle_tick_result` as a pure function, add unit tests
**Component:** `src/commands/watch.rs`
**Test Type:** Unit tests (TC100-U01 through TC100-U04, no DB, no PTY)
**Related Strategy:** `tests/strategy/sprint-67-strategy.md` — Feature 2
**Specification:** `docs/sprints/sprint-67-planning.md` → Feature 2 Acceptance Criteria

## Overview

Sprint 65 flagged a gap in `watch.rs`: the `match render_result { Ok(body) => ..., Err(e) => ... }` block
inside `watch_loop` was inlined and untestable in isolation. Feature 2 extracts it into a pure function
`handle_tick_result(render_result, last_body) -> TickOutcome` and adds unit tests that feed the function
directly without needing a terminal, a live DB, or a real watch interval.

The `TickOutcome` struct returned by the function contains:
- `body: Vec<u8>` — the body to retain as `last_body` for the next frame
- `error_message: Option<String>` — formatted error text for this frame (or `None` on success)

The function is private (`fn`, not `pub`) but callable from the `#[cfg(test)]` module in the same file.

## TC100-U01: AC-3 — Error path retains last_body

**Requirement:** Feature 2 AC-3 — `Err(...)` keeps `TickOutcome::body == last_body` and populates `error_message`.

**Location:** `src/commands/watch.rs`, `#[cfg(test)]`

**Existing test function:** `test_handle_tick_result_error_retains_last_body`

```rust
#[test]
fn test_handle_tick_result_error_retains_last_body() {
    let last_body = b"previous frame content\n".to_vec();
    let render_result: crate::error::Result<Vec<u8>> =
        Err(crate::error::TqError::QueryExecution("simulated tick failure".into()));

    let outcome = handle_tick_result(render_result, last_body.clone());

    assert_eq!(
        outcome.body, last_body,
        "On error, retained body must equal last_body unchanged"
    );
    let err_msg = outcome.error_message.expect("Error path must populate error_message");
    assert!(
        err_msg.contains("simulated tick failure"),
        "Error message should contain the error text, got: {:?}", err_msg
    );
}
```

**Pass criteria:**
- `outcome.body == last_body` (byte-identical)
- `outcome.error_message.is_some()`
- `error_message` contains `"simulated tick failure"`

## TC100-U02: AC-4 — Success path replaces last_body

**Requirement:** Feature 2 AC-4 — `Ok(new)` makes `TickOutcome::body == new` and `error_message` is `None`.

**Location:** `src/commands/watch.rs`, `#[cfg(test)]`

**Existing test function:** `test_handle_tick_result_success_replaces_body`

```rust
#[test]
fn test_handle_tick_result_success_replaces_body() {
    let last_body = b"previous frame content\n".to_vec();
    let new_body = b"fresh frame content\n".to_vec();
    let render_result: crate::error::Result<Vec<u8>> = Ok(new_body.clone());

    let outcome = handle_tick_result(render_result, last_body);

    assert_eq!(
        outcome.body, new_body,
        "On success, retained body must equal the freshly rendered body"
    );
    assert!(
        outcome.error_message.is_none(),
        "Success path must not populate error_message"
    );
}
```

**Pass criteria:**
- `outcome.body == new_body`
- `outcome.error_message.is_none()`

## TC100-U03: AC-3 corollary — Error with empty last_body

**Requirement:** Feature 2 AC-3 — edge case: first tick fails before any successful render; empty `last_body` stays empty.

**Location:** `src/commands/watch.rs`, `#[cfg(test)]`

**Existing test function:** `test_handle_tick_result_error_with_empty_last_body`

```rust
#[test]
fn test_handle_tick_result_error_with_empty_last_body() {
    let last_body: Vec<u8> = Vec::new();
    let render_result: crate::error::Result<Vec<u8>> =
        Err(crate::error::TqError::QueryExecution("first tick failed".into()));

    let outcome = handle_tick_result(render_result, last_body);

    assert!(outcome.body.is_empty(), "Empty last_body stays empty on error");
    assert!(outcome.error_message.is_some(), "Error message must be populated");
}
```

**Pass criteria:**
- `outcome.body.is_empty()`
- `outcome.error_message.is_some()`

## TC100-U04: AC-4 corollary — Ownership transfer works correctly

**Requirement:** Feature 2 AC-1 (purity) — the function takes ownership of its inputs and returns a `TickOutcome` that owns the body; mutation of the returned body is independent.

**Location:** `src/commands/watch.rs`, `#[cfg(test)]`

**Existing test function:** `test_handle_tick_result_ownership`

```rust
#[test]
fn test_handle_tick_result_ownership() {
    let last_body = b"old".to_vec();
    let new_body = b"new".to_vec();
    let render_result: crate::error::Result<Vec<u8>> = Ok(new_body);
    let mut outcome = handle_tick_result(render_result, last_body);
    outcome.body.extend_from_slice(b"-more");
    assert_eq!(outcome.body, b"new-more");
}
```

**Pass criteria:** `outcome.body == b"new-more"` — mutation of the returned value is independent.

## AC-2 — Behavioral Identity (Manual / Regression)

**Requirement:** Feature 2 AC-2 — existing `/sessions --watch`, `/locks --watch`, and `/resources --watch` behaviour is byte-identical to pre-extraction.

**Approach:** This AC is validated by two means:
1. **Code inspection:** `watch_loop` calls `handle_tick_result(render_result, last_body)` at line 167 and assigns `last_body = outcome.body`. This is the only change from the pre-extraction inline match. The function is pure — it cannot introduce side effects. The output of `TickOutcome` is used in exactly the same way as the original inline assignments.
2. **Regression guard:** TC097 tests cover `/sessions --watch` end-to-end. TC097 cannot be executed in this sprint due to the pre-existing live-DB timeout documented in `tests/results/sprint-66/tc097-failure-analysis.md`. AC-2 is therefore: `skipped for reason: TC097 interactive regression guard not runnable due to pre-existing live-DB timeout (same timeout that blocked TC097 in Sprint 65 and Sprint 66); code inspection confirms byte-identical behavior`.
