# TC086: Transaction Control - Basic Success (--atomic)

**Test ID:** TC086  
**Feature:** Batch Mode Transaction Control (Sprint 23 - P1)  
**Priority:** Critical  
**Test Type:** Integration (with database)  
**Created:** 2026-01-23

## Objective

Verify `--atomic` flag wraps multi-statement batch in a transaction with automatic COMMIT on success.

## Requirement Coverage

- REQ-F2-01: `--atomic` flag accepted
- REQ-F2-02: BEGIN TRANSACTION before first statement
- REQ-F2-03: COMMIT on success

## Prerequisites

**BLOCKING:** Requires `--atomic` flag implementation in `src/cli.rs`.  
If flag not yet implemented, this test is **BLOCKED**.

## Test Procedure

```bash
# Create test table
tq query "CREATE VOLATILE TABLE test_txn (id INT, val VARCHAR(50))"

# Execute multi-statement batch with --atomic
cat > /tmp/test_batch.sql << 'SQL'
INSERT INTO test_txn VALUES (1, 'First');
INSERT INTO test_txn VALUES (2, 'Second');
INSERT INTO test_txn VALUES (3, 'Third');
SQL

tq query --file /tmp/test_batch.sql --atomic -v

# Verify all rows committed
tq query "SELECT COUNT(*) FROM test_txn"
# Expected: 3

# Clean up
tq query "DROP TABLE test_txn"
rm -f /tmp/test_batch.sql
```

## Expected Results

- ✅ Verbose output shows: "BEGIN TRANSACTION (--atomic mode)"
- ✅ All statements execute successfully
- ✅ Verbose output shows: "COMMIT (all statements succeeded)"
- ✅ All rows visible in database after commit

## Acceptance Criteria

- BEGIN issued before first statement
- COMMIT issued after last statement
- All changes persisted
- Transaction messages clear
