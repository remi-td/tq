# TC-043-001: Profile Add - Happy Path

**Test ID:** TC-043-001
**Feature:** Profile Management - `tq profile add`
**Priority:** P0 - Critical
**Test Type:** Integration (CLI process) + Unit
**Sprint:** 43
**Created:** 2026-03-21
**Requirement References:** AC-1, AC-4, AC-6, AC-7, AC-8, AC-11, AC-12

---

## Objective

Verify that `tq profile add <name> --host <host> [options]` correctly creates a new profile entry in the config file, produces a confirmation message, creates the config directory and file if they do not exist, and rejects invalid field values.

---

## Test Environment

All integration tests use a temporary directory as the config home to prevent modifying the real `~/.tq/config.toml`. The config path must be overridable via the `TQ_CONFIG_DIR` environment variable (or equivalent mechanism exposed by the architect). No database connection is required.

**Setup pattern (each test):**
```rust
let tmp = tempfile::TempDir::new().unwrap();
let config_dir = tmp.path();
// Pass as env var to the spawned process:
// std::process::Command::new("tq")
//     .env("TQ_CONFIG_DIR", config_dir)
//     ...
```

## Test Cases

### TS43-P-A01: Add profile to non-existent config (AC-1, AC-6, AC-8)

**Precondition:** Config directory does NOT exist (fresh temp dir with no `config.toml`).

**Command:**
```
tq profile add dev --host myhost.example.com
```

**Expected Results:**
- Exit code: 0
- Stdout contains: `Profile 'dev' added successfully` (or equivalent confirmation message)
- Config file created at `<TQ_CONFIG_DIR>/config.toml`
- Config file contains a `[profiles.dev]` section (or `[[profile]]` depending on TOML schema)
- `host = "myhost.example.com"` present in the `dev` profile section

```rust
#[test]
fn test_profile_add_creates_config_and_directory() {
    let tmp = tempfile::TempDir::new().unwrap();
    let config_dir = tmp.path();
    // config.toml must not exist yet
    assert!(!config_dir.join("config.toml").exists());

    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "dev", "--host", "myhost.example.com"])
        .env("TQ_CONFIG_DIR", config_dir)
        .output()
        .expect("failed to run tq");

    assert!(output.status.success(), "exit code must be 0, stderr: {}", String::from_utf8_lossy(&output.stderr));
    let stdout = String::from_utf8_lossy(&output.stdout);
    assert!(
        stdout.to_lowercase().contains("dev") && (stdout.to_lowercase().contains("added") || stdout.to_lowercase().contains("success")),
        "stdout must confirm profile creation, got: {stdout}"
    );
    let config_path = config_dir.join("config.toml");
    assert!(config_path.exists(), "config.toml must be created");
    let contents = std::fs::read_to_string(&config_path).unwrap();
    assert!(contents.contains("myhost.example.com"), "host must appear in config");
    assert!(contents.contains("dev"), "profile name must appear in config");
}
```

### TS43-P-A02: Add profile with all fields specified (AC-1, AC-8)

**Precondition:** Fresh temp directory (no config file).

**Command:**
```
tq profile add prod \
  --host td-prod.example.com \
  --port 1025 \
  --database mydb \
  --user admin \
  --logmech TD2 \
  --password-file /home/user/.secrets/td-prod.pass
```

**Expected Results:**
- Exit code: 0
- Confirmation message on stdout
- All specified fields written to the TOML config under the `prod` profile

```rust
#[test]
fn test_profile_add_all_fields() {
    let tmp = tempfile::TempDir::new().unwrap();
    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args([
            "profile", "add", "prod",
            "--host", "td-prod.example.com",
            "--port", "1025",
            "--database", "mydb",
            "--user", "admin",
            "--logmech", "TD2",
            "--password-file", "/home/user/.secrets/td-prod.pass",
        ])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output()
        .expect("failed to run tq");

    assert!(output.status.success(), "stderr: {}", String::from_utf8_lossy(&output.stderr));
    let contents = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert!(contents.contains("td-prod.example.com"), "host");
    assert!(contents.contains("1025"),                "port");
    assert!(contents.contains("mydb"),                "database");
    assert!(contents.contains("admin"),               "user");
    assert!(contents.contains("TD2"),                 "logmech");
    assert!(contents.contains("td-prod.pass"),        "password-file");
}
```

### TS43-P-A05: Add duplicate profile without --force fails (AC-4)

**Precondition:** Config file already contains a profile named `dev`.

**Command:**
```
tq profile add dev --host otherhost.example.com
```

**Expected Results:**
- Exit code: non-zero
- Error message mentions "dev" and indicates the profile already exists

```rust
#[test]
fn test_profile_add_duplicate_without_force_fails() {
    let tmp = tempfile::TempDir::new().unwrap();
    // Create initial profile
    let _ = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "dev", "--host", "originalhost.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    // Attempt to add again without --force
    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "dev", "--host", "otherhost.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output()
        .expect("failed to run tq");

    assert!(!output.status.success(), "must fail when profile already exists");
    let stderr = String::from_utf8_lossy(&output.stderr);
    let stdout = String::from_utf8_lossy(&output.stdout);
    let combined = format!("{stderr}{stdout}");
    assert!(
        combined.contains("dev") && (combined.to_lowercase().contains("exists") || combined.to_lowercase().contains("already")),
        "error must mention profile name and existence, got: {combined}"
    );
    // Original host must not be overwritten
    let contents = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert!(contents.contains("originalhost.example.com"), "original host must be preserved");
}
```

### TS43-P-A06: Add duplicate profile with --force overwrites (AC-4)

**Precondition:** Config file already contains a profile named `dev` pointing to `originalhost`.

**Command:**
```
tq profile add dev --host newhost.example.com --force
```

**Expected Results:**
- Exit code: 0
- Confirmation message on stdout
- Config file now has `newhost.example.com` for the `dev` profile

```rust
#[test]
fn test_profile_add_duplicate_with_force_overwrites() {
    let tmp = tempfile::TempDir::new().unwrap();
    // Create initial profile
    let _ = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "dev", "--host", "originalhost.example.com"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output().unwrap();

    // Overwrite with --force
    let output = std::process::Command::new(env!("CARGO_BIN_EXE_tq"))
        .args(["profile", "add", "dev", "--host", "newhost.example.com", "--force"])
        .env("TQ_CONFIG_DIR", tmp.path())
        .output()
        .expect("failed to run tq");

    assert!(output.status.success(), "stderr: {}", String::from_utf8_lossy(&output.stderr));
    let contents = std::fs::read_to_string(tmp.path().join("config.toml")).unwrap();
    assert!(contents.contains("newhost.example.com"), "new host must be written");
}
```
