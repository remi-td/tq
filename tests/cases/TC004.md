## Purpose

Verify that `tq query --format json` produces valid, well-formatted JSON output with proper type preservation.

## Scope

This test validates:
- JSON output format
- Type preservation (numbers, booleans, null)
- Valid JSON syntax
- Array of objects structure
- Parsing with jq

## Prerequisites

- tq binary is built and available
- `.env` file configured with valid Teradata connection credentials
- jq installed for JSON validation

## Test Procedure

### Step 1: Execute query with JSON format
```bash
# Using credentials from .env file
tq query --format json "SELECT 1 AS id, 'Alice' AS name, true AS active"
```

### Step 2: Validate JSON syntax with jq
```bash
tq query --format json "SELECT 1 AS id" | jq '.'
```

### Step 3: Test NULL value handling
```bash
tq query --format json "SELECT NULL AS empty_field"
```

### Step 4: Test numeric types
```bash
tq query --format json "SELECT 42 AS integer, 3.14 AS decimal, 1e10 AS scientific"
```

### Step 5: Test boolean types
```bash
tq query --format json "SELECT true AS t, false AS f"
```

### Step 6: Pipe to jq for processing
```bash
tq query --format json "SELECT 1 AS id, 'test' AS name" | jq '.[0].name'
```

## Expected Results

### Step 1 Output:
```json
[
  {
    "id": 1,
    "name": "Alice",
    "active": true
  }
]
```
- Valid JSON array
- Numbers as JSON numbers (not strings)
- Booleans as JSON booleans (not strings)

### Step 2 Output:

    "id": 1

]

jq should parse without errors

### Step 6 Output:

jq extracts the field correctly

## Pass/Fail Criteria

**PASS if:**
- Output is valid JSON (parseable by jq)
- Array of objects structure
- Numbers are JSON numbers, not strings
- Booleans are JSON booleans, not strings
- NULL is JSON null, not empty string
- Column names are object keys
- No formatting issues or syntax errors
- Exit code is 0

**FAIL if:**
- Invalid JSON syntax
- Type information is lost (all strings)
- NULL represented incorrectly
- Not parseable by standard JSON tools
- Exit code is non-zero

## Notes

- JSON format is ideal for scripting and piping to tools like jq
- Type preservation is critical for data processing
- Output should be compact or pretty-printed consistently
- Large result sets should still be valid JSON
