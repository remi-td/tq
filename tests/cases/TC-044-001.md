# TC-044-001: Driver Path Resolution - Fallback Chain Order

**Sprint:** 44
**Feature:** Runtime Driver Library Resolution (Issue #31)
**Acceptance Criteria:** AC-1, AC-2
**Type:** Unit Test
**Requires DB:** No
**Requires Binary:** No

---

## Objective

Verify that the driver path resolution function returns candidate directories in the correct priority order: executable directory first, then `--driver-lib-dir` flag, then `TERADATA_LIB_DIR` env var, then `.` (current working directory) as last resort.

## Preconditions

- The implementation exposes a testable path resolution function (pure function, no actual driver loading)
- The function signature accepts an injected `exe_path: &Path` to avoid calling `current_exe()` inside the function under test

## Test Scenarios

### Scenario 1: No flag, no env var

**Setup:** `exe_path = /home/user/bin/tq`, `flag = None`, `env_var = None`

**Expected:** Resolution candidate list is `["/home/user/bin", "."]` (exe dir first, cwd last)

**Assert:**
- `candidates[0]` equals `/home/user/bin`
- `candidates[candidates.len() - 1]` equals `.`
- Length is 2

### Scenario 2: Flag provided

**Setup:** `exe_path = /home/user/bin/tq`, `flag = Some("/opt/teradata/lib")`, `env_var = None`

**Expected:** Resolution candidate list is `["/home/user/bin", "/opt/teradata/lib", "."]`

**Assert:**
- `candidates[0]` equals `/home/user/bin` (exe dir still first)
- `candidates[1]` equals `/opt/teradata/lib` (flag second)
- `candidates[candidates.len() - 1]` equals `.`
- Length is 3

### Scenario 3: Env var set

**Setup:** `exe_path = /home/user/bin/tq`, `flag = None`, `env_var = Some("/usr/local/teradata")`

**Expected:** Resolution candidate list is `["/home/user/bin", "/usr/local/teradata", "."]`

**Assert:**
- `candidates[0]` equals `/home/user/bin`
- `candidates[1]` equals `/usr/local/teradata`
- Length is 3

### Scenario 4: Both flag and env var set

**Setup:** `exe_path = /home/user/bin/tq`, `flag = Some("/opt/lib")`, `env_var = Some("/usr/lib")`

**Expected:** Resolution candidate list is `["/home/user/bin", "/opt/lib", "/usr/lib", "."]`

**Assert:** Flag (`/opt/lib`) appears before env var (`/usr/lib`); both appear before `.`

### Scenario 5: exe_path is in current directory

**Setup:** `exe_path = ./tq` (relative), `flag = None`, `env_var = None`

**Expected:** Exe dir candidate resolves correctly (parent of exe path), `.` still last

**Assert:** No panic; candidates contains at least one entry; last entry is `.`

## Implementation Location

`src/db/client.rs` - extract function `resolve_driver_candidates(exe_path: &Path, flag: Option<&str>, env_var: Option<&str>) -> Vec<PathBuf>`

## Test Code Sketch

```rust
#[cfg(test)]
mod tests {
    use super::*;
    use std::path::Path;

    #[test]
    fn test_resolve_candidates_no_flag_no_env() {
        let exe = Path::new("/home/user/bin/tq");
        let candidates = resolve_driver_candidates(exe, None, None);
        assert_eq!(candidates[0], Path::new("/home/user/bin"));
        assert_eq!(candidates.last().unwrap(), Path::new("."));
        assert_eq!(candidates.len(), 2);
    }

    #[test]
    fn test_resolve_candidates_flag_takes_second_position() {
        let exe = Path::new("/home/user/bin/tq");
        let candidates = resolve_driver_candidates(exe, Some("/opt/lib"), None);
        assert_eq!(candidates[0], Path::new("/home/user/bin"));
        assert_eq!(candidates[1], Path::new("/opt/lib"));
        assert_eq!(candidates.last().unwrap(), Path::new("."));
        assert_eq!(candidates.len(), 3);
    }

    #[test]
    fn test_resolve_candidates_env_var_after_flag() {
        let exe = Path::new("/home/user/bin/tq");
        let candidates = resolve_driver_candidates(exe, Some("/opt/lib"), Some("/usr/lib"));
        assert_eq!(candidates[0], Path::new("/home/user/bin"));
        assert_eq!(candidates[1], Path::new("/opt/lib"));
        assert_eq!(candidates[2], Path::new("/usr/lib"));
        assert_eq!(candidates.last().unwrap(), Path::new("."));
        assert_eq!(candidates.len(), 4);
    }

    #[test]
    fn test_resolve_candidates_only_env_var() {
        let exe = Path::new("/home/user/bin/tq");
        let candidates = resolve_driver_candidates(exe, None, Some("/usr/local/teradata"));
        assert_eq!(candidates[0], Path::new("/home/user/bin"));
        assert_eq!(candidates[1], Path::new("/usr/local/teradata"));
        assert_eq!(candidates.last().unwrap(), Path::new("."));
        assert_eq!(candidates.len(), 3);
    }
}
```

## Pass Criteria

All 4-5 scenario assertions pass. No panic. No compilation errors.
