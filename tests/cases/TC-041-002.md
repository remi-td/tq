## Purpose

Verify that `build.rs` has been updated to use Cargo's `CARGO_CFG_TARGET_OS` and `CARGO_CFG_TARGET_ARCH` environment variables (read at compile time for the TARGET platform) instead of `cfg!(target_os)` (which evaluates against the HOST platform). This change is essential for cross-compilation to select the correct native library.

## Background

The bug: `cfg!(target_os = "macos")` evaluates against the host OS at build time. When cross-compiling from macOS to Linux, it would still return `true` and select the macOS `.dylib`. The fix uses `std::env::var("CARGO_CFG_TARGET_OS")` which Cargo sets to the target platform's OS during cross-compilation.

## Acceptance Criteria Coverage

- **AC-12**: build.rs uses `CARGO_CFG_TARGET_OS` instead of `cfg!(target_os)`
- **AC-13**: build.rs uses `CARGO_CFG_TARGET_ARCH` to select correct library variant

## Test Procedure

### Check 1: CARGO_CFG_TARGET_OS is present

```bash
grep -n "CARGO_CFG_TARGET_OS" build.rs
```

**Expected result:**
- At least one match found
- The variable is used to determine the target OS (e.g., "linux", "macos", "windows")

### Check 2: CARGO_CFG_TARGET_ARCH is present

```bash
grep -n "CARGO_CFG_TARGET_ARCH" build.rs
```

**Expected result:**
- At least one match found
- The variable is used to select the architecture-specific library (e.g., `teradatasql.arm.so` for aarch64)

### Check 3: Old host-platform detection is removed

```bash
grep -n 'cfg!(target_os' build.rs
```

**Expected result:**
- Zero matches (the host-platform detection has been removed)

### Check 4: Correct library name mapping for supported targets

Review `build.rs` for the following mappings:

| Target OS | Target Arch | Expected Library Name |
|-----------|-------------|----------------------|
| linux | x86_64 | teradatasql.so |
| linux | aarch64 | teradatasql.arm.so |
| macos | x86_64 | teradatasql.dylib |
| macos | aarch64 | teradatasql.dylib |
| windows | x86_64 | teradatasql.dll |

**Expected result:**
- All target mappings are present and correct in the updated build.rs
