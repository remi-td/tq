# TC-035-002: Project Config Precedence Rules

## Metadata

## Purpose

Verify that project configuration correctly overrides user configuration according to precedence rules: project > user > defaults.

## Acceptance Criteria Coverage

- **AC-2**: Load project config before user config (project overrides user) - Precedence logic
- **AC-6**: Project profiles take precedence over user profiles with same name - Profile-level precedence
- **AC-7**: Comprehensive error handling (invalid TOML, permission errors) - Error handling component

## Scope

This test validates:
- Project config defaults override user config defaults
- Project profiles override user profiles (same name)
- Field-level merging (project fields override user fields)
- User-only profiles remain available (not removed by project config)
- Both configs loaded and merged correctly
- Profile fields from user config are inherited when not specified in project config

## Prerequisites

- Rust test framework available
- Configuration loading implementation exists
- Config merging logic exists

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn test_project_defaults_override_user_defaults() {
        // User config: format = "json", timing = false
        let user_config = Config {
            defaults: Some(Defaults {
                format: Some("json".to_string()),
                timing: Some(false),
                editor_mode: None,
                syntax_highlighting: None,
                paging: None,
            }),
            profiles: HashMap::new(),
        };

        // Project config: format = "table", timing = true
        let project_config = Config {
            defaults: Some(Defaults {
                format: Some("table".to_string()),
                timing: Some(true),
                editor_mode: None,
                syntax_highlighting: None,
                paging: None,
            }),
            profiles: HashMap::new(),
        };

        // Merge: project overrides user
        let merged = merge_configs(Some(user_config), Some(project_config));

        assert_eq!(merged.defaults.as_ref().unwrap().format.as_ref().unwrap(), "table");
        assert_eq!(merged.defaults.as_ref().unwrap().timing.unwrap(), true);
    }

    #[test]
    fn test_project_profile_overrides_user_profile() {
        // User config: profile "dev" with host = "localhost", database = "my_local"
        let mut user_profiles = HashMap::new();
        user_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("localhost".to_string()),
                port: None,
                database: Some("my_local".to_string()),
                user: Some("alice".to_string()),
                password_file: Some("~/.tq/passwords/dev".to_string()),
                logmech: None,
                timeout: None,
            },
        );
        let user_config = Config {
            defaults: None,
            profiles: user_profiles,
        };

        // Project config: profile "dev" with host = "dev.company.com", database = "shared_dev"
        let mut project_profiles = HashMap::new();
        project_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("dev.company.com".to_string()),
                port: Some(1025),
                database: Some("shared_dev".to_string()),
                user: None, // Not specified - should inherit from user
                password_file: None, // Not specified - should inherit from user
                logmech: Some("LDAP".to_string()),
                timeout: None,
            },
        );
        let project_config = Config {
            defaults: None,
            profiles: project_profiles,
        };

        // Merge: project profile fields override user profile fields
        let merged = merge_configs(Some(user_config), Some(project_config));

        let dev_profile = merged.profiles.get("dev").unwrap();
        assert_eq!(dev_profile.host.as_ref().unwrap(), "dev.company.com");
        assert_eq!(dev_profile.database.as_ref().unwrap(), "shared_dev");
        assert_eq!(dev_profile.logmech.as_ref().unwrap(), "LDAP");
        // Fields from user config should be inherited
        assert_eq!(dev_profile.user.as_ref().unwrap(), "alice");
        assert_eq!(
            dev_profile.password_file.as_ref().unwrap(),
            "~/.tq/passwords/dev"
        );
    }

    #[test]
    fn test_user_only_profiles_preserved() {
        // User config: profiles "dev" and "personal"
        let mut user_profiles = HashMap::new();
        user_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("localhost".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        user_profiles.insert(
            "personal".to_string(),
            Profile {
                host: Some("my-home-server.local".to_string()),
                port: None,
                database: Some("sandbox".to_string()),
                user: Some("alice".to_string()),
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        let user_config = Config {
            defaults: None,
            profiles: user_profiles,
        };

        // Project config: profile "dev" only (not "personal")
        let mut project_profiles = HashMap::new();
        project_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("dev.company.com".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        let project_config = Config {
            defaults: None,
            profiles: project_profiles,
        };

        // Merge
        let merged = merge_configs(Some(user_config), Some(project_config));

        // Both profiles should exist
        assert!(merged.profiles.contains_key("dev"), "dev profile should exist");
        assert!(
            merged.profiles.contains_key("personal"),
            "personal profile should be preserved from user config"
        );

        // "personal" should be unchanged
        let personal = merged.profiles.get("personal").unwrap();
        assert_eq!(personal.host.as_ref().unwrap(), "my-home-server.local");
        assert_eq!(personal.database.as_ref().unwrap(), "sandbox");
    }

    #[test]
    fn test_project_only_profiles_available() {
        // User config: profile "personal"
        let mut user_profiles = HashMap::new();
        user_profiles.insert(
            "personal".to_string(),
            Profile {
                host: Some("localhost".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        let user_config = Config {
            defaults: None,
            profiles: user_profiles,
        };

        // Project config: profiles "dev", "staging", "prod"
        let mut project_profiles = HashMap::new();
        project_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("dev.company.com".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        project_profiles.insert(
            "staging".to_string(),
            Profile {
                host: Some("staging.company.com".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        let project_config = Config {
            defaults: None,
            profiles: project_profiles,
        };

        // Merge
        let merged = merge_configs(Some(user_config), Some(project_config));

        // All profiles should exist
        assert_eq!(merged.profiles.len(), 3, "Should have 3 profiles total");
        assert!(merged.profiles.contains_key("personal"));
        assert!(merged.profiles.contains_key("dev"));
        assert!(merged.profiles.contains_key("staging"));
    }

    #[test]
    fn test_user_config_only() {
        // User config present, no project config
        let mut user_profiles = HashMap::new();
        user_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("localhost".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        let user_config = Config {
            defaults: Some(Defaults {
                format: Some("json".to_string()),
                timing: None,
                editor_mode: None,
                syntax_highlighting: None,
                paging: None,
            }),
            profiles: user_profiles,
        };

        // No project config
        let merged = merge_configs(Some(user_config), None);

        // User config should pass through unchanged
        assert_eq!(
            merged.defaults.as_ref().unwrap().format.as_ref().unwrap(),
            "json"
        );
        assert!(merged.profiles.contains_key("dev"));
    }

    #[test]
    fn test_project_config_only() {
        // Project config present, no user config
        let mut project_profiles = HashMap::new();
        project_profiles.insert(
            "dev".to_string(),
            Profile {
                host: Some("dev.company.com".to_string()),
                port: None,
                database: None,
                user: None,
                password_file: None,
                logmech: None,
                timeout: None,
            },
        );
        let project_config = Config {
            defaults: Some(Defaults {
                format: Some("table".to_string()),
                timing: Some(true),
                editor_mode: None,
                syntax_highlighting: None,
                paging: None,
            }),
            profiles: project_profiles,
        };

        // No user config
        let merged = merge_configs(None, Some(project_config));

        // Project config should pass through unchanged
        assert_eq!(
            merged.defaults.as_ref().unwrap().format.as_ref().unwrap(),
            "table"
        );
        assert_eq!(merged.defaults.as_ref().unwrap().timing.unwrap(), true);
        assert!(merged.profiles.contains_key("dev"));
    }

    #[test]
    fn test_neither_config_present() {
        // No user config, no project config
        let merged = merge_configs(None, None);

        // Should return empty config (or built-in defaults)
        assert!(merged.defaults.is_none() || merged.defaults.as_ref().unwrap().format.is_none());
        assert!(merged.profiles.is_empty());
    }
}

## Expected Results

All unit tests pass:
- Project defaults override user defaults (format, timing)
- Project profiles override user profiles with same name
- User-only profiles are preserved (not removed)
- Project-only profiles are available
- Field-level merging works (project fields override, user fields inherited)
- User config only works (no project config present)
- Project config only works (no user config present)
- Neither config present returns empty config

**PASS if:**

**FAIL if:**
