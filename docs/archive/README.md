# Archive

This directory contains historical documents that are no longer actively used but provide important context for the project's evolution.

## Contents

- **`original-user-story.md`**: The original feature request that kicked off the tq project (January 2025)
  - Described the vision for an interactive CLI database tool
  - Defined initial feature set (syntax highlighting, auto-completion, REPL, etc.)
  - Established technical requirements (lightweight, fast, single binary)
  - This request led to the creation of the tq project and guided early sprint planning

## Purpose

These documents are preserved for:
- Historical reference and project context
- Understanding original requirements and vision
- Tracking how the project evolved from initial conception
- Providing context for design decisions made in early sprints

## Note

These documents may reference outdated workflows or tools (e.g., the `incoming/` folder system that was replaced by GitHub Issues in January 2026).
